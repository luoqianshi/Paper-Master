> 依据：`skeleton-annotations.csv` 全部 97 条 `transferable` 字段（95 Y / 2 N）+ `batch-B01`~`B14` 差异化小节。使用者本行：低空无人机视角检测（YOLOv8/v11/v12、烟火误检优化、时空变化监测）。

## 3. 实验节的视觉化改写（建议 H3 序列）

1. **实验设置** — 写数据集与指标口径。配 `数据集\|图像数\|分辨率\|类别\|小目标占比` 表；指标行一次性定义 mAP/AP50/AP75/AP_S/AP_M/AP_L/FPS/Params/GFLOPs。
2. **对比实验** — 定量主表：`方法\|AP50:95\|AP50\|AP75\|AP_S\|AP_M\|AP_L\|Params\|GFLOPs\|FPS`，最优加粗；配 PR 曲线；末句必须给一句归因。
3. **消融实验** — H4 按模块（骨干/颈部/检测头/损失）。默认「文字段 + 增益表」`模块\|mAP\|Δ\|Params\|FPS`；变体 ≤4 且能用「实验情况\|意义」说清才启用变体表（B05 规范）。
4. **速度-精度权衡** — mAP-FPS 散点图、mAP-Params 曲线、输入分辨率敏感性折线；单超参连续调节出档位。
5. **可视化分析** — 检测效果图组（基线 vs 本文，红框标漏检、蓝框标误检）、Grad-CAM 热力图、混淆矩阵。
6. **跨数据集泛化** — 源域→目标域 mAP 衰减矩阵表；跨机型 / 跨地域 / 跨飞行高度三档。
7. **失败案例与局限性** — 典型误检图组（烟火误检：云霞、反光、烟囱）与漏检图组（极小目标、密集遮挡），归因到高度/光照/天气等场景因素。

## 5. 不可迁移项（诚实边界）

**两条 N 判定的原由**

- **不平衡学习/03 三支决策集成** — 预备知识节强依赖粗糙集与 CCA 覆盖算法的领域术语，整套形式化无法平移到视觉。仅「把算法随机性转化为集成多样性」这一**论证角度**可借。
- **决策森林/10 代价敏感深度森林（价格预测）** — 代价矩阵与区间离散化绑定表格回归业务（房价/租金分箱），与框级检测损失无对应。仅「按业务代价改造损失」这一层**抽象**可借。

**还有哪些表格 ML 手法会在视觉领域失效**

1. **符号回归 / GP 搜索本身不迁移**（B09 决策树08 明写）。可迁的只是其「合成集→真实集→噪声鲁棒→可解释」四段实验结构。
2. **「特征数-错误率」曲线会退化**：视觉无枚举特征维度，须换成「参数量/GFLOPs-mAP」曲线。
3. **大规模数据集基准不可复制**：表格侧动辄 68/96/110/117 个 UCI 集，航拍公开集有限。改为「多场景 + 跨数据集泛化 + 自建巡检集」三档；数据集 ≤5 时 Friedman/贝叶斯符号秩检验统计效力不足，改用逐集 ΔmAP + 置信区间柱状图。
4. **准确率对比表不足以支撑结论**：mAP 差 1–2 点往往看不出语义差异，误检/漏检只有效果图组能说清，定量表必须退居佐证位。
5. **特征重要性 ≠ 注意力图**：热力图不构成因果归因，必须配「关掉该模块后的 ΔmAP」才算证据。
6. **公式截图不可接受**：CIoU / Focal / 标签分配公式必须写 LaTeX（B05 判据：≥3 符号上符号表，≤2 符号走行内「其中」），否则不可复现。
