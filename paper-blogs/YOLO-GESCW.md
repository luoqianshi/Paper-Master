## 研究动机

红花是一种集药用、油料、天然色素等功能于一体的重要经济作物，其盛花期花丝直立、含水率高、颜色呈橘红色、形态饱满，是最佳采收期，及时采收且在不损伤花蕾情况下 2～3 d 可再生长下一茬花丝，累计可采收 2～3 茬，目前盛花期红花花丝采收仍依赖人工，采收技术要求高、人工需求量大、劳动强度高，人工采收成本比例占种植收益 50% 以上，为缓解人工采收劳动强度、降低采收成本，研制红花智能化采收装备成为突破红花采收难题的关键方向，而田间盛花期红花的精准快速识别是装备研发的一个关键环节。深度学习目标检测算法中，传统的两阶段检测算法虽在农业领域有一定应用，但在检测精度和实时性的平衡上，单阶段的 YOLO 系列算法更具竞争力；随着农业机器人技术发展，机器视觉与深度学习融合已成为果实等收获物快速精准识别的主流技术路径。现有相关研究中，张振国等基于 YOLOv3 提出 GSC-YOLOv3 红花丝检测算法，mAP 达 91.89%，但是未进行边缘设备部署，训练设备测试帧率仅 51.1 帧/s；GUO 等基于 YOLOv5 提出 SF-YOLO 红花检测模型，但计算开销较大，参数量达 5.34 M、浮点计算量达 13.2 G；陈金荣等针对红花尺度变化大、遮挡情况等复杂问题提出 YOLO-SSAR 红花检测模型，精确率为 90.1%，模型大小为 9.7 MB，但是未进行边缘设备部署测试；张新月等基于 YOLOv8n 提出 YOLOv8n-VLWS 轻量化红花识别方法，模型大小仅 3.00 MB，轻量化改进取得一定成效，但是边缘设备部署测试单图检测耗时较长，单图推理需要 0.27 s；CHEN 等基于 YOLOv8n 改进的 YOLO-SaFi 非结构环境下红花花丝检测算法，边缘设备部署测试检测速度为 29.1 帧/s，检测速度仍可进一步提升；王小荣等针对田间复杂环境造成红花机械化采摘识别不准问题，基于 YOLOv7 提出 Improved YOLOv7 模型，在不均衡样本检测方面取得了一定效果，但是参数量达 40.9 M，精确率仅 81.8%，模型检测精度和轻量化平衡仍有提升空间。但是针对盛花期红花检测，现有研究仍存在三方面核心问题：一是红花果球位姿各异且易晃动，花丝尺度变化大且属于小目标，增加检测难度；二是复杂自然环境下光照变化、枝叶遮挡、花丝重叠，模型检测精度不足；三是模型体积大、计算资源占用高，无法满足边缘设备高效部署需求。

## 文章贡献

针对盛花期红花检测场景下目标位姿各异、花丝尺度变化大、复杂自然环境下光照变化与枝叶遮挡导致的检测精度不足，以及模型体积大、计算资源占用高无法满足边缘设备高效部署需求的问题，本文提出了基于 YOLOv8n 的改进算法 YOLO-GESCW。其核心是幽灵卷积（Ghost Conv）、高效通道注意力（ECA）模块、空间金字塔池化高效层聚合网络（SPPELAN）模块、C3k2 模块与 Wise-IoUv3 损失函数的协同优化。首先引入幽灵卷积替换标准卷积，通过"基础特征提取 - 廉价特征衍生"两步法在保证特征表达能力的同时初步减少参数量与计算量；接着采用 ECA 注意力机制替换主干网络及颈部网络部分 C2f 模块，通过一维卷积自适应捕捉通道间依赖关系，避免全连接层导致的参数膨胀；进一步引入 SPPELAN 模块替换原 SPPF 模块，采用 3 个不同池化卷积核大小的最大池化层并行处理基础特征，强化多尺度特征均衡提取能力；在颈部网络加入 C3k2 模块，通过双分支结构与拼接融合策略增强对红花精细轮廓和局部细节特征的快速精准捕捉能力；最后使用 Wise-IoUv3 函数优化边界框损失，通过精细化误差惩罚机制解决遮挡场景定位问题。实验表明，改进后模型参数量约 0.98 M、模型大小为 2.09 MB、浮点计算量为 3.4 G，较原 YOLOv8n 分别降低 67.44%、65.10% 和 58.02%；测试集精确率为 93.6%、召回率为 93.0%、平均精度均值（mAP0.5）为 98.1%，平均检测速度为 106.79 帧/s；在 NVIDIA Jetson Xavier NX 边缘设备部署测试，目标模型 best.engine 大小为 3.48 MB、平均帧率 52.36 帧/s、单图平均推理耗时 0.007 2 s。该研究实现了检测模型轻量化与检测精度平衡，可为盛花期红花采收作业检测模型边缘设备部署提供解决方案。

## 本文方法

### 数据集构建与增强

盛花期红花数据图像采集地点为新疆维吾尔自治区塔城市裕民县哈拉布拉乡南哈拉不拉村，红花品种为"裕红 1 号"。裕民县是"中国无刺红花之乡"，红花种植面积约 1.33×10⁵ hm²，约占全疆一半。采集时间为 2025 年 7 月 10 日至 15 日，拍摄时间段为 7:00-10:00、12:00-14:00、20:00-22:00，采集设备为 iPhone 13、Vivo S15 Pro 智能手机，图像分辨率 4 032×3 024、3 072×3 072 像素，图像保存为"JPG"格式，所有数据图像均采集于自然环境中的盛花期红花。选择光照较强的晴天、光照较弱的阴天等天气状况下以顺光、侧光、逆光拍摄，俯视拍摄时摄像头光轴与竖直方向夹角 0°～45°，摄像头距离样本间距离 150～420 mm。最终，经过人工筛选剔除，采集到包含不同光照、不同位姿、不同尺度、不同遮挡以及重叠的盛花期红花数据图像 2 521 张。

为使模型充分训练、丰富盛花期红花样本数据集、进一步防止过拟合，本研究采用调整亮度、调节饱和度、引入高斯噪声等图像增强手段对原始图像进行处理，其中，亮度调整旨在模拟自然光照强度的动态变化，以还原不同时段（清晨、正午、傍晚）的实际光照效果；饱和度调节用于复现强光环境下设备摄像头因反射效应产生的图像偏差；而高斯噪声的引入则是为了模拟红花在风力作用下发生晃动，进而导致图像出现的模糊现象，使处理后的图像更贴合实际检测场景。原始数据集（2 521 张）叠加增强数据集共包含图片 7 563 张，利用脚本对所有数据图片尺寸调整为 640×640 像素尺寸。考虑到红花采收主要针对盛花期红花，该花期花丝形态饱满、颜色鲜艳呈现橘红色、具有很高的经济价值，为此仅对盛花期红花进行标注，标注标签为"Blooming"，采用标注软件 LabelImg 进行人工标注，标注过程精细化要求矩形框尽可能贴合花丝边缘，标注格式为 YOLO 格式的 txt 文件，且保证每张图片至少有一朵盛花期红花位置标注，最后，本研究利用脚本按照 7∶2∶1 比例将增强后的红花数据集划分为训练集（5 294 张）、验证集（1 512 张）、测试集（757 张）。

### YOLOv8n 基线模型

YOLOv8 作为 YOLO 系列目标检测算法的代表，在检测精度、推理速度与模型轻量化的平衡上较优，但在应用复杂环境检测、移动设备部署等计算资源受限的场景中，检测性能仍有提升空间。本研究选用 YOLOv8 系列中参数量最小、推理效率最高的 YOLOv8n 版本作为基线模型。其结构分为三部分，Backbone（主干网络）以 C2f 模块作为基础单元，承担核心特征提取任务；Neck（颈部网络）采用路径聚合网络（PANet）结构，负责多尺度特征融合；Head（检测头）采用解耦头结构与无锚框策略，在大、中、小三种尺度上完成目标分类与检测框定位。

### GhostConv 幽灵卷积

GhostConv 的目标是在保证特征表达能力的同时，初步减少参数量与计算量。原 YOLOv8n 采用标准卷积，其卷积核数量多、计算开销大。GhostConv 通过"基础特征提取 - 廉价特征衍生"两步法实现计算开销降低。具体流程如下：第一步，输入特征经 1×1 标准卷积压缩输入通道数，降低后续计算基数，同时融合跨通道信息，生成通道数更少的多层次核心基础特征；第二步，对每个基础特征分别执行低成本线性操作，生成"幽灵特征"，大幅减少卷积核计算与参数存储开销；最后，将第一步生成的基础特征与第二步生成的幽灵特征在通道维度拼接，得到与原标准卷积输出通道数、空间尺寸一致的特征图，完成同等特征表达能力下的计算开销降低。GhostConv 的输出为后续 ECA 模块提供基础特征，是骨干数据流的第一环改进。

### ECA 高效通道注意力

ECA 注意力模块的目标是增强特征筛选能力，进一步降低模型参数量与计算量。本研究使用 ECA 注意力机制替换主干网络全部 C2f 模块及颈部网络第 12、21 层 C2f 模块。ECA 注意力机制通过一维卷积自适应捕捉通道间依赖关系，避免全连接层导致的参数膨胀。首先对输入特征图执行全局平均池化，将每个通道的空间信息压缩为单个特征向量，获取全局上下文信息；其次将该特征向量送入 1D 卷积层，卷积核大小根据通道数自适应确定，实现通道依赖精准建模；最后通过 Sigmoid 激活函数对 1D 卷积输出归一化，得到各通道注意力权重，与原始输入特征图逐通道相乘，增强重要通道特征，抑制次要通道特征。ECA 注意力机制卷积核 k 与通道 C 关系如式（1）所示。

$$k = \psi(C) = |\log_2(C) / \gamma + b|_{\text{odd}}$$

| 符号 | 含义 |
| --- | --- |
| $k$ | 卷积核大小 |
| $C$ | 通道数 |
| $\gamma$ | 超参数，设为 2 |
| $b$ | 超参数，设为 1 |
| $|\cdot|_{\text{odd}}$ | 取最近奇数 |

这等价于通过一维卷积自适应地建立通道间的依赖关系，无需降维或展平操作即可捕捉全局上下文信息。该模块的输出为后续 SPPELAN 模块提供更聚焦的特征表示，是骨干与颈部数据流的第二环改进。

### SPPELAN 多尺度特征融合

SPPELAN 模块的目标是强化多尺度特征均衡提取能力，解决原 YOLOv8n 的 SPPF 模块对小目标红花局部簇状结构特征易丢失细节、导致检测精度不足的问题。本研究引入 SPPELAN 模块替换原 SPPF 模块。具体流程为：首先，输入特征通过 1×1 卷积统一通道维度，生成基础特征；其次，采用 3 个不同池化卷积核大小的最大池化层并行处理基础特征，既保留小目标局部细节，又兼顾大目标全局上下文；进一步，将原始基础特征与 3 个池化后的特征拼接，整合多尺度信息，避免单一尺度特征损耗；最后，经 1×1 卷积完成特征聚合，调整通道数至与后续网络匹配的维度，确保特征传递连贯性。SPPELAN 模块融合空间金字塔池化（SPP）的多尺度覆盖能力与高效特征聚合网络（ELAN）的特征整合能力，通过多尺度池化核并行提取特征，增强对小尺度红花的感知能力，提升复杂场景下模型鲁棒性。该模块的输出为后续 C3k2 模块提供多尺度特征，是颈部数据流的第三环改进。

### C3k2 细节捕捉模块

C3k2 模块的目标是增强对盛花期红花精细轮廓和局部细节特征的快速精准捕捉能力。本研究将 YOLOv8n 颈部网络第 15、18 层的 C2f 模块替换为 C3k2 模块。首先，输入特征经 1×1 卷积调整通道数后，分为两个并行分支，主分支直接传递基础特征，确保红花原始轮廓等低层级信息不丢失，残差分支进入由 N 个计算单元组成的残差序列，进行深层细节特征提取；其次，计算单元通过"C3k"参数选择类型，本研究设"C3k=False"，启用轻量化标准 Bottleneck 单元，在控制参数量的同时保证细节提取能力，每个计算单元采用"卷积 - 归一化 - 激活"标准配置，并通过"shortcut"参数启用跳跃连接，将输入与输出特征直接相加，缓解深层训练梯度消失问题，确保红花边缘、纹理等细节特征无损传递；最后，主分支原始特征与残差分支增强特征通过通道维度拼接融合，再经 1×1 卷积统一通道数后输出。该模块通过双分支结构与拼接融合策略，强化模型对红花轮廓与纹理的提取能力。C3k2 模块的输出为检测头提供更丰富的细节特征，是颈部数据流的第四环改进。

### Wise-IoUv3 损失函数

Wise-IoUv3 的目标是通过精细化误差惩罚机制解决遮挡场景定位问题，降低盛花期红花枝叶遮挡与重叠导致的边界框定位误差，提升盛花期红花检测的边界框定位精度与目标识别准确率。盛花期红花场景中存在类间枝叶遮挡红花和类中红花重叠遮挡，导致目标边界框易出现"定位偏移"或"形状偏差"。原 YOLOv8n 采用的 CIoU 损失函数，虽兼顾重叠度、中心点距离与宽高比，但存在两点缺陷：一是对宽高比的约束刚性过强；二是对高重叠遮挡目标的定位误差惩罚不足，导致边界框回归精度低。

CIoU 的计算如式（2）所示：

$$L_{\text{CIoU}} = 1 - \text{IoU} + \frac{\rho^2(b^{pt}, b^{gt})}{d^2} + \alpha v$$

| 符号 | 含义 |
| --- | --- |
| $L_{\text{CIoU}}$ | CIoU 损失 |
| $\text{IoU}$ | 预测框与真实框交并比 |
| $b^{pt}$ | 预测框中心点 |
| $b^{gt}$ | 真实框中心点 |
| $\rho$ | 两个中心点欧氏距离 |
| $d$ | 两个矩形框最小外接矩形对角线长度 |
| $\alpha$ | 平衡参数 |
| $v$ | 高宽比一致性度量 |

Wise-IoUv3 的计算如式（3）～（5）所示：

$$L_{\text{WIoU}} = r \cdot \exp\left(\frac{(x-x^{gt})^2 + (y-y^{gt})^2}{(H_g^2 + W_g^*)} \right) \cdot (1-\text{IoU})$$

| 符号 | 含义 |
| --- | --- |
| $L_{\text{WIoU}}$ | Wise-IoUv3 损失 |
| $(x, y)$ | 预测框中心点坐标 |
| $(x^{gt}, y^{gt})$ | 真实框中心点坐标 |
| $H_g, W_g$ | 预测框与真实框最小外接矩形的高和宽 |
| $*$ | 分离操作 |
| $r$ | 非单调聚焦系数 |

$$r = \frac{\beta}{\delta \beta^\delta - \delta}$$

| 符号 | 含义 |
| --- | --- |
| $\beta$ | 离群值，$\beta = (1-\text{IoU})^* \in [0, +\infty]$ |
| $\delta$ | 学习参数 |
| $*$ | 分离操作 |

直观上，Wise-IoUv3 将边界框回归误差拆解为"位置偏差"与"形状偏差"，独立优化路径，位置偏差强化中心点微调，形状偏差采用柔性权重约束；训练初期对小误差宽松惩罚，避免收敛缓慢，后期对大误差增强惩罚，强制修正框选偏移，将遮挡红花的边界框从枝叶区域调整至实际花体；通过"动态非单调频率调制"机制，降低低质量样本干扰，增强"中度遮挡、主体可见"有效红花样本的训练权重，减少无效样本导致的边界框损失，聚焦核心检测目标。Wise-IoUv3 作为最终的损失函数，指导整个网络的训练优化，是检测数据流的最后一环改进。

## 实验结果

### 实验设置

为确保试验条件一致性，本研究模型训练、验证和测试均在同一平台，该平台硬件配置为：Intel（R）Core（TM）i5-14600KF 14 核 3.50 GHz 处理器，主板为华硕 PRIME B760M-A WIFI D4，机带 RAM 32.0 GB、速度 3 600 MHz，显卡 NVIDIA GeForce RTX 4060TI 8GB。软件配置为：Windows 11（64 位专业工作站版）操作系统，Pytorch 2.6.0 深度学习框架，使用 12.6 版本 CUDA 加速 GPU，使用 Anaconda 24.11.3 部署 Ultralytics 8.3.162 资源库，编程使用 Python 3.12.9，编译器使用 PyCharm Community Edition 2 024.1.4。部分训练参数设置为：输入图片尺寸为 640×640 像素，优化器为 Auto，优化器动量因子为 0.937，衰减系数设置为 0.000 5，初始学习率为 0.005，训练批次大小设置为 16，训练轮次设置为 300，其余参数为默认值。评价指标采用精确率（precision，P）、召回率（recall，R）、平均精度均值（mean average precision，mAP，阈值设置为 0.5）、模型参数量（parameters）、浮点计算量（floating point of operation，FLOPs）、模型大小（model size）、帧率（frames per second，FPS）。

### 消融试验

为验证各改进模块在盛花期红花检测中的有效性，以 YOLOv8n 为基准模型开展消融试验，结果如下表所示。

![消融试验结果](../assets/paper-imgs/YOLO-GESCW/table1_ablation.png)

由表可知，与基线模型 YOLOv8n 相比，单独引入 Ghost Conv 替换标准卷积后，参数量、浮点计算量均出现小幅度下降，说明先进行部分基础特征生成，再进行简单线性操作可减少计算开销。在引入 Ghost conv 基础上，引入 ECA 注意力模块替换 C2f 模块，模型参数量、浮点计算量均大幅度下降，说明该模块通过通道自适应卷积操作可有效降低模型的参数量和计算量。单独引入 SPPELAN 模块替换 SPPF 后，参数量、浮点计算量波动较小，平均精度均值维持 98.5%，说明其在不增加计算负担的前提下，维持多尺度特征融合能力。单独引入 C3k2 模块后精确率为所有单模块改进中最优达 95.1%，说明该模块有助于增强模型细节特征提取能力。同时进行 5 个模块改进的模型与仅不使用 Wise-IoUv3 的模型对比表明，引入 Wise-IoUv3 可以有效提高精确率和召回率，说明采用动态非单调聚焦机制强化了对低冗余、多尺度、细节特征的聚焦，从而提高了检测性能。引入 5 个模块改进的 YOLO-GESCW 模型参数量仅为 0.98 M、模型大小仅为 2.09 MB、浮点计算量仅为 3.4 G，较原模型 YOLOv8n 分别下降约 67.44%、65.10%、58.02%，精确率为 93.6%、召回率为 93.0%、平均精度均值为 98.1%，较原模型分别下降 1.1、3.4、0.7 个百分点，帧率为 106.79 帧/s，较原模型表现出更好的综合性能，在轻量化和检测精度平衡上较优。

### 对比试验

选取目前主流检测模型 YOLOv9t、YOLOv10n、YOLOv11n、YOLOv12n，在相同试验条件下训练模型与 YOLO-GESCW 进行性能对比，同时为客观评价改进的 YOLO-GESCW 模型，选择本领域 9 种相关模型进行对比分析，不同模型性能对比结果如下表所示。

![不同模型性能对比](../assets/paper-imgs/YOLO-GESCW/table2_comparison.png)

综合而言，改进后的模型计算资源消耗更少、模型更小、可部署性更优、检测速度更有优势，满足盛花期红花检测的精度需求和边缘设备部署要求。YOLO-GESCW 模型参数量较 YOLOv9t、YOLOv10n、YOLOv11n、YOLOv12n 分别降低约 50.25%、56.83%、62.02%、61.72%，浮点计算量较上述 4 种主流模型分别降低 55.3%、47.7%、46.0%、46.0%，同时参数量和计算量均低于本领域 9 种模型；模型大小仅为 2.09 MB；检测帧率为 106.79 帧/s，均比 4 种主流模型高。

### 特征可视化

采用 Grad-CAM（gradient-weighted class activation mapping）技术，选取盛花期红花图片分别对 YOLOv8n 与 YOLO-GESCW 的主干网络第 7、8、9 层进行特征图像可视化，结果如下图所示。

![特征热力图可视化对比](../assets/paper-imgs/YOLO-GESCW/fig7_heatmap.png)

通过对比可知，YOLOv8n 模型第 7 层网络对盛花期红花目标区域关注度不高，并且存在对非花朵区域的关注，相比之下 YOLO-GESCW 模型更关注目标花朵区域；YOLOv8n 模型第 8 层网络关注区域是背景特征信息，YOLO-GESCW 模型仍然关注目标盛花期红花区域特征；YOLOv8n 模型第 9 层网络只关注到部分目标边缘区域，然而 YOLO-GESCW 模型更关注全局目标区域。相比之下 YOLO-GESCW 模型能够准确地聚焦于图像中检测目标的区域，对非目标区域关注较少，这一表现更符合网络模型改进设计的预期目标。

### 边缘部署验证

为验证 YOLO-GESCW 的边缘部署性能，基于 NVIDIA Jetson Xavier NX 平台开展试验，边缘计算平台部分配置为：Ultralytics 为 8.3.162 版本，TensorRT 为 8.5.2.2 版本，Python 为 3.8.20 版本，Jetpack 为 5.1.1 版本，CUDA 为 11.4.315 版本，cuDNN 采用 8.6.0.166 版本，启用 20W-6core 模式。输入数据为实地拍摄的照片与视频（iPhone13 拍摄，视频 1080P/60FPS，MP4 格式）。分别使用改进前后未依赖 Pytorch 框架运行的 best.pt 文件，通过 ONNX Runtime 框架调用 GPU 的 CUDA 计算跨框架中间格式 best.onnx 文件，以及使用 TensorRT 加速，启用 FP16 半精度量化 best.engine 文件进行部署测试。YOLO-GESCW 模型的 best.pt、best.onnx、best.engine 三个部署文件大小分别是 2.09、3.95、3.48 MB，较原 YOLOv8n 模型三个部署文件 best.pt（5.99 MB）、best.onnx(11.6 MB)、best.engine(7.39 MB)，分别降低约 65.1%、66.0%、52.9%。

4 种典型场景下的检测性能如下表所示，其中帧率计算方法为 FPS = 1/(Tpre + Tin + Tpost) × 1000，YOLO-GESCW 模型的 best.engine 文件在测试中检测速度、推理速度最优。小尺度 - 强光 - 重叠遮挡场景下，best.engine 模型帧率 43.48 帧/s、推理耗时 0.007 1 s；弱光 - 无遮挡场景下，帧率 32.15 帧/s，推理耗时 0.007 1 s；多株连片红花场景下，平均帧率 51.81 帧/s，平均推理耗时 0.007 2 s；单株红花晃动场景下，平均帧率 52.36 帧/s，平均推理耗时 0.007 2 s。

![模型部署性能对比](../assets/paper-imgs/YOLO-GESCW/table3_deployment.png)

部署试验表明，YOLO-GESCW 模型的 best.engine 文件在边缘设备上具备"小体积、高速度、高精度"的综合优势。

## 优点和创新点

个人认为，本文有如下一些优点和创新点可供参考学习：

1. 五个改进模块分别从卷积结构、注意力机制、多尺度特征融合、细节捕捉和损失函数五个维度协同优化，消融试验给出单模块与组合改进下 mAP、参数量与 FLOPs 的变化，模块增益清晰可归因。
2. 在 NVIDIA Jetson Xavier NX 边缘设备上完成部署验证，best.engine 文件仅 3.48 MB、单株晃动场景平均帧率 52.36 帧/s，实现轻量化与实时性的平衡，工程可用性说服力强。
3. 采用 Grad-CAM 技术对主干网络第 7、8、9 层进行特征可视化，将检测性能的改善归因到各模块对目标区域的聚焦能力提升，可视化证据链完整。
