## 研究动机

棉花顶芽识别是精准农业中棉田智能管理的重要问题，表现为在自然光环境下对密集生长的棉花植株顶端新生芽点进行实时定位与计数，导致人工巡检效率低、误判率高会直接影响水肥调控与产量预测的准确性。现有基于深度学习的检测方法虽然取得一定进展，然而存在三类局限。其一是**复杂背景干扰严重**：棉田环境中叶片遮挡、光照变化与土壤背景造成大量误检，传统方法依赖手工特征难以区分顶芽与相似形态的嫩叶；其二是**小目标检测性能不足**：棉花顶芽在航拍或远距离图像中仅占几十个像素，YOLOv8/v11 等主流检测器在下采样过程中容易丢失细节，造成漏检；其三是**推理速度受限**：田间部署需要边缘设备实时处理，高分辨率输入下的计算负担使帧率下降，无法满足农事操作的时效性要求。暂未有工作在同一框架内同时解决棉田复杂背景干扰、顶芽小目标漏检与边缘端实时推理这三个瓶颈。

## 文章贡献

针对棉田复杂背景干扰、棉花顶芽小目标漏检与边缘端实时推理的问题，本文提出了 DFR-SN-YOLO，一种面向棉花顶芽识别的改进 YOLO 检测器。其核心是双特征共振模块 DFR 与稀疏连接网络 SN 两大组件：首先 DFR 嵌入颈部特征金字塔，通过双路径特征共振机制增强多尺度特征表达，一路提取高频细节保留顶芽边缘信息，另一路聚合低频语义抑制背景噪声，二者经共振融合后强化小目标响应；接着 SN 替换骨干部分卷积层，引入通道级稀疏连接剪枝冗余计算通路，在保持特征表达能力的同时降低参数量与 GFLOPs；最终设计面向边缘部署的轻量化配置，调整输入分辨率与批量大小以平衡精度与速度。实验表明，DFR-SN-YOLO 在自建棉花顶芽数据集上的 mAP 达到 87.3%，较 YOLOv8 提升 4.2 个百分点，推理速度在 Jetson Xavier 上达 28 FPS，满足田间实时检测需求。

## 本文方法

### 整体架构

DFR-SN-YOLO 以 YOLOv8n 为基线，保持 backbone-neck-head 的三段式结构，改进集中在骨干网络的稀疏连接设计与颈部的双特征共振模块。整体框架如下图所示。

![DFR-SN-YOLO 整体框架](../assets/paper-imgs/dfrsn_yolo/fig1.png)

骨干采用改进的 CSPDarknet，部分 C2f 模块替换为带通道稀疏连接的 SC2f；颈部引入 DFR 模块增强多尺度特征融合；检测头保持解耦结构输出顶芽检测框。各组件功能如下表所示。

| 组件 | 模块 | 功能 |
| --- | --- | --- |
| Backbone | SC2f × N + Sparse Conv | 特征提取，通道级稀疏剪枝降低计算量 |
| Neck | DFR × 3 + UP + Concat | 多尺度特征融合，双路径共振增强小目标 |
| Head | 解耦检测头 | 输出类别与位置（棉花顶芽/非顶芽） |
| 轻量化 | 通道剪枝 + 低分辨率输入 | 适配边缘设备部署 |

骨干输出的三尺度特征（C3、C4、C5）经 DFR 增强的 P3、P4、P5 层融合后送入检测头，DFR 与 SC2f 的产物均在骨干与颈部内部完成，对检测头透明。

### 双特征共振模块

DFR 的目标是在特征金字塔的每一层同时保留高频细节与低频语义，通过双路径并行处理再经共振融合强化有效特征。其结构由特征分解、双路提取、共振融合三步构成。输入特征 $F_{in} \in \mathbb{R}^{C \times H \times W}$ 先经高斯模糊分解为高频与低频两支，分解公式如下：

$$F_{high} = F_{in} - \mathrm{Gauss}(F_{in}, \sigma)$$

其中 $\mathrm{Gauss}(\cdot, \sigma)$ 表示标准差为$\sigma$的高斯模糊操作，$F_{high} \in \mathbb{R}^{C \times H \times W}$为高频细节分支，包含顶芽边缘与纹理信息；$F_{low} = \mathrm{Gauss}(F_{in}, \sigma) \in \mathbb{R}^{C \times H \times W}$为低频语义分支，包含目标整体形状与上下文。直观上，高频支突出细微结构，低频支抑制噪声干扰，二者分离后进入独立处理。

高频分支走轻量化 1×1 卷积压缩通道，再经 3×3 卷积增强局部感受野，计算为：

$$F_{high}' = \phi_3(1 \times 1, \phi_1(3 \times 3, F_{high}))$$

其中$\phi_1$与$\phi_3$分别表示 1×1 与 3×3 卷积映射；$F_{high}' \in \mathbb{R}^{C' \times H \times W}$，$C' < C$为压缩后的细节特征。低频分支则采用空洞卷积扩大感受野并聚合上下文，空洞率设为{2, 4, 6}，计算为：

$$F_{low}' = \mathrm{ASPP}(F_{low}, \{2, 4, 6\})$$

其中$\mathrm{ASPP}(\cdot)$表示多比例空洞空间池化操作，$F_{low}' \in \mathbb{R}^{C' \times H \times W}$为聚合后的语义特征。两路特征经通道拼接后进入共振融合，融合过程表示为：

$$F_{out} = \alpha \otimes F_{high}' \oplus \beta \otimes F_{low}'$$

其中$\alpha, \beta \in \mathbb{R}^{1 \times 1 \times 1}$为可学习的共振权重，$\otimes$表示逐元素相乘，$\oplus$表示拼接后再经 1×1 卷积降维至原始通道数。这等价于根据特征重要性动态调整高低频成分的贡献比例，自适应地增强顶芽区域响应。DFR 嵌入颈部的每个特征融合层，其输出流向下一层的 Concat 操作，实现跨尺度共振。

### 稀疏连接卷积

SC2f 的目标是削减骨干网络中的冗余计算通路，在保持特征表达能力的前提下降低参数量与 GFLOPs。现有 C2f 模块中所有通道均参与卷积运算，造成大量无效计算。SC2f 引入通道级稀疏掩码，只保留重要通路的特征传播。设输入通道数为$C_{in}$，输出通道数为$C_{out}$，标准 C2f 的参数量为：

$$P_{C2f} = k \times k \times C_{in} \times C_{out}$$

其中$k$为卷积核尺寸（通常为 3）。SC2f 先经通道重要性评分筛选出$s$比例的关键通道，$s \in (0, 1]$为稀疏率，筛选后的参数量计算为：

$$P_{SC2f} = s \times P_{C2f}$$

给出一个简单的例子，假设某 SC2f 层输入$C_{in} = 256$、输出$C_{out} = 512$、核尺寸$k = 3$、稀疏率$s = 0.5$。1. 标准 C2f 参数量$P_{C2f} = 3 \times 3 \times 256 \times 512 = 1179648$；2. SC2f 仅保留 50% 关键通路，$P_{SC2f} = 0.5 \times 1179648 = 589824$；3. 二者之比约为 50%。可以看到，通过通道级稀疏连接，能在几乎不损失精度的情况下大幅压缩模型规模。

通道重要性评分基于预训练权重的 L1 范数，计算公式为：

$$score_c = \sum_{i,j} |W_{c,i,j}|$$

其中$W_{c,i,j}$为第$c$个输出通道的卷积核权重，$i,j$为空间维度。评分高的通道被保留，低的被剪枝。SC2f 的整体流程为：输入特征经两组 1×1 卷积分叉，一组走稀疏卷积，另一组走标准卷积，二者 Concat 后经 1×1 卷积整合。其输出接下一个 SC2f 或下采样层，逐步构建深层语义表示。

### 标签分配策略

DFR-SN-YOLO 采用 Task-Aligned Assigner 进行正负样本分配，兼顾分类得分与定位质量。设预测框与 GT 框的 IoU 为$u$，分类置信度为$t$，对齐因子计算为：

$$a = t^\alpha \times u$$

其中$\alpha = 4$为平衡因子，用于放大分类得分的影响。IoU 阈值设为 0.15，对齐因子$a > 0.5$的样本标记为正样本，其余为负样本。这种分配方式避免了对齐不良的硬负样本干扰训练，提升收敛稳定性。

### 损失函数

DFR-SN-YOLO 采用 CIoU Loss 作为定位损失，VFL Loss 作为分类损失。CIoU Loss 考虑重叠面积、中心点距离与长宽比一致性，计算为：

$$L_{CIoU} = 1 - \mathrm{IoU} + \frac{\rho^2(b, b^{GT})}{c^2} + \beta \left| \tan^{-1}\frac{w}{h} - \tan^{-1}\frac{w^{GT}}{h^{GT}} \right|$$

其中$\rho(\cdot)$为欧氏距离，$c$为对角线长度，$\beta$为加权系数，$b, b^{GT}$分别为预测框与 GT 框的中心点。直观上，CIoU 比 IoU 更快收敛，尤其在框重叠较小时表现更优。总损失为加权和：

$$L_{total} = \lambda_{box} L_{CIoU} + \lambda_{cls} L_{VFL}$$

其中$\lambda_{box} = 7.5$、$\lambda_{cls} = 1.0$为超参数。直观上，平衡因子的设定使分类与定位损失在训练初期保持均衡，避免某一主导另一，提升收敛稳定性。

### 数据增强策略

DFR-SN-YOLO 采用 Mosaic 与 MixUp 混合增强策略，提升模型泛化能力。Mosaic 将四张图像随机缩放、拼接为一，增加背景多样性与目标尺度变化；MixUp 则线性插值两张图像及其标签，计算为：

$$\tilde{x} = \lambda x_i + (1 - \lambda) x_j, \quad \tilde{y} = \lambda y_i + (1 - \lambda) y_j$$

其中$\lambda \sim \mathrm{Beta}(0.4, 0.4)$为采样参数，$x_i, x_j$为输入图像，$y_i, y_j$为对应标注。直观上，MixUp 生成软标签，缓解过拟合，尤其对小目标有益。训练前 10 个 epoch 启用 Mosaic，后续关闭转为单图训练，保证最终精度。

## 实验结果

### 实验设置

自建棉花顶芽数据集包含 3200 张田间图像，分辨率从 640×640 到 1280×1280 不等，标注类别为棉花顶芽与非顶芽（叶片、土壤、杂草等）。数据集划分比例为 train/val/test = 7/1.5/1.5，共约 2240/480/480 张。评测指标为 mAP@0.5:0.95、AP50、AP75、Params、GFLOPs 与 FPS。除速度测试在 Jetson Xavier AGX（边缘设备）上进行外，其余训练与评估均在 NVIDIA RTX 4090 上完成；网络训练 300 个 epoch，优化器为 SGD，动量 0.937、权重衰减 0.0005、batch size 为 16、初始学习率 0.01，采用 Cosine Annealing 调度。

### 定性效果对比

棉田复杂背景条件下基线与本文方法的检测结果可视化如下图所示。

![棉田复杂背景下检测结果对比](../assets/paper-imgs/dfrsn_yolo/fig2.png)

图中蓝框为 YOLOv8n 的预测结果，红框为 DFR-SN-YOLO 的预测结果。基线在密集叶片遮挡区域出现漏检，且对光照变化敏感产生误检；DFR-SN-YOLO 成功补回被遮挡的顶芽目标，并对相似形态的嫩叶给出正确分类，表明 DFR 的双特征共振机制有效增强了背景鲁棒性。

### 定量对比

DFR-SN-YOLO 与多种主流检测器在棉花顶芽数据集上的对比如同一张精度 - 参数量散点图所示，完整数字见下表。

![与各检测器的 mAP 与 Params 对比](../assets/paper-imgs/dfrsn_yolo/table1.png)

DFR-SN-YOLO 的 mAP@0.5:0.95 达 87.3%，较 YOLOv8n 的 83.1% 提升 4.2 个百分点，较 YOLOv11n 的 84.5% 提升 2.8 个百分点；AP50 达 92.1%，高于 YOLOv8n 的 88.4% 与 YOLOv11n 的 89.7%；Params 仅 3.2 M，比 YOLOv8n 的 3.5 M 减少 8.6%，GFLOPs 为 8.9，比 YOLOv8n 的 10.1 降低 12%。可见在保持轻量化的同时取得了更高的检测精度。与 SOTA 小目标检测方法的对比如下表所示。

![与小目标检测方法的 AP 对比](../assets/paper-imgs/dfrsn_yolo/table2.png)

DFR-SN-YOLO 的 AP_S（小目标 AP）达 76.8%，显著高于 CenterNet 的 68.4% 与 SAHI 的 71.2%，验证了 DFR 对小目标特征的增强效果。

### 消融实验

以 YOLOv8n 为基线，DFR、SC2f、稀疏率$s$的消融如下表所示。

![DFR、SC2f 与稀疏率消融](../assets/paper-imgs/dfrsn_yolo/table3.png)

单独启用 DFR 后 mAP 提升 2.1 个百分点，Params 基本不变；单独启用 SC2f（$s = 0.6$）后 Params 减少 15%、GFLOPs 降低 12%，mAP 仅回落 0.4 个百分点；二者叠加后 mAP 达 86.5%，Params 减少 10%，说明 DFR 带来的精度增益能够补偿 SC2f 的轻微损失。稀疏率$s$的影响如下表所示。

![稀疏率 s 的消融](../assets/paper-imgs/dfrsn_yolo/table4.png)

$s$取 0.6 时取得最优的 86.8%/3.1M 折中，过小的$s$（如 0.4）导致精度大幅下降，过大的$s$（如 0.8）则压缩收益有限，说明 40% 的通道剪枝是性能与效率的平衡点。

## 优点和创新点

个人认为，本文有如下一些优点和创新点可供参考学习：

1. 提出双特征共振模块 DFR，通过高频细节与低频语义的双路并行再动态融合，解决棉田复杂背景下的顶芽小目标检测难题，mAP 提升 2.1 个百分点。
2. 设计通道级稀疏连接 SC2f，基于权重 L1 范数筛选关键通路剪枝冗余，稀疏率$s = 0.6$时参数减少 15% 且精度仅微降 0.4%，工程实用性强。
3. 实验覆盖自建棉花顶芽数据集与边缘设备部署测试，Jetson Xavier 上 28 FPS 满足实时性要求，说服力强。
