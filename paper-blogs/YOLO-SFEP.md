## 研究动机

番茄穴盘苗缺苗检测是设施农业中育苗智能管理的重要问题，表现为在自然光波动、阴影遮挡与土壤背景共存条件下对番茄幼苗缺苗位置进行实时定位与计数，导致人工巡检效率低、补苗不及时会直接影响出苗率评估与产量损失预测的准确性。现有基于深度学习的检测方法虽然取得一定进展，然而存在三类局限。其一是**光照变化干扰严重**：温室环境中自然光随时间变化造成亮度不均，传统方法依赖固定阈值难以适应动态光照条件；其二是**小目标检测性能不足**：番茄幼苗在远距离或密集种植情况下仅占几十个像素，YOLOv8/v11 等主流检测器在下采样过程中容易丢失细节，造成漏检；其三是**实时性受限**：育苗场部署需要边缘设备实时处理，高分辨率输入下的计算负担使帧率下降，无法满足大规模巡检的时效性要求。暂未有工作在同一框架内同时解决温室光照变化干扰、幼苗小目标漏检与边缘端实时推理这三个瓶颈。

## 文章贡献

针对温室光照变化干扰、番茄幼苗小目标漏检与边缘端实时推理的问题，本文提出了 YOLO-SFEP，一种面向自然光环境下番茄缺苗检测的改进 YOLO 检测器。其核心是特征增强金字塔 FEP 与自适应光照模块 AIL 两大组件：首先 FEP 嵌入颈部特征金字塔，通过多尺度特征增强机制提升不同尺度幼苗的特征表达，对小尺度幼苗分配更高感受野，对大尺度幼苗抑制冗余响应；接着 AIL 替换骨干部分卷积层，引入通道级自适应增益调整光照敏感通道的响应，在保持特征表达能力的前提下降低光照变化影响；最终设计面向嵌入式部署的轻量化配置，调整输入分辨率与批量大小以平衡精度与速度。实验表明，YOLO-SFEP 在自建番茄缺苗检测数据集上的 mAP 达到 91.2%，较 YOLOv8 提升 4.5 个百分点，推理速度在 Jetson Nano 上达 25 FPS，满足育苗场实时监测需求。

## 本文方法

### 整体架构

YOLO-SFEP 以 YOLOv8n 为基线，保持 backbone-neck-head 的三段式结构，改进集中在骨干网络的自适应光照设计与颈部的特征增强金字塔模块。整体框架如下图所示。

![YOLO-SFEP 整体框架](../assets/paper-imgs/yolo_sfep/fig1.png)

骨干采用改进的 CSPDarknet，部分 C2f 模块替换为带自适应光照增益的 AL2f；颈部引入 FEP 模块增强多尺度特征融合；检测头保持解耦结构输出缺苗检测框。各组件功能如下表所示。

| 组件 | 模块 | 功能 |
| --- | --- | --- |
| Backbone | AL2f × N + Adaptive Gain | 特征提取，通道级增益调整光照敏感度 |
| Neck | FEP × 3 + UP + Concat | 多尺度特征融合，特征增强增强小目标 |
| Head | 解耦检测头 | 输出类别与位置（缺苗/有苗） |
| 轻量化 | 增益压缩 + 低分辨率输入 | 适配嵌入式部署 |

骨干输出的三尺度特征（C3、C4、C5）经 FEP 增强的 P3、P4、P5 层融合后送入检测头，FEP 与 AL2f 的产物均在骨干与颈部内部完成，对检测头透明。

### 特征增强金字塔模块

FEP 的目标是在特征金字塔的每一层根据目标尺度动态调整特征增强强度，对小尺度幼苗分配更高增强系数，对大尺度幼苗抑制冗余响应。其结构由尺度估计、增强生成、特征增强三步构成。输入特征 $F_{in} \in \mathbb{R}^{C \times H \times W}$ 先经多尺度池化得到三个尺度的全局描述符，估计公式如下：

$$G_s = \mathrm{AvgPool}_s(F_{in}), \quad s \in \{8, 16, 32\}$$

其中$\mathrm{AvgPool}_s$表示核大小为$s$的平均池化操作，$G_s \in \mathbb{R}^{C \times 1 \times 1}$为第$s$尺度的全局描述符。直观上，小尺度池化保留高频细节，大尺度池化聚合低频语义，三者结合覆盖全尺度范围。

尺度描述符经共享的全连接层映射为增强系数，计算为：

$$e_c = \sigma(W_2(\delta(W_1([G_8; G_{16}; G_{32}]))))$$

其中$[;\cdot]$表示通道拼接，$\delta(\cdot)$为 ReLU 激活，$W_1, W_2$为全连接权重，$\sigma(\cdot)$为 Sigmoid 函数；$e_c \in \mathbb{R}^C$为最终通道增强系数向量。这等价于根据多尺度上下文自适应学习每个通道的增强强度。增强过程表示为：

$$F_{out} = e_c \otimes F_{in} + F_{in}$$

其中$\otimes$表示通道维度的逐元素相乘，加号表示残差连接。直观上，增强系数高的通道对应小目标特征，被放大；增强系数低的通道对应背景或大目标冗余信息，保持原状。FEP 嵌入颈部的每个特征融合层，其输出流向下一层的 Concat 操作，实现跨尺度感知。

### 自适应光照增益模块

AL2f 的目标是削减骨干网络中对光照敏感通道的响应波动，在保持特征表达能力的同时降低光照变化影响。现有 C2f 模块中所有通道均平等参与卷积运算，造成光照敏感通道过度响应亮度变化。AL2f 引入通道级自适应增益，根据局部光照统计动态调整增益系数，计算为：

$$g_c = \sigma(W_g(\mu_c, \sigma_c))$$

其中$\mu_c, \sigma_c$分别为第$c$通道的均值与标准差，$W_g(\cdot)$为轻量级增益网络，$\sigma(\cdot)$为 Sigmoid 函数；$g_c \in \mathbb{R}$为最终增益系数。直观上，光照敏感通道（如边缘检测通道）被降低增益，鲁棒通道（如纹理通道）被保持增益。

给出一个简单的例子，假设某 AL2f 层输入通道数$C = 256$，其中 50 个通道对光照敏感。1. 标准 C2f 所有通道平等响应，敏感通道在强光下过曝、弱光下欠曝；2. AL2f 对敏感通道平均增益$g = 0.6$，对鲁棒通道$g = 1.0$；3. 光照变化导致的特征波动减少 40%。可以看到，通过通道级自适应增益，能在几乎不增加计算量的情况下显著提升光照鲁棒性。

增益网络采用全局平均池化加 1×1 卷积的极简设计，参数量仅 0.5K。AL2f 的整体流程为：输入特征经两组 1×1 卷积分叉，一组走自适应增益，另一组走标准卷积，二者 Concat 后经 1×1 卷积整合。其输出接下一个 AL2f 或下采样层，逐步构建深层语义表示。

### 标签分配策略

YOLO-SFEP 采用 Task-Aligned Assigner 进行正负样本分配，兼顾分类得分与定位质量。设预测框与 GT 框的 IoU 为$u$，分类置信度为$t$，对齐因子计算为：

$$a = t^\alpha \times u$$

其中$\alpha = 4$为平衡因子，用于放大分类得分的影响。IoU 阈值设为 0.15，对齐因子$a > 0.5$的样本标记为正样本，其余为负样本。这种分配方式避免了对齐不良的硬负样本干扰训练，提升收敛稳定性。

### 损失函数

YOLO-SFEP 采用 CIoU Loss 作为定位损失，VFL Loss 作为分类损失。CIoU Loss 考虑重叠面积、中心点距离与长宽比一致性，计算为：

$$L_{CIoU} = 1 - \mathrm{IoU} + \frac{\rho^2(b, b^{GT})}{c^2} + \beta \left| \tan^{-1}\frac{w}{h} - \tan^{-1}\frac{w^{GT}}{h^{GT}} \right|$$

其中$\rho(\cdot)$为欧氏距离，$c$为对角线长度，$\beta$为加权系数，$b, b^{GT}$分别为预测框与 GT 框的中心点。直观上，CIoU 比 IoU 更快收敛，尤其在框重叠较小时表现更优。总损失为加权和：

$$L_{total} = \lambda_{box} L_{CIoU} + \lambda_{cls} L_{VFL}$$

其中$\lambda_{box} = 7.5$、$\lambda_{cls} = 1.0$为超参数。

### 数据增强策略

YOLO-SFEP 采用 Mosaic 与 MixUp 混合增强策略，提升模型泛化能力。Mosaic 将四张图像随机缩放、拼接为一，增加背景多样性与目标尺度变化；MixUp 则线性插值两张图像及其标签，计算为：

$$\tilde{x} = \lambda x_i + (1 - \lambda) x_j, \quad \tilde{y} = \lambda y_i + (1 - \lambda) y_j$$

其中$\lambda \sim \mathrm{Beta}(0.4, 0.4)$为采样参数，$x_i, x_j$为输入图像，$y_i, y_j$为对应标注。直观上，MixUp 生成软标签，缓解过拟合，尤其对小目标有益。训练前 10 个 epoch 启用 Mosaic，后续关闭转为单图训练，保证最终精度。

## 实验结果

### 实验设置

自建番茄缺苗检测数据集包含 5200 张温室图像，分辨率从 640×640 到 1280×1280 不等，标注类别为缺苗位置与有苗位置（幼苗、土壤、穴盘边缘等）。数据集划分比例为 train/val/test = 7/1.5/1.5，共约 3640/780/780 张。评测指标为 mAP@0.5:0.95、AP50、AP75、Params、GFLOPs 与 FPS。除速度测试在 Jetson Nano（嵌入式设备）上进行外，其余训练与评估均在 NVIDIA RTX 4090 上完成；网络训练 300 个 epoch，优化器为 SGD，动量 0.937、权重衰减 0.0005、batch size 为 16、初始学习率 0.01，采用 Cosine Annealing 调度。

温室复杂光照条件下基线与本文方法的检测结果可视化如下图所示。

![温室复杂光照下检测结果对比](../assets/paper-imgs/yolo_sfep/fig2.png)

图中蓝框为 YOLOv8n 的预测结果，红框为 YOLO-SFEP 的预测结果。基线在强逆光与阴影区域出现漏检，且对穴盘边缘产生误检；YOLO-SFEP 成功补回被遮挡的缺苗位置，并对相似形状的穴盘边缘给出正确过滤，表明 AIL 的自适应增益机制有效增强了光照鲁棒性。

### 定量对比

YOLO-SFEP 与多种主流检测器在番茄缺苗检测数据集上的对比如同一张精度 - 参数量散点图所示，完整数字见下表。

![与各检测器的 mAP 与 Params 对比](../assets/paper-imgs/yolo_sfep/table1.png)

YOLO-SFEP 的 mAP@0.5:0.95 达 91.2%，较 YOLOv8n 的 86.7% 提升 4.5 个百分点，较 YOLOv11n 的 88.9% 提升 2.3 个百分点；AP50 达 94.5%，高于 YOLOv8n 的 91.2% 与 YOLOv11n 的 92.3%；Params 仅 2.8 M，比 YOLOv8n 的 3.5 M 减少 20%，GFLOPs 为 7.5，比 YOLOv8n 的 10.1 降低 25.7%。可见在保持轻量化的同时取得了更高的检测精度。与 SOTA 小目标检测方法的对比如下表所示。

![与小目标检测方法的 AP 对比](../assets/paper-imgs/yolo_sfep/table2.png)

YOLO-SFEP 的 AP_S（小目标 AP）达 81.5%，显著高于 CenterNet 的 72.3% 与 SAHI 的 75.6%，验证了 FEP 对小目标特征的增强效果。

### 消融实验

以 YOLOv8n 为基线，FEP、AL2f、增益复杂度$D$的消融如下表所示。

![FEP、AL2f 与增益复杂度消融](../assets/paper-imgs/yolo_sfep/table3.png)

单独启用 FEP 后 mAP 提升 2.5 个百分点，Params 基本不变；单独启用 AL2f（$D = 2$）后 Params 减少 10%、GFLOPs 降低 12%，mAP 仅回落 0.2 个百分点；二者叠加后 mAP 达 90.3%，Params 减少 6%，说明 FEP 带来的精度增益能够补偿 AL2f 的轻微损失。增益复杂度$D$的影响如下表所示。

![增益复杂度 D 的消融](../assets/paper-imgs/yolo_sfep/table4.png)

$D$取 2 时取得最优的 90.8%/2.7M 折中，过小的$D$（如 1）导致增益调节能力不足，过大的$D$（如 4）则计算开销增加明显，说明 2 层全连接是性能与效率的平衡点。

## 优点和创新点

个人认为，本文有如下一些优点和创新点可供参考学习：

1. 提出特征增强金字塔模块 FEP，通过多尺度池化估计与自适应增强系数分配，解决温室复杂光照下的小目标检测难题，mAP 提升 2.5 个百分点。
2. 设计通道级自适应增益 AL2f，基于局部光照统计动态调整增益系数，增益复杂度$D = 2$时 GFLOPs 降低 12% 且精度仅微降 0.2%，工程实用性强。
3. 实验覆盖自建番茄缺苗检测数据集与嵌入式部署测试，Jetson Nano 上 25 FPS 满足实时性要求，说服力强。
