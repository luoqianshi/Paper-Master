## 研究动机

红花天然环境下的花朵识别是精准农业中花田智能监测的重要问题，表现为在复杂光照、风动干扰与背景杂草共存条件下对红花花朵进行实时定位与计数，导致人工采收效率低、成熟度判断不准会直接影响药材产量评估与采收时机的选择。现有基于深度学习的检测方法虽然取得一定进展，然而存在三类局限。其一是**背景干扰严重**：红花田环境中绿色茎叶、土壤背景与其他作物造成大量误检，传统方法依赖颜色特征难以区分红花与相似红色的野花；其二是**小目标检测性能不足**：红花花朵在远距离或遮挡情况下仅占几十个像素，YOLOv8/v11 等主流检测器在下采样过程中容易丢失细节，造成漏检；其三是**实时性受限**：田间部署需要边缘设备实时处理，高分辨率输入下的计算负担使帧率下降，无法满足农事操作的时效性要求。暂未有工作在同一框架内同时解决红花田复杂背景干扰、花朵小目标漏检与边缘端实时推理这三个瓶颈。

## 文章贡献

针对红花田复杂背景干扰、花朵小目标漏检与边缘端实时推理的问题，本文提出了 YOLO-SSAR，一种面向自然环境下红花检测的改进 YOLO 检测器。其核心是尺度感知重加权模块 SAR 与稀疏注意力机制 SSA 两大组件：首先 SAR 嵌入颈部特征金字塔，通过多尺度通道重加权增强不同尺度花朵的特征表达，对小目标分配更高权重，对大目标抑制冗余响应；接着 SSA 替换骨干部分自注意力层，引入空间稀疏采样降低计算复杂度，在保持长程依赖建模能力的同时减少 GFLOPs；最终设计面向移动端的轻量化配置，调整输入分辨率与批量大小以平衡精度与速度。实验表明，YOLO-SSAR 在自建红花检测数据集上的 mAP 达到 89.7%，较 YOLOv8 提升 3.8 个百分点，推理速度在 Jetson Orin 上达 32 FPS，满足田间实时监测需求。

## 本文方法

### 整体架构

YOLO-SSAR 以 YOLOv8n 为基线，保持 backbone-neck-head 的三段式结构，改进集中在骨干网络的稀疏注意力设计与颈部的尺度感知重加权模块。整体框架如下图所示。

![YOLO-SSAR 整体框架](../assets/paper-imgs/yolo_ssar/fig1.png)

骨干采用改进的 CSPDarknet，部分 C2f 模块替换为带稀疏注意力的 SA2f；颈部引入 SAR 模块增强多尺度特征融合；检测头保持解耦结构输出花朵检测框。各组件功能如下表所示。

| 组件 | 模块 | 功能 |
| --- | --- | --- |
| Backbone | SA2f × N + Sparse Attn | 特征提取，空间稀疏采样降低计算量 |
| Neck | SAR × 3 + UP + Concat | 多尺度特征融合，尺度感知重加权增强小目标 |
| Head | 解耦检测头 | 输出类别与位置（红花/非红花） |
| 轻量化 | 稀疏采样 + 低分辨率输入 | 适配移动端部署 |

骨干输出的三尺度特征（C3、C4、C5）经 SAR 增强的 P3、P4、P5 层融合后送入检测头，SAR 与 SA2f 的产物均在骨干与颈部内部完成，对检测头透明。

### 尺度感知重加权模块

SAR 的目标是在特征金字塔的每一层根据目标尺度动态调整通道权重，对小目标分配更高权重，对大目标抑制冗余响应。其结构由尺度估计、权重生成、特征重加权三步构成。输入特征 $F_{in} \in \mathbb{R}^{C \times H \times W}$ 先经多尺度池化得到三个尺度的全局描述符，估计公式如下：

$$G_s = \mathrm{AvgPool}_s(F_{in}), \quad s \in \{8, 16, 32\}$$

其中$\mathrm{AvgPool}_s$表示核大小为$s$的平均池化操作，$G_s \in \mathbb{R}^{C \times 1 \times 1}$为第$s$尺度的全局描述符。直观上，小尺度池化保留高频细节，大尺度池化聚合低频语义，三者结合覆盖全尺度范围。

尺度描述符经共享的全连接层映射为通道权重，计算为：

$$w_c = \sigma(W_2(\delta(W_1([G_8; G_{16}; G_{32}]))))$$

其中$[;\cdot]$表示通道拼接，$\delta(\cdot)$为 ReLU 激活，$W_1, W_2$为全连接权重，$\sigma(\cdot)$为 Sigmoid 函数；$w_c \in \mathbb{R}^C$为最终通道权重向量。这等价于根据多尺度上下文自适应学习每个通道的重要性。重加权过程表示为：

$$F_{out} = w_c \otimes F_{in}$$

其中$\otimes$表示通道维度的逐元素相乘。直观上，权重高的通道对应小目标特征，被放大；权重低的通道对应背景或大目标冗余信息，被抑制。SAR 嵌入颈部的每个特征融合层，其输出流向下一层的 Concat 操作，实现跨尺度感知。

### 稀疏注意力机制

SA2f 的目标是削减骨干网络中自注意力机制的计算开销，在保持长程依赖建模能力的同时降低 GFLOPs。现有 Self-Attention 的计算复杂度为$O(N^2)$，其中$N = H \times W$为特征图像素数，对于高分辨率输入计算负担巨大。SA2f 引入空间稀疏采样，只计算部分关键位置的注意力，计算复杂度降为$O(k \times N)$，$k \ll N$为采样点数。

给出一个简单的例子，假设某 SA2f 层特征图$H = W = 56$，总像素$N = 3136$。1. 标准 Self-Attention 计算$3136^2 \approx 9.8 \times 10^6$次乘法；2. SA2f 仅采样$k = 64$个关键点，计算$64 \times 3136 \approx 2.0 \times 10^5$次乘法；3. 计算量减少约 98%。可以看到，通过空间稀疏采样，能在几乎不损失精度的情况下大幅降低计算成本。

关键点选择基于预计算的查询向量$L1$范数排序，计算公式为：

$$score_i = \sum_{j=1}^C |Q_{i,j}|$$

其中$Q_{i,j}$为第$i$个位置的$j$维查询向量分量，$C$为通道数。评分高的位置被选为关键点，其余跳过。SA2f 的整体流程为：输入特征经 1×1 卷积生成 Query、Key、Value，对 Key 与 Value 进行稀疏采样，再计算 Query 与采样 Key 的注意力图，最后加权聚合 Value。其输出接下一个 SA2f 或下采样层，逐步构建深层语义表示。

### 标签分配策略

YOLO-SSAR 采用 Task-Aligned Assigner 进行正负样本分配，兼顾分类得分与定位质量。设预测框与 GT 框的 IoU 为$u$，分类置信度为$t$，对齐因子计算为：

$$a = t^\alpha \times u$$

其中$\alpha = 4$为平衡因子，用于放大分类得分的影响。IoU 阈值设为 0.15，对齐因子$a > 0.5$的样本标记为正样本，其余为负样本。这种分配方式避免了对齐不良的硬负样本干扰训练，提升收敛稳定性。

### 损失函数

YOLO-SSAR 采用 CIoU Loss 作为定位损失，VFL Loss 作为分类损失。CIoU Loss 考虑重叠面积、中心点距离与长宽比一致性，计算为：

$$L_{CIoU} = 1 - \mathrm{IoU} + \frac{\rho^2(b, b^{GT})}{c^2} + \beta \left| \tan^{-1}\frac{w}{h} - \tan^{-1}\frac{w^{GT}}{h^{GT}} \right|$$

其中$\rho(\cdot)$为欧氏距离，$c$为对角线长度，$\beta$为加权系数，$b, b^{GT}$分别为预测框与 GT 框的中心点。直观上，CIoU 比 IoU 更快收敛，尤其在框重叠较小时表现更优。总损失为加权和：

$$L_{total} = \lambda_{box} L_{CIoU} + \lambda_{cls} L_{VFL}$$

其中$\lambda_{box} = 7.5$、$\lambda_{cls} = 1.0$为超参数。

### 数据增强策略

YOLO-SSAR 采用 Mosaic 与 MixUp 混合增强策略，提升模型泛化能力。Mosaic 将四张图像随机缩放、拼接为一，增加背景多样性与目标尺度变化；MixUp 则线性插值两张图像及其标签，计算为：

$$\tilde{x} = \lambda x_i + (1 - \lambda) x_j, \quad \tilde{y} = \lambda y_i + (1 - \lambda) y_j$$

其中$\lambda \sim \mathrm{Beta}(0.4, 0.4)$为采样参数，$x_i, x_j$为输入图像，$y_i, y_j$为对应标注。直观上，MixUp 生成软标签，缓解过拟合，尤其对小目标有益。训练前 10 个 epoch 启用 Mosaic，后续关闭转为单图训练，保证最终精度。

## 实验结果

### 实验设置

自建红花检测数据集包含 4500 张田间图像，分辨率从 640×640 到 1280×1280 不等，标注类别为红花花朵与非红花（叶片、茎干、土壤、杂草等）。数据集划分比例为 train/val/test = 7/1.5/1.5，共约 3150/675/675 张。评测指标为 mAP@0.5:0.95、AP50、AP75、Params、GFLOPs 与 FPS。除速度测试在 Jetson Orin AGX（移动端设备）上进行外，其余训练与评估均在 NVIDIA RTX 4090 上完成；网络训练 300 个 epoch，优化器为 SGD，动量 0.937、权重衰减 0.0005、batch size 为 16、初始学习率 0.01，采用 Cosine Annealing 调度。

红花田复杂光照条件下基线与本文方法的检测结果可视化如下图所示。

图中蓝框为 YOLOv8n 的预测结果，红框为 YOLO-SSAR 的预测结果。基线在强逆光与阴影区域出现漏检，且对相似红色的野花产生误检；YOLO-SSAR 成功补回被遮挡的花朵目标，并对相似颜色的背景给出正确过滤，表明 SAR 的尺度感知机制有效增强了光照鲁棒性。

### 定量对比

YOLO-SSAR 与多种主流检测器在红花检测数据集上的对比如同一张精度 - 参数量散点图所示，完整数字见下表。

![与各检测器的 mAP 与 Params 对比](../assets/paper-imgs/yolo_ssar/table1.png)

YOLO-SSAR 的 mAP@0.5:0.95 达 89.7%，较 YOLOv8n 的 85.9% 提升 3.8 个百分点，较 YOLOv11n 的 87.2% 提升 2.5 个百分点；AP50 达 93.8%，高于 YOLOv8n 的 90.1% 与 YOLOv11n 的 91.5%；Params 仅 3.0 M，比 YOLOv8n 的 3.5 M 减少 14.3%，GFLOPs 为 8.2，比 YOLOv8n 的 10.1 降低 18.8%。可见在保持轻量化的同时取得了更高的检测精度。与 SOTA 小目标检测方法的对比如下表所示。

![与小目标检测方法的 AP 对比](../assets/paper-imgs/yolo_ssar/table2.png)

YOLO-SSAR 的 AP_S（小目标 AP）达 79.2%，显著高于 CenterNet 的 70.5% 与 SAHI 的 73.8%，验证了 SAR 对小目标特征的增强效果。

### 消融实验

以 YOLOv8n 为基线，SAR、SA2f、采样率$k$的消融如下表所示。

![SAR、SA2f 与采样率消融](../assets/paper-imgs/yolo_ssar/table3.png)

单独启用 SAR 后 mAP 提升 2.3 个百分点，Params 基本不变；单独启用 SA2f（$k = 64$）后 Params 减少 12%、GFLOPs 降低 15%，mAP 仅回落 0.3 个百分点；二者叠加后 mAP 达 88.9%，Params 减少 8%，说明 SAR 带来的精度增益能够补偿 SA2f 的轻微损失。采样率$k$的影响如下表所示。

![采样率 k 的消融](../assets/paper-imgs/yolo_ssar/table4.png)

$k$取 64 时取得最优的 89.2%/2.9M 折中，过小的$k$（如 32）导致精度大幅下降，过大的$k$（如 128）则压缩收益有限，说明 2% 的关键点采样比例是性能与效率的平衡点。

## 优点和创新点

个人认为，本文有如下一些优点和创新点可供参考学习：

1. 提出尺度感知重加权模块 SAR，通过多尺度池化估计与自适应通道权重分配，解决红花田复杂背景下的小目标检测难题，mAP 提升 2.3 个百分点。
2. 设计空间稀疏注意力 SA2f，基于查询向量 L1 范数筛选关键点采样，采样率$k = 64$时 GFLOPs 降低 15% 且精度仅微降 0.3%，工程实用性强。
3. 实验覆盖自建红花检测数据集与移动端部署测试，Jetson Orin 上 32 FPS 满足实时性要求，说服力强。
