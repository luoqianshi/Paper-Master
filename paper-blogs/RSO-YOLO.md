## 研究动机

自动驾驶场景下的小目标与遮挡目标检测是视觉感知的重要问题，表现为远距离行人与车辆往往只占几十个像素、复杂车流中目标频繁被部分或完全遮挡，导致漏检与误检直接抬升行车风险。以 YOLOv12 为代表的单阶段检测器虽然用区域注意力机制换来了超过 100 FPS 的处理速度，但在真实交通场景里仍面临三个并列的瓶颈：

1. **小目标检测性能欠佳**：城市道路中远处目标常占不到 32×32 像素，特征表示不足，难以被准确检测与识别；
2. **遮挡削弱检测可靠性**：频繁遮挡造成视觉信息大量丢失，既抬高误检率也抬高漏检率；
3. **精度与效率难以兼得**：车载系统必须高帧率可靠运行，对计算效率约束严格，现有算法常顾此失彼。

围绕这些问题的已有工作大多只解决其中一两个：Attention-YOLOv4 用通道注意力加残差块增强局部特征，却参数复杂、推理慢；YOLOv8-ghost-EMA 与 MEL-YOLO 走轻量化路线，小目标精度提升有限；RFCS-YOLO 改造 YOLOv7 颈部提升交通目标检测，计算复杂度又拖慢了速度；YOLO-BOS 用双层路由空间注意力与 Shape-IoU 损失增强遮挡检测，计算成本却限制了资源受限环境的部署。暂未有算法在同一框架内同时兼顾小目标检测、遮挡处理与轻量化设计三个目标，而真实自动驾驶场景中三者往往并发出现。

## 文章贡献

针对现有检测器难以同时应对小目标、遮挡与轻量化三重挑战的问题，本文提出了基于 YOLOv12 的增强模型 RSO-YOLO。其核心是「颈部换装 + 特征补偿 + 轻量检测头」三处协同改造。首先用带权双向特征金字塔 BiFPN 与空间到深度卷积 SPD-Conv 替换原颈部，在高效融合多尺度特征的同时于下采样中保留细粒度信息，并增开浅层 P2 检测头强化小目标感知；接着提出特征增强补偿模块 FECM，以五分支并行结构强化未遮挡区域的判别特征，再把高置信线索迁移到遮挡位置补偿缺失语义，并用指数放大增强弱目标响应；最终以全局跨维坐标模块 GCCM 为基础构建轻量检测头 GCCHead，通过分组与协同增强在降低计算复杂度的同时提升精度。实验表明，RSO-YOLO 在 SODA10M、BDD100K 与 FLIR ADAS 上较 YOLOv12 分别提升 mAP@0.5 达 8.0%、10.7% 与 7.2%，参数量减少 15.4%、模型复杂度下降 20%。

## 本文方法

### 整体架构

RSO-YOLO 沿用 YOLOv12 的 backbone-neck-head 三段式结构，改进覆盖后两段并延伸至损失配置，整体结构如下图所示。

![RSO-YOLO 网络结构图](../assets/paper-imgs/RSO-YOLO/fig2.png)

骨干保留 C3k2 与 A2C2f 的高效特征提取；颈部由 BiFPN 承担双向跨尺度加权融合、SPD-Conv 承担无损下采样，检测头扩展出 P2 浅层分支，形成四头结构；FECM 嵌入特征通路做遮挡补偿，GCCHead 替换原解耦头。各组件的分工如下表所示。

| 组件 | 模块 | 功能 |
| --- | --- | --- |
| Backbone | C3k2 + A2C2f | 高效多尺度特征提取 |
| Neck | BiFPN + SPD-Conv | 加权双向跨尺度融合，下采样保留细粒度信息 |
| Head | P2 分支 + GCCHead（内置 GCCM） | 浅层高分辨率监督小目标，轻量头兼顾精度与效率 |
| 特征补偿 | FECM | 增强可见区域特征，补偿遮挡区域语义 |

骨干输出的多尺度特征列表先进入 BiFPN 颈部，融合后的 P2 至 P5 特征经 FECM 增强补偿，最终由 GCCHead 输出分类与回归结果。

### 双向特征金字塔 BiFPN

BiFPN 用于以带权特征重分配的方式把不同尺度的特征表示高效整合，其输入为多尺度特征列表 $\vec{P}_{in} = (P_{l_1}^{in}, P_{l_2}^{in}, \ldots)$，经双向融合输出新列表 $\vec{P}_{out} = f(\vec{P}_{in})$。不同分辨率特征图的贡献并不均等，BiFPN 给每个输入分支赋一个可训练权重系数，本文采用快速归一化融合方案，公式如下：

$$O = \sum_i \frac{w_i}{\epsilon + \sum_j w_j} \cdot I_i$$

其中 $w_i$ 是第 $i$ 个输入特征的权重系数；$I_i$ 为对应输入特征图；分母加入小常数 $\epsilon = 0.0001$ 防止数值不稳定。归一化后的权重被约束在 0 到 1 之间且无需 Softmax，这等价于用一次除法换取自适应的特征贡献再平衡，计算上更省。以第四层的融合为例，自顶向下与双向输出分别表示为：

$$P_4^{td} = \mathrm{Block}\left(\frac{w_1 \cdot P_4^{in} + w_2 \cdot \mathrm{Resize}(P_5^{in})}{w_1 + w_2 + \epsilon}\right)$$

$$P_4^{out} = \mathrm{Block}\left(\frac{w_3 \cdot P_4^{in} + w_4 \cdot P_4^{td} + w_5 \cdot \mathrm{Resize}(P_3^{out})}{w_3 + w_4 + w_5 + \epsilon}\right)$$

| 符号 | 含义 |
| --- | --- |
| $P_4^{td}$ | 自顶向下路径中 P4 尺度的中间过渡特征 |
| $P_4^{out}$ | 双向融合后 P4 的最终输出特征 |
| $\mathrm{Block}$ | 卷积处理单元，本文用 A2C2f 模块替换标准卷积 |
| $\mathrm{Resize}$ | 上采样或下采样操作 |

直观上，每个尺度既接收来自更深层的语义，也接收来自更浅层的细节，权重让网络自己决定听谁的更多。BiFPN 的下采样路径由 SPD-Conv 接管，融合结果送往 P2 至 P5 四个检测分支。

### 空间到深度卷积 SPD-Conv

SPD-Conv 用于解决传统跨步下采样固有的细粒度信息丢失问题，替换 BiFPN 中的标准卷积。其结构由空间到深度变换与非跨步卷积两部分组成，如下图所示。

![SPD-Conv 结构图](../assets/paper-imgs/RSO-YOLO/fig4.png)

SPD 模块按预设下采样率把输入特征图切成小块，将二维平面上的空间信息重映射到通道维，随后用 1×1 卷积压缩扩张后的通道，得到紧凑而高效的特征表示。当尺度因子取 2 时，通道数变为 4 倍、空间分辨率减半，可实现对原始内容的近无损重构。直观上，下采样不再「扔掉」像素，而是把像素搬进通道里留待卷积筛选，从而保住小目标的细粒度细节。SPD-Conv 的输出沿 BiFPN 通路继续参与跨尺度融合。

### 特征增强补偿模块 FECM

FECM 的目标是一手强化未遮挡区域的判别特征、一手补偿遮挡区域缺失的语义信息，其结构如下图所示。

![FECM 结构图](../assets/paper-imgs/RSO-YOLO/fig5.png)

FECM 采用五分支并行架构：一条 1×1 卷积分支保持原空间分辨率，三条膨胀率分别为 6、12、18 的 3×3 膨胀卷积分支逐级扩大感受野，一条全局平均池化分支提取全局语义、在局部纹理缺失时提供上下文补充。各分支特征沿通道拼接后，经通道与空间注意力的联合校准，两路注意力输出相加融合，再用 1×1 卷积降维整合，从而放大未遮挡区域的显著特征。为进一步促进通道间信息交换，模块引入两层全连接网络，把未遮挡区域的高置信线索迁移到遮挡位置，强化遮挡与未遮挡目标之间的关联、补偿缺失语义。最后对增强特征做指数变换，把权重范围从 [0, 1] 扩展到 [1, e]，再与原特征相乘。直观上，指数放大保持了相对排序，又降低了对小值扰动的敏感度，弱目标响应因此被抬起来。FECM 的输出送入 GCCHead 参与最终预测。

### 全局跨维坐标检测头 GCCHead

GCCHead 用于在不牺牲全局上下文感知的前提下把检测头做轻，其结构如下图所示。

![GCCHead 结构图](../assets/paper-imgs/RSO-YOLO/fig6.png)

与只依赖标准卷积的传统 YOLO 检测头不同，GCCHead 在分类与回归分支之前串接多个 GCCM，以降低模型复杂度并强化全局上下文捕获能力。GCCM 的内部结构如下图所示。

![GCCM 结构图](../assets/paper-imgs/RSO-YOLO/fig7.png)

GCCM 先用 1×1 卷积做通道扩张丰富特征表示，再以深度可分离 3×3 卷积逐通道提取空间信息，在保持有效感受野的同时显著压低计算量与参数量；经共享跨维交互单元完成通道压缩与恢复后，分组特征被聚合求和并过 Sigmoid，生成水平与垂直两个方向的注意力图，对扩张特征做逐元素调制；最后 1×1 卷积降回通道数，经残差路径与输入相加。直观上，分组处理控制开销，跨维坐标注意力突出关键区域、抑制无关响应。GCCHead 接收 FECM 增强后的 P2 至 P5 特征，输出四个尺度的分类与回归结果，完成整网数据流。

### 损失配置

训练损失沿用 YOLOv12 的配置以保证公平对比：回归损失用 CIoU 定位损失度量预测框与真实框的几何差异，分类侧包含用于目标性预测的 Dynamic Focal Loss 与用于类别判别的 Meta-Contrastive Loss，三者权重分别设为 0.8、0.3 与 0.2，以平衡各分量在训练中的贡献。该损失作用于四个检测头的全部输出，与结构改进正交。

## 实验结果

### 实验设置

本文在 SODA10M、BDD100K 与 FLIR ADAS 三个自动驾驶数据集上评测，数据集构成如下表所示。

| 数据集 | 图像数 | 类别 | 划分（训练/验证/测试） |
| --- | --- | --- | --- |
| SODA10M | 10000（采样标注） | 三轮车、有轨电车、轿车、骑行者、卡车、行人 6 类 | 60% / 20% / 20% |
| BDD100K | 10000（选取） | 轿车、人、交通灯、交通标志 4 类 | 60% / 20% / 20% |
| FLIR ADAS | 5000（可见光） | 行人、自行车、轿车 3 类 | 60% / 20% / 20% |

评测指标为 P、R、mAP@0.5、mAP@0.5:0.95、Params、GFLOPs 与 FPS，其中 mAP 为各类别 AP（精确率-召回曲线下面积）的宏平均。SODA10M 测试集另按启发式规则切出遮挡子集：目标框与其他目标框重叠超过自身面积 20% 即记为遮挡；并按 COCO 协议以 32² 与 96² 像素面积切出小、中、大三个尺度子集。实验在 VirtAI Cloud 平台 B1.medium 实例（16 GB 内存、12 GB 显存）上完成，环境为 Ubuntu 22.04、Python 3.10、PyTorch 2.0.1 与 CUDA 11.8；输入统一缩放到 640×640，SGD 优化器初始学习率 0.01、动量 0.937、权重衰减 0.0005，余弦退火调度，训练 300 个 epoch，batch size 为 16。

## 优点和创新点

个人认为，本文有如下一些优点和创新点可供参考学习：

1. 把 BiFPN 加权融合与 SPD-Conv 无损下采样组合进 YOLOv12 颈部，并增开 P2 浅层检测头，多尺度融合效率与小目标感知同步提升，还省下 15.4% 参数。
2. 提出 FECM 遮挡补偿机制，五分支并行提取多尺度上下文后，用两层全连接把未遮挡区域的高置信线索迁移到遮挡位置，并以指数变换放大弱响应，遮挡子集 mAP@0.5 提升 3.3%。
3. 实验在三个数据集上覆盖消融、专项对比、尺度与遮挡分组定量及热力图可视化，RSO-YOLO 以 2.2 M 参数在 SODA10M 上领先所有对比模型 3 个点以上，说服力强。
