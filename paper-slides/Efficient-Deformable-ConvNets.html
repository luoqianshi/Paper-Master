DCNv4
Efficient Deformable ConvNets: Rethinking
Dynamic and Sparse Operator for Vision

从动态性质与内存访问两个维度重新设计可变形卷积：移除 softmax 放开权重取值，用线程复用与向量化读写消除冗余内存访问，前向速度达到 DCNv3 的 3 倍以上且收敛显著更快。

Contributions

核心贡献：DCNv3 的双重瓶颈一次解决

01

移除 softmax 归一化

调制标量变为 无界动态权重，增强算子动态性与表达能力，同时修复训练初期收敛慢的问题。

02

内存访问系统优化

指令级剖析定位瓶颈后，用同组通道线程复用、向量化读写与半精度，消除冗余内存读取与指令。

03

通用视觉算子

在 InternImage、ConvNeXt、ViT 与扩散模型 U-Net 上即插即用，覆盖分类、检测、分割、3D 与生成五类任务。

DCNv4 前向速度达到 DCNv3 的 3 倍以上；替换 InternImage 得到的 FlashInternImage 吞吐提升 50%~80%，精度还进一步提高。

Motivation

两个瓶颈：算子运行慢 + 训练初期收敛慢

瓶颈一

运行速度

  • 采样非邻近位置带来额外开销，使 DCN 不适应现代卷积算法
  • 对比测量中 DCNv3 甚至比充分优化的稠密全局注意力更慢
瓶颈二

收敛行为

  • DCNv3 在骨干训练初期 收敛速度慢于全局注意力，与自带的卷积归纳偏置直觉相悖
  • DCN 始终没有成为视觉骨干网络的首选方案

问题收窄为：暂未有工作在保留动态稀疏聚合能力的前提下，同时解决运行慢与初期收敛慢这两个瓶颈。

Method 01

算子性质对比：保留动态稀疏，放开权重取值

  • 注意力与 DCNv3 都用取值 (0, 1) 的有界动态权重聚合空间特征，差别在窗口——注意力共享且固定，DCNv3 每个位置独立
  • 卷积拥有独立滑窗与无界权重，但窗口形状与权重都与输入无关
  • DCNv4 同时具备自适应聚合窗口、动态聚合权重与无界取值范围
图 2：四种算子在聚合窗口、权重动态性与权重取值范围三个维度上的定位。这张图把 DCNv4 的改造方向表述为「保留动态稀疏、放开权重取值」，直接引出下一节移除 softmax 的操作。
Method 02

消除冗余负载与冗余内存指令

  • 旧实现按 H×W×C 建线程，每线程只算一个输出位置的一个通道；同组 D = C/G 个通道共享偏移与权重，多线程重复读取对内存受限算子是巨大浪费
  • 每线程处理 D′ 个通道后，偏移/权重读取与双线性插值系数计算成本都降低 D′ 倍
  • 但线程数减少使并行度下降、单线程负载增 D′ 倍，单纯复用线程并不提速
  • channel-last 布局下 D′ 个通道连续：一条 128 位向量化加载替代四次 32 位读取，写回同理；半精度再把读写字节数减半
图 3：DCNv3 (a) 每个通道一个线程、重复读取同组偏移与权重；DCNv4 (b) 让一个线程处理同组多个通道并合并访存，标注 2× fewer memory access cost，内核时间由 1.45 ms 降到 0.404 ms。
Method 03

移除 softmax：独立聚合窗口不需要有界权重

  • softmax 在注意力中是必需的：去掉后 K⊤V ∈ Rd×d 可先算，同一窗口内所有查询退化为一次线性投影
  • 但对 DWConv、DCNv3 这类每点拥有独立聚合窗口的算子，各窗口取值本就不同、也不存在「键」，退化问题不复存在
  • 归一化反而把权重压在 0 到 1 之间：ConvNeXt 加 7×7 窗内 softmax 后第 5 epoch 精度从 29.9 跌到 8.5，第 300 epoch 仍落后 2.2 个点
  • DCNv4 移除 softmax，把调制标量变为无界动态权重，收敛曲线全程快于 DCNv3、卷积与稠密注意力
ConvNeXt 深度卷积权重做 7×7 窗内 softmax 后的 ImageNet-1K 精度（括号内为相对基线的差值）。有界权重同时损害收敛速度与最终性能，这正是 DCNv4 去掉 softmax 的直接依据。
Experiments 01

算子级速度基准：标准分辨率

  • 设置：224×224 输入经 4/8/16/32 倍下采样，外加 ViT 的 14×14×768；batch 64，只测核心空间聚合操作
  • 稠密注意力随分辨率显著变慢甚至显存溢出；FlashAttention-2 大幅提速但不改变二次复杂度
  • DCNv3 快于朴素深度卷积，却慢于 cuDNN 优化版——3×3 稀疏窗口的速度优势并未兑现
  • DCNv4 全面超越基线：56×56×128 的 FP16 耗时从 1.52 ms 降到 0.404 ms
表 2：标准输入形状下各算子的运行时间（ms，FP32/FP16），DCNv4 在四档降采样率与 ViT 等宽形状上均快于 DCNv3。
Experiments 02

算子级速度基准：高分辨率

  • 设置：800×1280 层级特征图与 1024×1024 各向同性特征图，batch size 1，对应检测等下游任务的常用输入
  • 高分辨率下稠密全局注意力显存溢出，FlashAttention-2 也无法消除二次复杂度
  • 窗口注意力与深度卷积在高分辨率下同样落后于 DCNv4
  • 各档输入上 DCNv4 均比 DCNv3 快 3 倍以上，稀疏窗口的速度优势只有在内存访问优化后才成为现实
表 3：高分辨率输入下的算子级基准（ms，FP32/FP16）。DCNv4 在各档输入上均优于 cuDNN 深度卷积、窗口注意力与 FlashAttention-2。
Experiments 03

运行时间消融：3 倍提速来自多项叠加

  • 测试输入 56×56×128、batch size 64、4 组（每组 32 通道）
  • 微设计（合并线性层、去掉 LN-GELU）把模块时间 3.28 → 2.12 ms
  • 单纯线程复用消除冗余内存访问后反而升到 2.20 ms：并行度下降抵消了访存收益；复用插值系数收益也不显著
  • 向量化读写消除冗余内存指令后内核 1.45 → 0.606 ms，半精度进一步压到 0.404 ms
  • 最终模块 0.873 ms / 内核 0.404 ms，消除冗余内存指令是最关键一步
表 10：各优化环节的累积运行时间（ms）。Module 为模块级、Kernel 为内核级，灰色行即最终 DCNv4。
Experiments 04

ImageNet-1K 分类：吞吐提升 50%~80%

  • 用 DCNv4 替换 InternImage 中的 DCNv3 得到 FlashInternImage，架构与超参保持不变
  • 同规模对比吞吐提升 50%~80%，精度还略有提升
  • FlashInternImage-S 以 84.4% 超过 ConvNeXt-B 的 83.8% 且更快；L 达 88.1%，超过 ConvNeXt-XL 与 InternImage-XL 且快 30%~130%
  • T/S/B 训练 300 epochs；L 先在 ImageNet-22K 训练 90 epochs，再在 ImageNet-1K 微调 20 epochs
表 4：ImageNet-1K 分类精度与吞吐（images/s，FP32/FP16）。FlashInternImage 在更高精度下同时更快。
Experiments 05

COCO 实例分割：小模型追平更大基线

  • 检测头用 Mask R-CNN 与 Cascade Mask R-CNN，1×（12 epoch）看收敛速度，3×+MS（36 epoch）看最终性能
  • 短边 800、长边不超过 1333；AdamW，weight decay 0.05，骨干用分类预训练权重初始化
  • FlashInternImage-T/S 在实例分割上超过所有同规模模型，追平更大的 InternImage-S/B 且快 80%~90%
  • 3×+MS 下 FlashInternImage-B 达 50.6 APb / 45.4 APm

Experiments 06

ADE20K 语义分割：Large 规模刷新最好结果

  • 用 UperNet 在 ADE20K 上验证，T/S/B 的 crop size 为 512、L 为 640，batch 16 训练 160k iterations
  • 骨干同样以分类预训练权重初始化，其余设置对齐 InternImage
  • FlashInternImage-L 达到 55.6 / 56.0 的 SS/MS mIoU，刷新当时的最好结果

Experiments 07

nuScenes 3D 检测：骨干快 2~3 倍

  • 用 BEVFormerV2 验证，骨干在 COCO 上预训练，使用前后共 8 秒的数据
  • FlashInternImage-B 取得 63.1 NDS 与 57.4 mAP
  • 同 NDS/mAP 下整体快 50%~90%；只算骨干时快 200%~300%

Experiments 08

通用算子验证：ConvNeXt 与 ViT 即插即用

  • 把 ConvNeXt 的深度卷积、ViT 的注意力替换为 DCNv4，不改其它架构与超参，ImageNet-1K 监督训练
  • ConvNeXt-B + DCNv4：83.8 → 84.0，吞吐提升 20%/33%
  • ViT-B + DCNv4：81.8 → 81.9，吞吐提升 24%/17%
  • 在为特定算子精心调参的架构中，DCNv4 仍能保持精度并获得更快速度
表 8：ConvNeXt 与 ViT 中替换 DCNv4 后的 ImageNet-1K 精度与吞吐，均未做任何超参调整。
Experiments 09

扩散模型替换：参数更少、FID 更好

  • U-Net 中的卷积与注意力替换为 DCNv4，基于 U-ViT 代码库与 Stable Diffusion 图像潜变量训练
  • 参数量 860M → 566M，FID 2.94 → 2.44，FPS 4.82 → 4.92
  • 未做任何超参调整即取得更好的 FID 与吞吐，验证其作为通用视觉算子的潜力
  • 作者指出该架构与超参未必对 DCNv4 最优，重新设计模型或搜索超参可能更好

Summary

优点和创新点

1

指令级内核剖析

从剖析出发定位到瓶颈是占 99% 的内存访问而非计算，再用线程复用、向量化读写与半精度系统消除冗余，把稀疏算子的理论速度优势变为现实。

2

softmax 对照实验

用「给 ConvNeXt 卷积权重加 softmax」的反事实实验验证独立窗口算子不需要有界权重，据此移除 softmax 同时收获收敛速度与精度。

3

三种替换设置

InternImage 替换、ConvNeXt 与 ViT 即插即用、扩散模型 U-Net 替换，覆盖分类、检测、分割、3D 检测与生成五类任务，实验丰富。

可复用的路径：先用 roofline 与指令级剖析量化瓶颈，再用一个反事实对照实验验证设计假设。
