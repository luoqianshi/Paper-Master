基于 PSMF-YOLO 的
无人机遥感图像枇杷花蕾小目标检测方法

在 YOLOv11n 上融合 P2 小目标检测层、SPD-Conv、C2PSA-MSDA 与 Focaler-DIoU，mAP@0.5 达到 84.9%，较基线提升 4.9 个百分点。

西南大学工程技术学院，重庆 400715
农业工程学报 2026, 42(11): 1-10 无人机遥感 小目标检测 YOLOv11n 轻量化部署
Motivation

研究动机

枇杷花蕾呈簇状密集生长，单个目标体积小且与背景叶片颜色相近，导致漏检与误检同时高发，影响疏花决策的科学性。 现有目标检测方法在无人机遥感视角下面临层层递进的局限。

A

特征提取丢失空间信息

步幅卷积和池化层在特征提取时会不可避免地丢失关键空间信息，小目标赖以辨识的边缘与纹理随之被削弱。

B

跨层次感知能力不足

YOLOv11 等主流模型的改进多聚焦于单一结构或注意力机制，对复杂果园背景下低对比度小目标的跨层次感知能力不足。

C

回归损失受到干扰

CIoU 在小目标检测中还同时引入宽高比约束的干扰，对定位偏差与样本分布不均衡问题的缓解有限。

上述缺陷相互耦合，使检测精度、定位质量与模型规模难以同时兼顾。本文以 YOLOv11n（五档中参数量与计算量最小）为基线，在保持轻量化的前提下提升密集簇生小目标的检测能力。

Contributions

文章贡献

01

数据集构建

无人机采集 850 张图像，筛选 600 张精细标注，按 7:2:1 划分，增强后训练集扩至 3 000 张。

02

P2 + SPD-Conv

新增 P2 小目标检测层保留高分辨率细节；7 个非步幅卷积层替换为 SPD-Conv，实现无损下采样。

03

C2PSA-MSDA

把多尺度扩张注意力嵌入 C2PSA，扩张率 1～4 并行，覆盖 3×3 至 9×9 感受野。

04

Focaler-DIoU

替换 CIoU：按 IoU 区间动态调整样本权重，并直接优化预测框与真实框的中心点距离。

PSMF-YOLO 的 mAP@0.5、精确率与召回率较 YOLOv11n 分别高 4.9、2.3 与 4.2 个百分点；较表现最好的 YOLOv5s 仍高 0.8、0.1 与 0.6 个百分点。

Method 01

PSMF-YOLO 整体网络架构

  • SPD-Conv + C3k2（骨干）：无损下采样并逐级提取花蕾的边缘与纹理特征
  • P2 分支与多尺度融合（颈部）：在 P3、P4、P5 基础上新增 P2 分支，以上采样和拼接融合 P2—P5 各层特征
  • Detect 检测头（输出端）：在 4 个尺度上输出花蕾的类别与边界框
  • Focaler-DIoU（回归损失）：约束预测框与真实框的中心点距离并动态加权样本

输入图像先经骨干逐级压缩空间尺寸并扩张通道，再由颈部把深层语义与浅层细节融合，最后送入检测头产生预测框。

PSMF-YOLO 网络结构图：按 Backbone、Neck、Head、Result 四个区域展示全部组件及连接关系，并放大给出 C3k2、C2PSA-MSDA 与 SPPF 的内部构成。
Method 02

P2 小目标检测层

为小尺寸花蕾保留高分辨率的检测特征，对应较低下采样倍率的特征层。

  • 不额外下采样：先把高层特征图上采样两倍恢复空间分辨率，再与主干同尺度浅层特征在通道维拼接。
  • 拼接后经带残差连接的 C3k2 完成特征融合与增强，浅层携带的位置与纹理信息进入检测分支。
  • 该分支接收主干浅层特征与颈部上采样特征，输出 160×160 特征图交给 P2 检测头。
  • 与 P3、P4、P5 共同构成四尺度预测，减少小目标信息在层层下采样中的流失。

P2 让花蕾的细微边缘得以进入检测分支，是消融中 mAP@0.5 增益最大的单项模块（+2.1 个百分点）。

检测层输出特征图尺寸
P2160 × 160
P380 × 80
P440 × 40
P520 × 20

输入统一为 640×640 像素，四尺度特征图依次为 160×160、80×80、40×40、20×20。

Method 03

SPD-Conv 空间到深度卷积

在下采样过程中保留全部空间信息，用于替换网络中的非步幅卷积层。

  • SPD 变换把原始特征图划分为 scale² 个子特征图，按固定间隔抽取像素并重排到通道维度。
  • 空间尺寸缩小到 S/2 × S/2，但通道数变为 4C₁，信息不丢失而是被重新编码。
  • 随后接 stride=1 的标准卷积，输出 S/2 × S/2 × C₂ 的 X''，兼顾感受野扩展与冗余信息抑制。
  • 本文将整个网络中的 7 个非步幅卷积层替换为 SPD-Conv。
SPD 变换 · 式（1）

fi,j = X[ i : S : scale,  j : S : scale ]

X 为输入特征图，S 为空间尺寸，scale 为缩放因子（本文取 2），fi,j 为按偏移 (i, j) 抽取的子特征图。

SPD-Conv 模块结构与转换示意图：输入特征图 X 经 SPD 变换拆分为子特征图、在通道维拼接得到 X'，再由 stride=1 的标准卷积得到输出 X''。
Method 04

多尺度扩张注意力机制 MSDA

为小目标检测引入可控范围的全局上下文，弥补 C2PSA 模块感受野有限的问题。

  • 输入 H × W × C 特征图先映射为查询 Q、键 K、值 V，并在通道维划分为多个注意力头，各头只处理部分通道。
  • 在特征图上以滑动窗口遍历空间位置，按预设扩张率对邻域采样，把全局注意力转化为局部计算，在控制复杂度的同时扩大有效感受野。
  • 扩张率 r 取 1、2、3、4，感受野分别为 3×3、5×5、7×7、9×9；小 r 聚焦细粒度纹理，大 r 建立远距离依赖。
  • 各头输出在通道维拼接并映射回原通道空间，交给 C2PSA-MSDA 与主干特征融合。

不同扩张率的局部注意力并行学习，使 MSDA 同时刻画局部细节与较大范围的上下文语义。

多尺度扩张注意力机制 MSDA 结构图：展示 Q、K、V 三组线性映射、多个注意力头、滑动窗口扩张注意力，以及扩张率 r 取 1～4 时对应的采样网格。
Method 05

C2PSA-MSDA 跨阶段注意力融合模块

把 MSDA 嵌入 C2PSA 的注意力通路，同时建模局部细节与全局上下文。

C2PSA-MSDA 模块结构图：Conv、N 个 PSABlock-MSDA 单元、Concat 与输出 Conv 的串联方式，以及跨越拼接的直连通路。

补上远距离依赖

C2PSA 通过对不同空间位置和通道加权提升关键区域敏感度，但缺乏通过扩张卷积捕捉远距离依赖的能力。

多尺度邻域动态聚合

MSDA 的多扩张率并行补上这一环，注意力权重可在多种尺度邻域内动态聚合，同时刻画局部细节与较大范围上下文。

骨干末端送入颈部

模块位于骨干网络末端、SPPF 之后，接收深层语义特征，把增强后的特征送入颈部参与多尺度融合。

Method 06

Focaler-DIoU 损失函数

让边界框回归同时关注困难样本与中心点偏移，替换 YOLOv11 原有的 CIoU 损失。

Focaler-DIoU · 式（2）
IoUfocaler = 0IoU < d (IoU − d) / (u − d)d ≤ IoU ≤ u 1IoU > u
LFocaler-IoU = 1 − IoUfocaler LDIoU = 1 − DIoU DIoU = IoU − ρ²(b, bgt) / c² LFocaler-DIoU = LDIoU + IoU − IoUfocaler

按区间重新赋权

低于下限阈值 d 的回归样本不被重视，高于上限阈值 u 的样本被完全关注，中间区间线性过渡，从而缓解数据分布不均衡并加快收敛。

去掉宽高比干扰

DIoU 直接惩罚预测框与真实框中心点之间的欧氏距离，相较 CIoU 去掉了宽高比约束带来的额外干扰，梯度更新更为稳定。

两项综合后重点校正困难样本的位置误差；该损失接在检测头的回归分支上，与分类损失共同监督训练，输出最终检测框。

Experiments 01

实验设置

自建枇杷花蕾数据集与统一训练配置。

  • 采集：重庆北碚秀峰枇杷园，DJI mini3 在 5～8 m 航高拍摄，共 850 张 1920×1080 RGB 图像。
  • 标注：人工筛选 600 张，Labelimg 精细标注；按 7:2:1 划分训练、验证与测试集。
  • 增强：翻转、旋转、随机裁剪、亮度与对比度调整，训练集扩充至 3 000 张。
  • 训练：输入 640×640，300 轮，批大小 32，初始学习率 0.01，权重衰减 0.000 5；RTX 4090D 平台。
  • 指标：mAP@0.5、P、R、F1，以及 GFLOPs、参数量、FPS 与模型大小。
无人机遥感图像数据增强样例图：原图与随机裁剪、旋转、翻转及亮度对比度调整等增强方式的效果对比；增强样本在视角、构图与明暗上差异明显，覆盖田间拍摄常见的成像变化。

Experiments 05

消融实验

为厘清各模块的贡献，以 YOLOv11n 为基线逐个添加模块进行消融。

PSMF-YOLO 模型消融试验结果表：8 种模块组合下的 mAP@0.5、P、R 与 F1 score。

单独引入 P2 时 mAP@0.5、P 和 R 分别提高 2.1、1.6 和 0.9 个百分点，单独替换 SPDConv 时三项分别提高 0.9、0.1 和 1.4 个百分点；P2 与 SPDConv 结合后 mAP@0.5 升至 83.0%，加入 MSDA 后进一步升至 83.5%， Focaler-DIoU 单独加入则把 mAP@0.5 由 80.0% 提升到 80.6%。四模块齐备的 PSMF-YOLO 最终取得 84.9%、79.3% 与 80.6%，较基线分别提高 4.9、2.3 和 4.2 个百分点。

Summary

优点和创新点

1

信息保留链路

将 P2 小目标检测层与 SPD-Conv 组合成信息保留链路，以空间到深度的无损下采样配合浅层高分辨率特征拼接，使 mAP@0.5 较基线提升 4.9 个百分点，可供小目标检测的特征保留设计参考学习。

2

C2PSA-MSDA

设计 C2PSA-MSDA 模块把多尺度扩张注意力嵌入跨阶段注意力结构，用四种扩张率并行的滑动窗口注意力覆盖 3×3 至 9×9 感受野，统一了局部细节与全局上下文的建模。

3

Focaler-DIoU

以 Focaler-DIoU 重构边界框回归损失，将按区间动态加权的样本难度与中心点距离约束相结合，配合逐模块消融、P-R 曲线与多模型检测效果可视化相互印证，实验完整且说服力强。

从特征保留、上下文建模到边界框回归，三方面协同改进，在保持轻量化的前提下提升密集簇生小目标的检测能力。
