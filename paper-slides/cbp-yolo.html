CBP-YOLO
基于 CBP-YOLO 的玉米田间草地贪夜蛾侵染痕迹检测与试验

通过 Real-ESRGAN 超分辨率重建、协调注意力机制与 BiFPN 双向特征融合，系统提升无人机多尺度图像中小尺度虫害痕迹的检测精度。

齐江涛 · 王硕 · 熊悦凇 · 高芳芳 · 王发赢 · 邹宗峰 · 刘英智 · 刘慧力
吉林大学 · 吉林省智慧农业装备与技术重点实验室 · 烟台市农业技术推广中心
超分辨率重建 协调注意力 BiFPN 虫害检测
Contributions

核心贡献：超分辨率 + 协调注意力 + BiFPN + P2 检测头

01

Real-ESRGAN 超分辨率

对低分辨率图像进行超分辨率预处理，恢复叶片损伤区域的纹理细节，GSD 从 0.53 提升至 0.26 cm/像素。

02

C2f-CA 协调注意力

将通道注意力分解为水平与垂直两个独立一维编码，保留精确位置信息，弥补 SE 模块空间细节丢失。

03

BiFPN + P2 检测头

BiFPN 可学习权重动态调节跨尺度融合，新增 P2 检测头拓展对小尺度目标的感知能力。

CBP-YOLO 在自建数据集上 mAP@0.5 达 76.5%，较 YOLOv8m 提升 3.4 个百分点，较 YOLOv9m、YOLOv10m 分别提升 10.1、7.2 个百分点。

Motivation

无人机多尺度图像中的虫害检测难点

核心挑战

检测难点

  • 小目标尺度变化大、特征对比度低容易被忽略
  • GSD 从 0.22 到 0.53 cm/像素的宽范围变化下模型鲁棒性不足
  • 土壤、杂草、阴影等背景噪声干扰严重
本文方案

系统改进

  • Real-ESRGAN 超分辨率恢复低分辨率纹理
  • CA 注意力增强位置感知
  • BiFPN + P2 检测头实现多尺度均衡检测
Method 01

Real-ESRGAN 超分辨率预处理

  • 结合 RRDBs 生成器与 U-Net 判别器，恢复高频细节、抑制伪影
  • 引入模糊、下采样、噪声和 JPEG 压缩等高阶退化过程合成训练数据
  • Pixel Unshuffle 操作将空间分辨率降为 1/2、通道扩展 4 倍，减少 GPU 显存
  • GSD=0.53 图像经处理后尺寸由 800×650 提升至 1600×1300，GSD 减小为 0.26 cm/像素
退化建模流程

Ib = Blur(I) → In = Noise(Ib) → Is = Down(In) → ILR = JPEG(Is)

正向退化建模逆向重建，使生成器学习真实世界退化的逆过程。

Method 02

C2f-CA 协调注意力机制

  • 将通道注意力分解为水平和垂直两个独立一维特征编码
  • 一条路径沿空间维度捕捉长程依赖，另一条路径保留精确位置信息
  • 拼接后经 1×1 卷积变换，再分解为两个方向的注意力权重
CA 注意力输出

yc(i, j) = xc(i, j) × gch(i) × gcw(j)

嵌入 YOLOv8 的 C2f 模块形成 C2f-CA 结构，有效削弱背景噪声干扰。

Method 03

BiFPN 双向特征金字塔网络

加权融合公式

P̂i = ∑ wj · Pj∑ wj + ε

其中 wj 为非负可学习权重，ε 为避免除零的常数。可学习权重通过归一化 softmax 获得。

  • 构建 4 层特征金字塔：P2(160×160×64)、P3(80×80×128)、P4(40×40×256)、P5(20×20×512)
  • 新增 P2 浅层检测头可检测 4×4 像素感受野的小目标
  • 4 个尺度并行输出检测结果，显著提升小尺度虫害感知
Experiments 01

不同地面采样距离 GSD 的检测对比

GSD=0.38 cm/像素取得最佳效果（AP@0.5=79.8%），GSD=0.53 条件下应用 Real-ESRGAN 后 AP@0.5 提高 7.3 个百分点，F1-score 提高 8.6 个百分点。
Experiments 02

消融实验：多模块协同增益

  • 基准 AP@0.5=73.1%，P2 模块引入提升至 75.1%（+2.0%），CA 提升约 1%，BiFPN 达 73.8%
  • 三模块协同：精确率 74.7%，AP@0.5=76.5%，F1=73.5%
  • 多模块协同优化实现精确率与召回率的有效平衡
Experiments 03

与主流模型性能对比

  • CBP-YOLO 在各项指标上均优于其他模型，AP@0.5 较 YOLOv9m 提升 10.1、较 YOLOv10m 提升 7.2、较 RetinaNet 提升 17.9 个百分点
红框为真实标注框，蓝框为检测框。CBP-YOLO 在多个尺度下均能更准确定位虫害痕迹，漏检和误检数量明显减少。
Summary

优点和创新点

1

超分辨率预处理

Real-ESRGAN 恢复低分辨率纹理细节，GSD=0.53 条件下 AP@0.5 提升 7.3 个百分点。

2

协调注意力 CA

二维坐标注意力分解同时捕捉空间位置信息和通道重要性，增强小目标局部细节提取。

3

BiFPN + P2 检测头

可学习权重动态调节跨尺度融合，配合 P2 小目标检测头实现多尺度均衡检测。

CBP-YOLO

超分辨率重建 + 协调注意力 + BiFPN，
为无人机多尺度图像中「草地贪夜蛾侵染检测」提供系统方案。
