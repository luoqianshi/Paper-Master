Dynamic Head
Unifying Object Detection Heads with Attentions

把检测头的输入视为「层级 × 空间 × 通道」三维张量，将尺度感知、空间感知与任务感知统一为三个串联的注意力——作为即插即用模块，在 COCO test-dev 取得 54.0 AP，配合 Transformer 骨干与额外数据推至 60.6 AP。

Xiyang Dai · Yinpeng Chen · Bin Xiao · Dongdong Chen · Mengchen Liu · Lu Yuan · Lei Zhang
Microsoft, Redmond, USA
检测头 统一注意力 即插即用 可变形卷积 arXiv:2106.08322
Abstract

摘要：用注意力统一检测头

“The complex nature of combining localization and classification in object detection has resulted in the flourished development of methods. Previous works tried to improve the performance in various object detection heads but failed to present a unified view. In this paper, we present a novel dynamic head framework to unify object detection heads with attentions. By coherently combining multiple self-attention mechanisms between feature levels for scale-awareness, among spatial locations for spatial-awareness, and within output channels for task-awareness, the proposed approach significantly improves the representation ability of object detection heads without any computational overhead. … With a standard ResNeXt-101-DCN backbone, we largely improve the performance over popular object detectors and achieve a new state-of-the-art at 54.0 AP. Furthermore, with latest transformer backbone and extra data, we can push current best COCO result to a new record at 60.6 AP.”

— 论文摘要原文（节选），CVPR 2021 / arXiv:2106.08322

一句话概括：不新增复杂结构，而是把「该看哪一层、该看哪里、该看哪些通道」统一成检测头上的注意力学习问题。

Motivation

研究动机：一个好检测头需要同时具备三种感知

Scale-aware

尺度感知 ↔ 层级 L

同一图像中物体尺度差异巨大。特征金字塔不同层级的语义差异，正对应物体尺度；跨层级改进表示学习即可增强尺度感知。

Spatial-aware

空间感知 ↔ S = H × W

不同视角下物体形状、旋转与位置差异显著。不同空间位置的特征承载这些几何变换，跨位置改进表示学习即可增强空间感知。

Task-aware

任务感知 ↔ 通道 C

边界框、中心点、关键点等表示具有完全不同的目标与约束。不同通道的特征对应不同任务与表示，跨通道改进表示学习即可增强任务感知。

现状：特征金字塔与路径增强的工作聚焦尺度，可变形卷积一系聚焦空间变换，各式物体表示的工作聚焦任务建模——彼此缺少统一的视角，尚无工作把三种感知放进同一个检测头同时优化。

Method · 统一表示

把检测头写成三维张量上的串联注意力

General Form → Sequential Decomposition
W(F) = π(F) · F = πC( πS( πL(F) · F ) · F ) · F
直接在完整张量上学注意力代价过高；于是拆成三个各管一个维度的注意力，依次串联，整体可嵌套多次。
F ∈ ℝL×S×C把 L 个层级特征缩放对齐到中间层尺度，S = H × W 后重排得到的三维张量。
L特征金字塔层级数——对应物体尺度差异。
S空间位置数——对应形状、旋转、位置的几何差异。
C通道数——对应任务与物体表示的差异。
  • 先对相邻层级做上采样或下采样，把特征金字塔缩放成 F ∈ ℝL×H×W×C；再记 S = H × W，重排为 F ∈ ℝL×S×C。
  • 三个维度与三类感知能力一一对应，这是把各种检测头改进统一起来的关键一步。
  • 完整自注意力在如此高维张量上优化困难、计算不可承受；分解后每个注意力只在一个维度上学习，代价可控。
  • 三个注意力按 πL → πS → πC 的固定顺序串联，形成可堆叠的 DyHead 块。

论文将此视为首次把三个维度上的多重注意力组合进统一检测头，以最大化各方向改进的合力。

Method · 整体范式

Dynamic Head 的整体范式与特征演进

Figure 1. Dynamic Head 整体范式：三种注意力各聚焦一个视角，底部同时可视化每类注意力作用后的特征图改善。
  • 任意骨干提取特征金字塔 → 缩放对齐为三维张量 → 堆叠若干 DyHead 块 → 输出供分类、中心 / 框回归等任务使用。
  • 骨干输出的初始特征图受 ImageNet 预训练域差异影响，噪声较大；经尺度感知注意力后对前景尺度差异更敏感；再经空间感知注意力后更稀疏、聚焦判别性位置；最后经任务感知注意力按下游任务重组为不同激活。
  • 底部可视化与块内「先尺度、再空间、后任务」的顺序相互印证，直观说明三个模块各自有效。
Method · πL

尺度感知注意力：按语义重要性融合层级

Scale-aware Attention
πL(F) · F = σ( f( (1 / SC) ΣS,C F ) ) · F
f(·) 是由 1 × 1 卷积层近似的线性函数；σ(x) = max(0, min(1, (x + 1) / 2)) 是 hard sigmoid。
  • 先在空间与通道维度上聚合得到各层级的统计量，再经 1 × 1 卷积映射为层级重要性分数，逐层缩放特征。
  • 与物体尺度更匹配的层级被增强、不匹配的被抑制，使不同层级的重要性随输入自适应。
  • 作为串联注意力的第一级，它输出给空间感知注意力继续加工；Fig. 3 的尺度比值分布为其学习效果提供了直接证据。

与以往在骨干 / 金字塔上做多尺度融合不同，这里把尺度选择放在检测头内部，且是数据驱动的动态加权。

Method · πS

空间感知注意力：稀疏采样 + 跨层聚合

Spatial-aware Attention
πS(F) · F = (1 / L) Σl=1…L Σk=1…K wl,k · F(l; pk + Δpk; c) · Δmk
K 为稀疏采样位置数；pk + Δpk 是经自学习空间偏移后的采样位置；Δmk 是该位置的自学习重要性标量——两者都从 中间层输入特征学习。
  • 目标：聚焦在空间位置与特征层级间持续共存的判别性区域。S 维度过高，模块拆成两步。
  • 第一步用可变形卷积让注意力学习稀疏化，避免全空间注意力的巨大开销；偏移使采样点自适应落到前景判别位置。
  • 第二步在相同空间位置上对 L 层特征聚合（取平均），把跨层信息并入空间注意力。
  • 输出交给任务感知注意力；Fig. 4 显示随块数增加，特征图逐步收敛到前景的判别位置。
Method · πC

任务感知注意力：按任务动态开关通道

Task-aware Attention
πC(F) · F = max( α1(F) · Fc + β1(F),   α2(F) · Fc + β2(F) )
Fc 为第 c 个通道的特征切片；[α1, α2, β1, β2]T = θ(·) 学习激活阈值。
  • θ(·) 的实现在思想上接近 Dynamic ReLU：先在 L × S 维度上全局平均池化降维，接两个全连接层与一个归一化层，再用平移 sigmoid 把输出归一到 [−1, 1]。
  • 两条仿射分支取 max，形成分段线性的通道激活；哪条分支占优由输入统计动态决定。
  • 效果相当于按任务打开 / 关闭不同通道，使分类、框回归、中心 / 关键点学习各得其所。

算例：设某通道切片 Fc = 1，θ(·) 输出 α1 = 0.5、β1 = 0.2、α2 = −0.3、β2 = 0.4。分支一 = 0.7，分支二 = 0.1，取 max 后输出 0.7。该通道被「打开」，而具体程度由输入决定。

该模块位于串联注意力末端，输出直接供下游分类、回归等分支使用；对一阶段与两阶段、框 / 中心 / 关键点表示均适用。

Method · 块设计

DyHead 块内部：三个注意力怎么实现

  • πL 分支：avg pool → conv 1 × 1 → relu → hard sigmoid，先在空间与通道上聚合，再生成 L 个层级的权重。
  • πS 分支：index 取中间层特征 → conv 3 × 3 预测 offset → sigmoid 生成 Δm，实现可变形稀疏采样。
  • πC 分支：avg pool → fc → relu → fc → normalize，配合常量 1, 0, 0, 0 生成通道门控参数。
  • 融合方式：每个注意力与输入 F 逐元素相乘后再相加（图中的 ⊗ 与 ⊕），沿同一路径串联。
  • 可嵌套堆叠：式 (2) 可嵌套多次，从而叠出多个 πL / πS / πC 块；Fig. 4 即对比 2 / 4 / 6 个块。

Method · 泛化到现有检测器

同一套块，如何接进一阶段与两阶段检测器

Figure 2(b)(c). (b) 接入一阶段检测器；(c) 接入两阶段检测器。
One-stage

一条统一分支替代多条任务子网

RetinaNet 等通常在骨干后挂多个任务特定子网。DyHead 只接一条统一分支即可处理多任务；FCOS、ATSS、RepPoints 等 anchor-free 变体只需在头端追加各类预测（Fig. 2b）。

Two-stage

ROI Pooling 前做两步，之后换掉 FC

先在 ROI Pooling 之前施加 πL 与 πS，再用 πC 替换原来的全连接层，把统一注意力延伸到两阶段框架（Fig. 2c）。

设计意图：把三种感知做成可插拔的头部组件，不绑定某一种检测范式——这也是 Table 3 能覆盖五类框架的前提。

Method · 统一视角

Deformable、Non-Local、Transformer 都只是子维度特例

Deformable

只建模 S 子维度

可变形卷积以稀疏采样改进传统卷积的变换学习，可视为只建模空间维度。它多用于检测骨干、少用于检测头；骨干中的可变形模块与 DyHead 互补——本文用 ResNeXt-101-64x4d-DCN 骨干取得新 SOTA。

Non-Local

只建模 L × S 子维度

Non-Local Networks 用点积形式融合不同空间位置的像素特征，可视为只建模层级与空间两个维度，未显式处理通道 / 任务维度。

Transformer

只建模 S × C 子维度

Transformer 以多头全连接层学习跨注意力对应、融合不同模态特征，可视为只建模空间与通道两个维度。

三类注意力都只部分建模特征张量的子维度；DyHead 把不同维度上的注意力合成一个连贯实现，并显式对应检测的三类挑战——相较之下既有方案的工作机制是隐式的。后文实验（尤其 Table 5）显示，这一设计带来实际收益。

Experiments · Setup

实验设置：COCO 2017 与「少用 trick」的训练配方

数据与指标

MS-COCO 2017

· 80 类、约 160K 张网络图像；train2017 / val2017 / test2017 分别含 118K / 5K / 41K 张。
· 所有实验只用 train2017 训练、不用额外数据；消融在 val2017 评测，与 SOTA 对比报告 test-dev 官方结果。
· 指标为 COCO AP 系列：AP、AP50、AP75、APS、APM、APL。

实现与训练

以插件形式接入 Mask R-CNN benchmark

· 未特别说明时用 ATSS 训练框架；单节点 8 × V100 32GB。
· 消融统一用 ResNet-50 + 1x 日程；其余模型用 2x。
· 初始学习率 0.02、weight decay 1e−4、momentum 0.9，在 67% 与 89% 轮次各乘 0.1。
· 增强仅用随机水平翻转；为对比多尺度输入方法，部分模型采用多尺度训练。

推理与声明：与使用测试时增强的方法对比时采用多尺度测试；未使用 model EMA、mosaic、mix-up、label smoothing、soft-NMS 或自适应多尺度测试——精度增益因此更易归因于 DyHead 本身。

Summary & Discussion

贡献、局限与可以继续追问的地方

01 · 统一框架

一个视角收编三类方法

把尺度、空间、任务感知统一为三维张量上的注意力学习，并让 Deformable / Non-Local / Transformer 成为子维度特例。

02 · 即插即用

五类检测器一致受益

接入 Faster R-CNN、RetinaNet、ATSS、FCOS、RepPoints，一致提升 1.2 ∼ 3.2 AP；2 块即超基线且更省算力。

03 · 简化头端

一条分支替代多条子网

同时完成分类与回归，对检测头的轻量化改造有直接借鉴意义。

04 · 结果扎实

消融、可视化、SOTA 闭环

COCO test-dev 54.0 AP；附录叠加 Swin-L、更大输入与额外数据后推至 60.6 AP。

作者自述的后续方向：如何让完整注意力模型更易学习、计算更高效；如何把更多模态的注意力系统性地纳入检测头设计。

  • 阅读观察：摘要称「without any computational overhead」，但 Table 2 的 6 块配置相对基线为 +21.50 GFLOPs；更准确的表述是「相对骨干开销较小」，引用时需分清口径。
  • 阅读观察：正文说加深到 8 块仍受益，表格 AP 峰值却在 6 块（42.6 vs 42.5），两处表述略有出入。
  • 阅读观察：论文报告 GFLOPs 而非实测延迟；部署到实时检测器时，可变形采样与索引操作的实际时延仍需实测。
