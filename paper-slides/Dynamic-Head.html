Dynamic Head
Unifying Object Detection Heads with Attentions

把检测头的输入看成「层级 × 空间 × 通道」的三维张量，将尺度感知、空间感知、任务感知统一为张量上三个串联的注意力 —— 即插即用提升各类检测器 1.2 ∼ 3.2 AP，COCO test-dev 54.0 AP，配合 Transformer 骨干与额外数据推至 60.6 AP。

Xiyang Dai · Yinpeng Chen · Bin Xiao · Dongdong Chen · Mengchen Liu · Lu Yuan · Lei Zhang
Microsoft, Redmond, USA
检测头 统一注意力 即插即用 可变形卷积 arXiv:2106.08322

核心贡献：一个统一的注意力检测头

01

统一表示

把特征金字塔缩放对齐后拼接成的检测头输入看作 L × S × C 三维张量，把各类头端改进统一为同一张量上的注意力学习问题。

02

三段串联注意力

沿三个维度依次作用：尺度感知 πL 按语义重要性动态融合层级，空间感知 πS 借可变形卷积稀疏采样聚焦判别区域，任务感知 πC 动态开关通道适配下游任务。

03

即插即用的泛化能力

作为插件块接入 Faster R-CNN、RetinaNet、ATSS、FCOS、RepPoints，覆盖两阶段/一阶段、anchor-based/anchor-free、基于框/基于点的多种设定，一致提升 1.2 ∼ 3.2 AP。

04

COCO 新纪录

配 ResNeXt-101-DCN 在 COCO test-dev 取得 54.0 AP，训练时间仅为 EfficientDet / SpineNet 的 1/20；结合 Transformer 骨干与自训练额外数据推至 60.6 AP。

Motivation

一个好的检测头要同时应对三类固有困难

尺度感知

Scale-aware

图像中不同尺度的物体常常并存，检测头应当让特征强度随物体尺度自适应 —— 这关系到特征张量的层级维度。

空间感知

Spatial-aware

物体在不同视角下呈现差异巨大的形状、姿态与位置，检测头应当能学习空间变换 —— 这关系到空间位置维度。

任务感知

Task-aware

边界框、中心点、关键点等物体表示各有全然不同的训练目标与约束，检测头应当按任务重组特征 —— 这关系到通道维度。

现状：改进特征金字塔与路径增强的工作聚焦尺度问题，可变形卷积一系的工作聚焦空间变换学习，各式物体表示的工作聚焦任务建模 —— 彼此之间缺少一个统一的视角，暂未有工作把三种感知能力放进同一个检测头框架中同时优化。

Method · 统一表示

特征张量与统一注意力表示

一般形式 → 三维分解
W(F) = π(F) · F
W(F) = πC( πS( πL(F) · F ) · F ) · F
π(·) 是注意力函数。朴素解法是用全连接层直接在所有维度上学注意力，但张量维度过高，优化困难且计算代价不可承受 —— 于是拆成三个各管一个维度的串联注意力。
L特征金字塔的层级数；层间特征差异关系物体尺度
S = H × W中间层特征的空间位置数；空间位置差异关系几何变换
C中间层特征的通道数；通道差异关系任务与物体表示
  • 给定特征金字塔的 L 个层级特征，先用上采样或下采样把各层缩放到中间层特征的尺度，得到 F ∈ ℝL×H×W×C。
  • 记 S = H × W，即可重排为三维张量 F ∈ ℝL×S×C。
  • 张量的三个维度与三类感知能力一一对应 —— 这是把各种头端改进统一起来的关键一步。
  • 其余符号：f(·) 是由 1×1 卷积近似的线性函数，σ(·) 是 hard sigmoid，K 是稀疏采样位置数，θ(·) 是生成通道激活参数的超函数。
  • 三个注意力依次串联，分别承接尺度、空间与任务感知；这一表示是后续三个模块的公共输入约定。
Method · πL

尺度感知注意力：在层级维度上融合

Scale-aware Attention
πL(F) · F = σ( f( (1/SC) ΣS,C F ) ) · F
f(·) 是由 1×1 卷积层近似的线性函数；σ(x) = max(0, min(1, (x+1)/2)) 是 hard sigmoid 函数。
  • 依据语义重要性动态融合不同层级的特征，让特征在各层级的相对强度随输入自适应。
  • 直观流程：先在空间与通道维度上聚合得到层级统计量，再映射成各层级的重要性分数并逐层缩放特征。
  • 与物体尺度更匹配的层级被增强，不匹配的被抑制。
  • 该模块位于串联注意力的第一级，输出交给空间感知注意力继续加工。
Method · πS

空间感知注意力：稀疏采样 + 跨层聚合

Spatial-aware Attention
πS(F) · F = (1/L) Σl=1…L Σk=1…K wl,k · F(l; pk+Δpk; c) · Δmk
K 是稀疏采样位置数；pk+Δpk 是由自学习空间偏移 Δpk 得到的偏移后位置；Δmk 是位置 pk 处自学习的重要性标量 —— 两者都从 F 的中间层输入特征中学习。
  • 目标：聚焦在空间位置与特征层级间持续共存的判别性区域。S 维度过高，因此把模块拆成两步。
  • 第一步用可变形卷积让注意力学习稀疏化，避免全空间自注意力的巨大开销。
  • 偏移量让采样点自适应地落到前景的判别位置；第二步对 L 层取平均，完成相同空间位置上的跨层聚合。
  • 该模块接收尺度融合后的特征，输出交给任务感知注意力。
Method · πC

任务感知注意力：动态开关特征通道

Task-aware Attention
πC(F) · F = max( α1(F) · Fc + β1(F),   α2(F) · Fc + β2(F) )
Fc 是第 c 个通道上的特征切片；[α1, α2, β1, β2]T = θ(·) 是学习激活阈值的超函数。θ(·) 与 Dynamic ReLU 一脉相承：先在 L×S 维度上全局平均池化降维，再接两个全连接层与一个归一化层，最后用平移 sigmoid 把输出归一到 [−1, 1]。

算例：设某通道特征切片 Fc = 1，超函数输出 α1 = 0.5、β1 = 0.2、α2 = −0.3、β2 = 0.4。第一条分支 0.5 × 1 + 0.2 = 0.7；第二条分支 −0.3 × 1 + 0.4 = 0.1；取 max 后该通道输出 0.7。两条仿射分支中哪条占优由输入统计动态决定，通道因此被按需「打开」或「关闭」，呈现分段线性的任务自适应特性。

该模块部署在串联注意力的末端，输出直接供分类、回归等下游任务分支使用。
Method · 整体范式

DyHead 块的堆叠与整体范式

Dynamic Head 整体范式：三种注意力各聚焦一个视角 —— 尺度感知、空间感知、任务感知；图底部还可视化了每类注意力前后特征图的改善
  • 任意骨干网络先提取特征金字塔，缩放对齐成三维张量后送入 DyHead；三个注意力按固定顺序串联即构成一个 DyHead 块，把统一注意力公式嵌套多次即可有效堆叠多个 πL、πS、πC 块。
  • 若干注意力块串联的输出可用于分类、中心与框回归等不同任务和表示。
  • 图底部的可视化：骨干输出的初始特征图因 ImageNet 预训练的域差异而噪声很大；经尺度感知注意力后对前景物体的尺度差异更敏感；再经空间感知注意力后变得更稀疏、聚焦到前景物体的判别性空间位置；最后经任务感知注意力后按下游任务需求重组出不同激活 —— 与块内「先尺度、再空间、后任务」的固定顺序相互印证。
Method · 块设计与接入

DyHead 块的详细设计与接入现有检测器

  • 图 (a)：各注意力模块的内部实现。
  • 一阶段检测器（图 b）：RetinaNet 这类通常在骨干后挂多个任务特定子网分别处理分类与回归；本文只接一条统一分支即可同时处理多个任务，得益于多重注意力机制，架构更简、效率更高。

Method · 统一视角

与其他注意力机制的联系：都只是子维度特例

Deformable

只建模 S 子维度

可变形卷积通过稀疏采样改进传统卷积的变换学习，可视为只建模了空间维度。它已被广泛用于检测骨干，但很少用在检测头；骨干中的可变形模块与 DyHead 互补。

Non-Local

只建模 L × S 子维度

Non-Local Networks 用点积形式融合不同空间位置的特征来增强像素特征，可视为只建模了层级与空间两个维度。

Transformer

只建模 S × C 子维度

Transformer 用多头全连接层学习跨注意力对应、融合不同模态特征，可视为只建模了空间与通道两个维度。

这三类注意力都只部分建模了特征张量的子维度；DyHead 把不同维度上的注意力合并成一个连贯且高效的实现，并显式对应检测任务的三类挑战 —— 相比之下既有方案的工作原理是隐式的。这正是实验部分显著收益的来源。

Experiments · Setup

实验设置

数据与指标

MS COCO 2017

· 80 类、约 160K 张网络图像；train2017 / val2017 / test2017 分别含 118K / 5K / 41K 张。
· 所有实验只用 train2017 训练、不使用任何额外数据；消融在 val2017 上评测，与 SOTA 对比时报告 test 服务器返回的 test-dev 官方结果。
· 指标为 COCO 风格 AP，含 AP、AP50、AP75、APS、APM、APL。

框架与训练

基于 Mask R-CNN benchmark 实现

· DyHead 块以插件形式实现；未特别说明时用 ATSS 训练框架。
· 单计算节点 8 张 V100 32GB；消融全部用 ResNet-50 + 标准 1x 配置，其余模型用 2x。
· 初始学习率 0.02、weight decay 1e−4、momentum 0.9，学习率在训练轮次的 67% 与 89% 处乘 0.1。
· 增强只用随机水平翻转；为与多尺度输入方法对比，部分模型采用多尺度训练。

推理与「不用 trick」声明：与使用测试时增强的方法对比时采用多尺度测试；未使用 model EMA、mosaic、mix-up、label smoothing、soft-NMS 或自适应多尺度测试等技巧 —— 因此精度增益可归因于 DyHead 本身。

Experiments · 消融 1/3

注意力模块消融：逐个加到基线上

  • 表中 L. / S. / C. 分别代表尺度感知、空间感知、任务感知注意力模块，基线为三者全关的 39.0 AP。
  • 单独加入三者分别带来 0.9 AP（39.9）、2.4 AP（41.4）、1.3 AP（40.3）的提升；同时加入 L. 与 S. 可提升 2.9 AP（41.9）。
  • 三者全部加入后基线从 39.0 AP 提升到 42.6 AP（+3.6 AP），AP50 从 57.2 升到 60.1，APS 从 22.1 升到 26.1。
  • 空间感知增益最大，与其在三个维度中占据主导地位相符；不同组件作为连贯模块协同工作，而非简单叠加。
DyHead 块中各注意力模块有效性的消融：全开时 42.6 / 60.1 / 46.4 的 AP / AP50 / AP75，相比基线 +3.6 AP

Experiments · 消融 2/3

头部深度与效率：块数怎么定

  • 基线为 254.39 GFLOPs / 39.0 AP；控制 DyHead 块数量得到精度与计算开销的对比。
  • 2 个块（39.5 AP，−63.45 GFLOPs）就已超过基线且计算成本更低；4 个块达 42.0 AP、开销仍比基线低 20.97 GFLOPs —— 因为 DyHead 用一条统一分支替代了多个任务特定子网。
  • 6 个块时达到 42.6 AP 的峰值，GFLOPs 仅增加 21.50，相对骨干的计算量可忽略。
  • 继续加深到 8、10 块后精度饱和甚至回落（42.5、42.3 AP），而开销增至 +63.98、+106.46 GFLOPs —— 证明该方法的高效率。
堆叠不同数量 DyHead 块的效率与效果消融：6 块取得 42.6 AP 峰值且 GFLOPs 仅 +21.50，8/10 块精度饱和
Experiments · 消融 3/3

对现有检测器的泛化

  • 把 DyHead 插入 Faster R-CNN、RetinaNet、ATSS、FCOS、RepPoints 五种检测框架。
  • 它们覆盖了两阶段与一阶段、anchor-based 与 anchor-free、基于框与基于点的多种设定，是对「统一检测头」这一主张最直接的检验。
  • 结果：各类检测器一致获得 1.2 ∼ 3.2 AP 提升 —— ATSS 39.4 → 42.6（+3.2）增益最大，FCOS 38.8 → 40.0（+1.2）增益最小；Faster R-CNN +2.5、RetinaNet +2.7、RepPoints +1.4。
  • 值得注意的是 ATSS + DyHead 的 42.6 AP 与消融全开结果一致 —— 本文默认框架正是 ATSS。
DyHead 应用于主流检测方法时的泛化性消融：五种框架按 anchor-based/anchor-free、框/中心/关键点分组，全部获得 1.2 ∼ 3.2 AP 提升
Experiments · SOTA 1/2

与最先进方法的对比：不同骨干网络

  • COCO test-dev 上，DyHead 配 ResNet-50（1x）、ResNet-101（2x）、ResNeXt-64x4d-101（2x）分别取得 43.0 / 46.5 / 47.7 AP。
  • 对比对象包括 Mask R-CNN、Cascade-RCNN、FCOS、ATSS 与 BorderDet 等相近配置的方法，DyHead 一致以较大优势超出。
  • 与相同设置下此前最好的 BorderDet 相比：ResNet-101 骨干高出 1.1 AP（46.5 vs 45.4），ResNeXt-64x4d-101 骨干高出 1.2 AP（47.7 vs 46.5） —— 在 COCO 上这是显著的改进。
不同骨干网络在 MS COCO test-dev 上的对比：两阶段与一阶段方法按骨干与训练日程列出六项指标，DyHead 三行位于表末并全部领先
Experiments · SOTA 2/2

与最先进检测器的整体对比

  • 表中把已有工作分成两类：仅多尺度训练，以及多尺度训练 + 多尺度测试。
  • 在仅多尺度训练的一组中，DyHead 用 2x 训练日程取得 52.3 AP 的新纪录，且训练时间只有 EfficientDet（∼50x）与 SpineNet（∼40x）的 1/20。
  • 相比 DETR、Deformable DETR、RelationNet++ 这些以 Transformer 模块做注意力的最新工作，DyHead 高出 2.0 AP 以上（52.3 vs Deformable DETR 50.1），且训练时间更短。
  • 再加入多尺度测试后达到 54.0 AP（AP50 72.1 / AP75 59.3 / APL 66.3），领先同期最好方法 1.3 AP。
MS COCO test-dev 上与最先进结果的对比：DyHead 以 ResNeXt-64x4d-101-DCN + 2x 取得 52.3 AP，加多尺度测试后达 54.0 AP
Experiments · 附录

与 Transformer 骨干和额外数据的对比

COCO 验证集上与 Transformer 骨干结果的对比：DyHead 配 Swin-T 用 2x 日程取得 49.7 AP，比框架原本的 ATSS 基线（Swin-T 3x，47.2）高 2.5 AP，并以更短训练日程接近需要额外 mask 标注的 Cascade Mask R-CNN（Swin-T 3x，50.4）—— 说明 DyHead 与 Transformer 骨干互补。
COCO test-dev 上与最新方法的对比（† 表示使用额外数据）：把输入最大边长从 1333 增至 2000（多尺度训练最短边 480–1200）后，DyHead 配 Swin-L 取得 58.7 AP，训练时间不到同类工作的 1/3；再用自训练在 ImageNet 上生成伪标签作额外数据，进一步推至 60.6 AP 的 COCO 新纪录。
Summary

优点和创新点

1

统一框架，解释力强

把尺度、空间与任务感知统一为三维张量上的注意力学习，将 Deformable、Non-Local 与 Transformer 收纳为子维度特例。

2

即插即用，效率高

作为插件块可接入一阶段与两阶段等各类检测器并一致带来 1.2 ∼ 3.2 AP 提升；2 个块即超基线且计算更低，6 个块的额外开销相对骨干可忽略。

3

简化头端设计

用单一统一分支替代多个任务特定子网，同时完成分类与回归等任务，简化了一阶段检测器的头端设计，对 YOLO 系列的检测头轻量化改造具有直接借鉴意义。

4

实验丰富，说服力强

消融、可视化、泛化与 SOTA 对比环环相扣，在 COCO test-dev 上取得 54.0 AP 并推至 60.6 AP 新纪录。
