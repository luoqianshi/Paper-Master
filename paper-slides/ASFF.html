PAPER READING arXiv 2019
ASFF
Learning Spatial Fusion for
Single-Shot Object Detection

自适应空间特征融合以数据驱动的方式学习空间融合权重，在逐位置过滤冲突信息后再组合多层特征，把加强版 YOLOv3 从 38.8% 提升到 40.6% AP。

Songtao Liu · Di Huang · Yunhong Wang
北京航空航天大学
特征融合 目标检测 自适应加权 YOLOv3
Contributions

核心贡献：逐位置自适应空间特征融合

01

空间过滤冲突信息

用 softmax 归一化的可学习权重图对各层特征逐位置加权求和，携带矛盾信息的位置被过滤。

02

梯度一致性理论

从梯度角度分析融合的一致性性质，说明权重系数能在保留背景监督的同时调和正负梯度冲突。

03

仅增加 2 ms

AP 从 38.8% 提升到 40.6%，仅增加约 2 ms 推理时间、保持 46 FPS，是当时最好的速度-精度权衡之一。

在 COCO test-dev 上以 45 FPS 取得 42.4% AP、以 29 FPS 取得 43.9% AP，输入分辨率越低、基线越弱，ASFF 的增益越显著。

Motivation

特征金字塔的跨尺度不一致问题

A

特征冲突

某个目标在某一层被当作正样本时，它在其余各层对应区域被视为背景；这种特征冲突占据金字塔大部分区域，干扰训练期的梯度计算。

B

现有方法的代价

ignore 区域策略丢弃背景监督易引入误检；TridentNet 放弃金字塔；图像金字塔推理时间急剧增加。暂无方法能在保留金字塔的前提下过滤冲突信息。

问题收窄为：暂未有工作能在保留特征金字塔结构的前提下，于特征融合阶段自适应地过滤跨尺度的冲突信息。

Method 01

ASFF 总体流程：resize + 自适应融合

对 level l，其余各层特征先被 resize 到相同形状，再与权重图 α、β、γ 逐位置相乘后求和。 上采样用 1×1 卷积 + 插值，1/2 下采样用 stride 2 的 3×3 卷积，1/4 下采样在 stride 2 卷积前加 max pooling。
Method 02

空间加权的自适应融合公式

融合公式

ylij = αlij · x1→lij + βlij · x2→lij + γlij · x3→lij

α、β、γ 是三个层到 level l 的空间重要度权重，跨通道共享的标量。

softmax 权重定义

αlij = eλlαij / (eλlαij + eλlβij + eλlγij)

λα、λβ、λγ 是控制参数图，分别用 1×1 卷积从各层 resize 特征计算得到，经标准反向传播学习。

Method 03

梯度一致性：ASFF 如何调和冲突

逐元素相加/拼接

梯度直接相加

  • ∂L/∂x1ij = ∂L/∂y1ij + ∂L/∂y2ij + ∂L/∂y3ij
  • 正负梯度直接相加，扰乱更新方向
  • ignore 区域虽消除冲突，却丢掉背景监督
ASFF

加权调和

  • ∂L/∂x1ij = α1ij·∂L/∂y1ij + α2ij·∂L/∂y2ij + α3ij·∂L/∂y3ij
  • α2ij → 0 时负梯度被权重压制
  • 背景监督信息仍保留，避免更多误检

融合参数由标准反向传播学习，充分训练后即可产出有效系数，在不丢弃监督的前提下调和正负梯度冲突。

Experiments 01

消融实验：各组件的逐级贡献

  • 基线（BoF + GA + IoU）达到 38.8% AP、50 FPS
  • ignore 区域过大（ε=0.5）时 AP 反而跌到 37.5
  • 逐元素相加与拼接拉低 AP_L
  • ASFF 把 AP 从 38.8% 提升到 40.6%，AP_S 与 AP_M 各增 2.9 点，仅 +2ms
Experiments 02

COCO test-dev：精度-速度领先

YOLOv3 @608 + ASFF* 取得 42.4% AP 与 45.5 FPS，@800 档 43.9% AP，@320 档 38.1% AP 与 60 FPS， 把 YOLOv3 抬到与 FCOS、CenterNet、NAS-FPN 同级水平。
Experiments 03

权重图可视化：冲突信息被逐位置过滤

三只斑马都由 level 1 检出，其中心区域在 level 2 与 level 3 的融合中被过滤； 羊群由 level 3 检出，目标区域内保留 level 1 的强语义特征、目标周围保留 level 3 特征。
Experiments 04

跨骨干泛化：RetinaNet 上同样有效

ASFF 接到 RetinaNet 的 P3 到 P5 金字塔特征之后，ResNet-50 与 ResNet-101 骨干上 AP 分别提升 1.5 与 1.0 个点， 说明该策略与骨干网络无关。
Summary

优点和创新点

1

抓住核心矛盾

抓住特征金字塔跨尺度不一致这一核心限制，用逐位置可学习的 softmax 权重图空间过滤冲突信息，AP_S 与 AP_M 各提升 2.9 点而 AP_L 不受损。

2

可微端到端训练

融合操作设计为可微形式并与检测损失端到端联合训练，与骨干无关，在 YOLOv3 与 RetinaNet 上均稳定涨点，仅引入约 2 ms 开销。

3

理论与实验闭环

给出梯度层面的一致性推导与权重图、融合激活的可视化互证，机制解释与实验证据闭环完整。

ASFF：逐位置自适应空间融合

用可学习的 softmax 权重图逐位置过滤跨尺度冲突信息，
以仅 2ms 的代价把 YOLOv3 提升到当时最好的速度-精度权衡。
