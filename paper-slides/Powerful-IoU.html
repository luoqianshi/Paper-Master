Contributions

核心贡献：消除锚框膨胀 + 非单调聚焦机制

01

根因级膨胀分析

用梯度推导证明 GIoU、CIoU、EIoU、SIoU 四类损失的惩罚因子都以 最小外接框尺寸 为分母，导致锚框膨胀。

02

尺寸自适应惩罚因子

PIoU 惩罚因子 P 只用 目标框边长 作分母，天然免疫膨胀且自适应目标尺寸。

03

PIoU v2 非单调聚焦

仅一个超参数 λ 控制的注意力层，将最大梯度分配给 中等质量 锚框。

PIoU v2 在 YOLOv8 + COCO 上取得 AP75/AP/AP50 = 53.26/48.63/65.42，在全部损失函数中达到 SOTA。

Motivation

锚框膨胀：IoU 系损失的共同根源

GIoU、CIoU、EIoU、SIoU 引导的锚框在回归初期都 明显增大了面积（膨胀）， 而 PIoU 引导的锚框几乎沿直线路径逼近目标框，60 epochs 即可对齐。
Method 01

膨胀根源：惩罚项分母都依赖最小外接框

GIoU、DIoU、CIoU、EIoU 与 SIoU 的惩罚因子都用最小外接框的对角线、宽高或面积作分母； PIoU 只用目标框边长作分母，分母不随锚框变化。
Method 02

PIoU 的两个核心组件

组件一：尺寸自适应惩罚因子

P = (dw₁/wgt + dw₂/wgt + dh₁/hgt + dh₂/hgt) / 4

d 是预测框与目标框对应边之间距离的绝对值，wgt、hgt 是目标框宽高。分母只取决于目标框，膨胀不会改变 P。

组件二：质量自适应惩罚函数

f(x) = 1 − e−x²

LPIoU = LIoU + f(P),   0 ≤ LPIoU ≤ 2

f(x) 呈「两端小、中间大」的非单调形态，无需额外权重即实现按锚框质量的静态聚焦。

Method 02

惩罚函数按锚框质量自适应调节梯度

P 很大时（低质量）f'(P) 取 小值抑制有害梯度；P 在 1 附近（中等质量）f'(P) 达到 峰值加速回归；P 趋近 0（高质量）梯度逐渐减小，锚框稳定优化到完全对齐。
Method 02

函数形式的重要性：f(x) vs g₁(x) vs g₂(x)

g₁(x) = x²/2 梯度单调递增，会放大低质量锚框有害梯度；g₂(x) = 0.5x 梯度恒定，对质量无注意力； 只有 f(x) 呈现非单调形态，无需额外权重即实现质量自适应聚焦。
Method 03

PIoU v2：非单调注意力层增强聚焦

质量度量与注意力函数

q = e−P,   q ∈ (0, 1]

u(x) = 3xe−x²

LPIoU_v2 = u(λq) · LPIoU

λ 是唯一超参数，控制梯度峰值对应的锚框质量位置。λ 越大峰值越偏向低质量一侧。

Experiments 01

回归仿真：PIoU 收敛速度最快

1,715,000 个回归案例的仿真中，PIoU 的 LIoU 曲线下降最快， 60 epochs 即可实现锚框对齐，而其余 IoU 系损失通常需要 80-300 epochs。
Experiments 02

MS COCO + YOLOv8：PIoU v2 全面 SOTA

PIoU v2 取得 AP75/AP/AP50 = 53.26/48.63/65.42，在全部损失函数中 SOTA； 0.5% AP75、0.5% AP50、0.3% AP 的提升幅度明显高于其他损失之间的差距。 Focal-EIoU 相比 EIoU 全面下降，说明其注意力函数缺乏泛化性。
Experiments 03

DINO + VOC 与超参数敏感性消融

  • DINO-4scale + VOC：PIoU v2 以 70.50/64.23 的 AP75/AP 取得 SOTA，比原始 GIoU 提升 1.1% AP75、0.6% AP
  • IC SEM 数据集：PIoU v2 以 96.0/98.9 AP/AP75 保持最高
  • λ = 1.3 时最优（AP 50.43），偏大或偏小均掉点
Experiments 04

惩罚函数形式消融验证

f(x) 在 54.12/49.72/69.26 的三项指标上全面优于 g₁(x) 与 g₂(x)， 验证了「两端小、中间大」的非单调梯度形态比单调递增或恒定梯度更适合锚框回归。
Experiments 05

检测可视化：PIoU v2 对不完整目标更敏感

PIoU v2 能凭部分区域准确判断类别并定位（如只露出后半身的 elephants 与被遮挡的 horse）， Focal-EIoU 与 WIoU 则漏掉不完整目标或出现定位与分类错误。
Summary

优点和创新点

1

根因级膨胀分析

用梯度推导证明四类损失的惩罚因子都以最小外接框尺寸为分母，思路可迁移到新损失设计。

2

惩罚因子 + 函数联合设计

P 只用目标框边长作分母，配合 f(x) 无需额外权重即实现按质量的梯度调节。

3

单超参数非单调聚焦

PIoU v2 的注意力层仅一个 λ，调参成本低于 WIoU 的双超参数设计，在三个数据集上一致提升。

PIoU：更直接、更快的边界框回归

以目标框边长取代最小外接框作分母，
从根源消除锚框膨胀，用非单调聚焦提升回归质量。
