核心贡献：从惩罚因子的分母下手

01

根因分析：锚框为什么会膨胀

分析 IoU 系损失中锚框膨胀的成因，系统考察惩罚项的惩罚因子与函数形式，指出分母依赖最小外接框尺寸是共同根源。

02

PIoU 损失

以具有良好特性的惩罚因子 P 配合基于锚框质量的梯度调节函数 f(x)，有效解决锚框膨胀，收敛速度快于现有 IoU 系损失。

03

PIoU v2：单超参数非单调注意力层

设计仅由一个超参数 λ 控制的非单调注意力层并与 PIoU 结合，增强对中等质量锚框的聚焦能力，调参成本低于 WIoU 的双超参数设计。

04

SOTA 验证

把 PIoU v2 集成进 YOLOv8 与 DINO，在 MS COCO、PASCAL VOC 与自建 IC SEM 三个数据集上取得所有对比损失中最高的检测精度。

Motivation · 1/2

BBR 损失的演进：从范数类到 IoU 系

  • ln-norm 类损失把 xywh 四个回归量当独立变量处理，忽略变量之间的相关性，且对目标尺度敏感。YOLOv1 预测宽高的平方根、Fast R-CNN 用 l1-smooth 抗离群值，都只是缓解，精度提升有限。
  • IoU 损失把预测框的四条边界当作整体回归：LIoU = 1 − I/U，解决了相关性问题；但当两框没有重叠时，LIoU 的梯度会消失。
  • IoU 系改进围绕惩罚项展开：GIoU 补上无重叠时的梯度，DIoU 直接最小化中心点归一化距离，CIoU 再加长宽比惩罚，EIoU 把长宽比换成更直接的宽高差，SIoU 从角度、形状、距离三方面设计惩罚项。
  • 被忽略的问题：改进都集中在惩罚项的形式上，惩罚因子本身是否合理长期没被追问。CIoU 与 EIoU 虽然承认了锚框膨胀现象，却没有找到根因、也没有解决它。
Motivation · 2/2

本文要同时解决的两个瓶颈

瓶颈一

惩罚因子不合理 → 锚框膨胀

  • 大多数惩罚项以预测框与目标框最小外接框的对角线长度或面积作为分母。
  • 仿真实验观察到：即使预测框面积已经大于目标框，多数损失仍然促使它继续增大面积。
  • 这种回归路径迂回而缓慢，需要更多训练轮次才能收敛。
  • 部分惩罚项在特定情形下会退化，无法真实反映两框之间的差异。
瓶颈二

聚焦机制利用不足

  • Focal-EIoU 引入回归版 Focal Loss，但注意力函数 IoUτ 单调递增，只放大高质量锚框的梯度，未能充分发挥注意力机制的潜力。
  • WIoU 用 batch 内平均质量做基准，实现了动态非单调聚焦，却依赖 δ 与 ε 两个难以确定的超参数，不同数据集上都难以调定。
  • BBR 中高质量实例远少于低质量实例，聚焦机制本应把梯度分给最该优化的那批锚框。

Method · 根因分析

锚框膨胀的根源：三类惩罚项的梯度

GIoU

RGIoU = (A − U)/A

∂R/∂A = U/A²，∂R/∂U = −1/A。两框不重叠时 U < A，于是 |∂R/∂U| > |∂R/∂A|：A 与 U 同增反而使 RGIoU 下降。预测框不向目标移动、仅靠自我膨胀就能减小惩罚。

CIoU / EIoU

RD = d²/c²

∂RD/∂d = 2d/c²，c 增大时 RD 减小。两框不重叠、LIoU 不变的情况下，单纯放大预测框就能降低损失 —— 用 c 作分母不合理。

SIoU

距离成本 Δ

∂Δ/∂wc = −e−γwI · γwI / wc² 为负；wc、hc 增大时 Δ 下降，膨胀问题依然存在。

共同根源：惩罚项的分母都依赖最小外接框的尺寸。除此之外还有各自的退化问题 —— GIoU 在两框存在包含关系时 A−U = 0，退化成 IoU 损失；CIoU 的两项都不反映目标框尺寸变化；EIoU 的形状差项数值通常很小，梯度不足以阻止膨胀；SIoU 结构复杂且距离、形状成本都不自适应目标尺寸。

Method · 现象观察

不同损失引导的回归过程

  • 图中彩色框是各损失引导下、回归过程中不同时刻的锚框位置。

  • PIoU 引导的锚框几乎沿直线路径逼近目标框，在 60 epochs 时就对齐了目标。

Method · 组件一

尺寸自适应惩罚因子 P

惩罚因子
P = ( dw1/wgt + dw2/wgt + dh1/hgt + dh2/hgt ) / 4
dw1、dw2、dh1、dh2 是预测框与目标框对应两条宽边、两条高边之间距离的绝对值；wgt、hgt 是目标框的宽与高（几何示意见第 5 页图 (c)）。
性质 1

免疫锚框膨胀

分母只取决于目标框的大小，与最小外接框无关 —— 锚框膨胀不会改变 P。

性质 2

不退化

只要预测框与目标框不完全重合，P 就不会退化为 0，始终真实反映两框差异。

性质 3

目标尺寸自适应

逐边除以目标框边长的写法，使 P 对目标尺寸具有自适应性，直接度量四条边的对齐程度。

P 解决的是「用什么来度量差距」；而惩罚项的梯度该有多大，由下一个组件 —— 惩罚函数 f(x) 决定。

Method · 组件二

质量自适应惩罚函数与 PIoU 损失

f(x) = 1 − e−x²   →   LPIoU = 1 − PIoU = LIoU + f(P)，  0 ≤ LPIoU ≤ 2
x 取惩罚因子 P 的值，锚框质量越高 P 越小；PIoU = IoU − f(P)，−1 ≤ PIoU ≤ 1。等价于在 IoU 损失上叠加一个有界的非单调惩罚项。
低质量、中等质量、高质量三种锚框的 LIoU、LPIoU 与梯度 f′(P)。P > 2 时 f′(P) 取小值以抑制有害梯度；P ≈ 1 时达到峰值以加速回归；P → 0 时梯度渐减以稳定对齐。算例：LIoU = 0.750、P = 0.5 → f(0.5) = 1 − e−0.25 ≈ 0.221，LPIoU = 0.971；梯度 f′(P) = 2Pe−P² ≈ 0.779，正处于峰值附近 —— 中等质量锚框同时获得可观惩罚量与接近最大的梯度。
Method · 函数形式

为什么是 f(x)：三种函数形式对照

g1(x) = x²/2，  L1 = LIoU + g1(P)   |   g2(x) = 0.5x，  L2 = LIoU + g2(P)
原文用同一个惩罚因子 P 配另外两个函数做对照，以隔离「函数形式」这一个变量的影响。
f(x)

两端小、中间大 ✓

非单调形态，无需任何额外权重就实现了按锚框质量的静态聚焦，且值域有界、优化稳定。

g1(x)

单调递增 ✗

梯度随锚框质量变差而增大，会把低质量锚框的有害梯度放大。

g2(x)

恒定 ✗

梯度恒定不变，对锚框质量毫无注意力，等于没有聚焦机制。

三种惩罚函数 f(x)、g1(x)、g2(x) 及其导数的图像：(a) 函数值，(b) 梯度 —— 只有 f(x) 的导数呈现「两端小、中间大」
Method · PIoU v2

非单调聚焦机制与 PIoU v2

q = e−P，  q ∈ (0, 1]
u(x) = 3x · e−x²
LPIoU_v2 = u(λq) · LPIoU = 3(λq) e−(λq)² · LPIoU
q 度量锚框质量：q = 1 即 P = 0，两框完全重合；P 越大 q 越小、质量越低。λ 是唯一需要调节的超参数。
  • 注意力层把最大梯度分配给中等质量锚框，同时抑制低质量锚框的有害梯度。
  • λ 决定梯度峰值对应的锚框质量位置：λ 越大，峰值越偏向低质量一侧。
  • 相比 WIoU 的 δ、ε 双超参数，PIoU v2 只需调一个 λ，简化了调参过程。
不同超参数 λ 下注意力函数 u(λx) 的图像：λ 越大，梯度峰值越偏向低质量锚框一侧

Summary

优点和创新点

1

根因级分析，双重验证

对锚框膨胀现象给出了根因级分析：用梯度推导证明四类代表性损失的惩罚因子都以最小外接框尺寸为分母，再以数值反例与百万例回归仿真双重验证，思路可迁移到新损失的设计中。

2

分母换掉，膨胀自然消失

惩罚因子 P 只用目标框边长作分母，天然免疫锚框膨胀且自适应目标尺寸；配合 f(x) 无需额外权重即实现按锚框质量的梯度调节，设计巧妙。

单超参数，跨检测器一致提升
