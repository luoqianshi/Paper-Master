FreqFusion:
Frequency-Aware Feature Fusion
for Dense Image Prediction

用频率视角统一特征融合的两大缺陷——对类内不一致做低通减法，对边界位移做高通加法

Linwei Chen · Ying Fu · Lin Gu · Chenggang Yan · Tatsuya Harada · Gao Huang 北京理工大学 · RIKEN AIP / 东京大学 · 杭州电子科技大学 · 清华大学

Overview · Contributions

核心贡献

01

特征相似性分析

把「类内不一致」与「边界位移」从经验观察升级为可量化的指标（IntraSim、SimMargin、SimAcc），设计前定位问题、设计后验证收益，形成完整闭环

02

频率视角统一两大缺陷

类内不一致 = 无效高频过剩 → ALPF 做减法；边界位移 = 有效高频缺失 → AHPF 做加法，一低一高互补

03

偏移重采样居中协调

沿局部相似度方向重采样，用一致特征替换不一致特征，兼顾大面积不一致区域与细窄边界

04

四大任务全面领先

在语义分割、目标检测、实例分割、全景分割上全面超越 CARAFE、FADE、SAPA 与 DySample 等先前最优方法

Motivation

研究动机：标准特征融合的两大缺陷

  • 现代分层架构多次下采样，边界细节持续丢失 → 特征融合把深层粗糙特征（类别信息）与浅层高分辨率特征（边界细节）相加或拼接
  • 标准融合只是把深层特征用最近邻 / 双线性插值放大后直接叠加，存在两个长期未被清晰定义的缺陷：
  • 类内不一致：物体各部件（车轮 vs 车窗）特征本就差异明显，插值把单个不一致特征复制到多个像素，受扰动的高频进一步压低类内相似度 → 物体内部错分
  • 边界位移：插值倾向过度平滑，边界缺乏准确高频成分 → 预测边界偏移
  • 此前工作只有经验观察，缺少可量化度量的支撑
特征类内相似度（IntraSim）与预测可视化：标准融合物体内部 IntraSim 低、边界模糊位移；FreqFusion 特征更一致、边界更清晰
Method · Feature Similarity Analysis

特征相似性分析：把缺陷变成标尺

类内相似度 · IntraSim

IntraSim(Y) = CosSim(Y, 类别中心)

特征向量与其类别中心的余弦相似度 · 类间相似度 InterSim 同理（中心换成另一类）

相似度裕度 · SimMargin

SimMargin(Y) = IntraSim(Y) − InterSim(Y)

另按最近类别中心归类统计出相似度精度 SimAcc

直观上：类内相似度低 → 物体内部特征涣散；裕度小 → 特征靠近类别边界、容易错分。三个指标共同构成衡量特征判别力的标尺，贯穿全文的设计与验证

类内相似度、类间相似度与相似度裕度的示意：不同颜色代表不同类别
Method · Overview

总体结构：从标准融合到频率感知融合

标准特征融合

Yl = FUP(Yl+1) + Xl

FUP：2× 最近邻 / 双线性插值

FreqFusion

Yli,j = Ỹl+1i+u,j+v + X̃li,j

Ỹl+1 = FUP(FLP(Yl+1)) 低通平滑后上采样 · X̃l = FHP(Xl) + Xl 高通残差增强 · (u,v) 为偏移

  • 三个生成器都以压缩融合特征 Zl 为输入：Zl = FUP(Conv1×1(Yl+1)) + Conv1×1(Xl)，r 为通道压缩率
FreqFusion 整体结构：初始融合 + 最终融合两级，初始融合中的 ALPF / AHPF 生成器与最终融合共享参数
Method · Enhanced Initial Fusion

初始融合的增强

  • 次优 ①：朴素初始融合仍用简单插值上采样压缩特征，继承边界模糊问题
  • 次优 ②：频率分析显示 ALPF 生成器强烈依赖 Zl 中的高频，而传统卷积层只能捕获固定模式的高频
  • 方案：把最终融合的 ALPF / AHPF 生成器复用到初始融合（共享参数）——初始低通核借浅层高分辨率结构引导上采样，初始高通核动态补频
  • 增强后的中间特征边界更清晰，预测的低通滤波器在边界处方差更小——滤波器能更有效地「守住」边界，为三个生成器提供更可靠的输入
ALPF 生成器学到的卷积核（a）及其傅里叶频谱（b/c）：高频段功率更高，印证其对特征高频信息的依赖
Method · ALPF Generator

ALPF 生成器：空间可变的低通滤波上采样

滤波器预测

W̄l,p,qi,j = Softmax(Conv3×3(Zl))

kernel-wise softmax 约束每个位置的滤波器权重全正且和为 1 → 天然是平滑的低通滤波器

  • 把 W̄l 按 pixel unshuffle 分成 4 组，各自与深层特征卷积，再 Pixel Shuffle 重排成 2× 上采样结果
  • 类内相似度 0.727 → 0.799、相似度精度 0.918 → 0.941，特征更一致
  • 但对大面积不一致区域与细窄边界仍有限 → 引出偏移生成器
类内相似度可视化：(a) 双线性内部涣散、边界位移 → (b) +ALPF 一致性与锐度同步改善 → (c) +Offset 进一步增强
Method · Offset Generator

Offset 生成器：沿局部相似度重采样

  • 两难：低通核大 → 能修大面积不一致但伤细边界；核小 → 反之
  • 观察：类内相似度低的特征，其邻居中往往存在相似度高的特征 → 重采样「就地取材」
偏移预测

Ol = Dl · Al

Dl = Conv3×3(Concat(Zl, Sl)) 方向 · Al = Sigmoid(Conv3×3(Concat(Zl, Sl))) 幅度 · Sl：与 8 邻域像素的局部余弦相似度

  • 类内相似度 0.760 → 0.799，边界相似度精度 0.720 → 0.728
局部相似度引导偏移指向：采样方向始终偏向类内相似度更高的一侧
偏移场可视化：内边界偏移指向一致的内部、外边界指向相反方向，一推一拒使边界更清晰
Method · AHPF Generator

AHPF 生成器：补回下采样丢失的高频

  • Nyquist-Shannon 采样定理：下采样时高于奈奎斯特频率（采样率一半）的分量被混叠并永久丢失——2× 下采样后高于 1/4 的频率全部损失，无法从深层特征找回
高通滤波预测

Ŵl,p,qi,j = E − Softmax(Conv3×3(Zl))

先用 softmax 造低通核，再用恒等核 E（中心 1、其余 0）反转 → 结果必为高通核；增强后残差并回：X̃li,j = Xli,j + Σ Ŵ · Xl

数值例子：softmax 输出低通核 [[0.1, 0.2, 0.1], [0.2, 0.2, 0.2], [0.1, 0.2, 0.1]]，用 E 减去它得 [[−0.1, −0.2, −0.1], [−0.2, 0.8, −0.2], [−0.1, −0.2, −0.1]]——9 个权重之和为 0，直流分量完全抵消，只保留邻域差分信号，正是高通特性

浅层特征增强前后对比：巴士轮廓与人物头部等边界细节明显更清楚

Experiments · Semantic Segmentation

语义分割：ADE20K 全面领先

  • SegFormer-B1 上取得 44.5 mIoU / 32.8 bIoU，较基线提升 2.8 mIoU，领先第二名 Dysample-S+ 达 1.2 mIoU
  • SegNeXt-T 跨库验证：Cityscapes +1.0、ADE20K +2.4、COCO-Stuff +2.0 mIoU，仅增加 0.18M 参数 / 0.44G FLOPs
  • 推理 23.0 FPS，与最快的 Dysample（25.9 FPS）接近，但涨点（+2.4 对 +1.1 mIoU）高出一倍多——精度收益远大于速度代价
ADE20K 验证集与近期最优方法对比：FreqFusion 以 +0.34M 参数取得 44.5 mIoU
Experiments · Generalization

结构不挑剔：跨解码器与跨数据集

与 UPerNet / SegFormer / SegNeXt 组合（Cityscapes）：三种解码器均 +1.0 以上 mIoU，参数与 FLOPs 增加极少
SegNeXt-T 在 Cityscapes / ADE20K / COCO-Stuff：80.8 / 43.5 / 40.7，全部稳定涨点

CNN（UPerNet）与 Transformer（SegFormer）结构差异巨大，FreqFusion 无需改动主结构即可无缝插入，泛化能力出色

Summary · Strengths

优点与创新点

01

问题量化闭环

特征相似性分析（IntraSim、SimMargin、SimAcc）把两大缺陷升级为可量化问题——设计前定位问题、设计后验证收益，说服力强

02

频率视角统一矛盾

无效高频过剩做 ALPF 减法、有效高频缺失做 AHPF 加法、偏移重采样居中协调——一低一高的互补设计十分巧妙

03

即插即用泛化出色

不改动主干，仅 +0.18M 参数即可在 CNN 与 Transformer 两类解码器、四大密集预测任务上一致涨点，实验丰富、可直接复用
