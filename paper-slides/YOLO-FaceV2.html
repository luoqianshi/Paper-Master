YOLO-FaceV2
A Scale and Occlusion Aware Face Detector

针对人脸尺度变化、遮挡与难易样本不平衡，提出 RFE 感受野增强、SEAM 遮挡感知注意力与 SWF 滑动权重函数，在 YOLOv5 上构建实时人脸检测器。

Ziping Yu · Hongbo Huang · Weijun Chen · Yongxin Su · Yahui Liu · Xiuying Wang
北京信息科技大学 · 蔚来数据算法部门
人脸检测尺度感知遮挡感知Pattern Recognition 2024
Contributions

三个模块分别对准三类人脸难题

01

RFE 感受野增强

共享权重的多分支空洞卷积提取多尺度像素信息，配合有效感受野设计的 anchor 与 NWD 度量应对小脸。

02

SEAM 遮挡感知注意力

利用特征图之间的关系召回被遮挡的特征，配合 Repulsion Loss 降低检测器对 NMS 的敏感。

03

SWF 滑动权重函数

以单一阈值 μ 与分段指数加权实现难易样本的自适应加权，避开众多超参数。

WiderFace 验证集 easy/medium/hard 取得 98.6% / 97.9% / 91.9%，超过此前 SOTA 2.3 / 2.5 / 1.1 个百分点；FDDB 98.71% mAP。

Method 01

YOLO-FaceV2 网络架构

骨干 CSPDarknet53 的 P5 层 C3 块替换为 RFE；P2 层并入 PAN 提升小脸检测精度；颈部之后引入 SEAM 模块增强对遮挡人脸的响应。
Method 02

RFE 模块与有效感受野 Anchor 设计

  • RFE 以 dilation rate 1/2/3 的 3x3 空洞卷积 + 平均 pooling 构成四分支，共享权重减少参数
  • 依据有效感受野近似高斯形状的结论重新估计 anchor 尺寸
  • 宽高比设为 1:1.2，P2/P3/P4 步长 4/8/16
  • NWD 对小目标不敏感，与 IoU 按 1:1 组合互补
Method 03

SEAM：遮挡感知注意力与 Repulsion Loss

  • SEAM 第一部分：带残差的深度可分离卷积逐通道学习
  • 第二部分：1x1 卷积组合 + FC 聚合通道信息，指数变换扩展到 [1, e]
  • RepGT 使预测框远离周围真值框，RepBox 降低预测框之间 IoU
  • 两者缓解拥挤场景中被遮挡人脸的误检与漏检
Method 04

SWF 滑动权重函数：自适应难样本加权

取 IoU 均值 μ=0.5 为阈值：IoU=0.3 的简单样本权重 1；IoU=0.45 的边界样本权重 e0.5 ≈ 1.65； IoU=0.9 的正样本权重 e0.1 ≈ 1.11，难分类边界样本的相对损失抬到约 1.65 倍。
Experiments 01

实验设置：数据集与 Anchor 配置

  • 主要在 WiderFace 上进行：训练集训练、验证集评测，easy/medium/hard 对应大、中、小人脸，hard 召回率超 90% 即认为性能相当好
  • FDDB 含 2845 张图像、5171 张人脸，姿态角度困难、失焦与遮挡广泛，mAP 达 95% 以上即认为遮挡问题被有效解决
  • 以 YOLOv5 为基线、PyTorch 实现，数据增强与训练超参与 YOLOv5 相同
  • ImageNet 预训练后，以 batch size 16 在 3090Ti 上微调约 50 个 iteration

anchor 按 1:1.2 宽高比与有效感受野收缩后的尺寸估计得到，P2/P3/P4 尺寸随步长 4/8/16 逐级翻倍——anchor 先验与三层检测头一一对应。

Experiments 02

WiderFace 对比：三子集全面 SOTA

  • YOLO-FaceV2l 在 easy/medium/hard 取得 98.6% / 97.9% / 91.9%，超过此前 SOTA 2.3 / 2.5 / 1.1 个百分点
  • 参数量大于 3M、FLOPs 大于 5G 的 YOLO 系模型中全面领先 YOLOv5l-Face 与 YOLOv7
  • hard 子集略逊于采用两阶段分类与回归的 RetinaNet 系最佳检测器，但后者以更多计算资源为代价
  • FDDB 不重训即取得 98.71% mAP，超过 PyramidBox 的 0.9869 与 YOLO5Face 的 0.9843，达到 SOTA
各检测器的 PR 曲线（原文 Fig 6）：小、中子集上超过 SOTA，hard 子集优于 YOLO 系方法——与正文数值互相印证。
Experiments 03

模型规模扩展：精度随容量持续上升

各档模型规模的 WiderFace 精度对比（原文 Table 6）：按 nano、small、medium、large 四档扩展，精度随参数增加持续上升（hard 子集从 0.812 升到 0.919），架构的容量潜力仍未释放完毕。
Experiments 04

消融实验：尺度、遮挡、样本不平衡三组独立验证

  • 尺度消融：RFE + P2 并入 PAN + 有效感受野 anchor，hard 提升 0.9%
  • 遮挡消融：SEAM 超过 SE、CBAM、EMA；Repulsion Loss 分别提升 0.71%/0.63%/0.5%
  • 组合消融：SWF+RFE+SEAM 依次叠加，三子集达 98.39/97.07/89.39
Experiments 05

组合消融：三模块增益稳定叠加

  • 样本不平衡与模块组合消融（原文 Table 5）：SWF 单独加入即提升 medium 与 hard 子集
  • 四个变体从 96.30、94.71、86.11 逐步升到 98.39、97.07、89.39
  • SWF、RFE、SEAM 依次叠加，三个模块均带来正向增益

三个模块的增益可以稳定叠加。

Experiments 06

遮挡人脸热力图：逐级召回被遮挡的人脸

基线没有注意到被手臂遮挡的脸；加入 Repulsion Loss 后该脸被检出；加入 SEAM 后每张脸都获得聚焦响应。 所有被遮挡的脸都被召回。
Summary

优点和创新点

1

问题-模块映射清晰

RFE、SEAM、SWF 分别对准尺度、遮挡、样本不平衡，消融独立自证。

2

有效感受野理论落地

将有效感受野理论引入 anchor 尺寸估计，以高斯分布形状重估离散 anchor，设计依据扎实。

3

SWF 简单高效

以单一阈值 μ 与分段指数加权实现难易样本自适应加权，避开众多超参数。

YOLO-FaceV2：尺度 + 遮挡 + 不平衡

用 RFE、SEAM、SWF 三个模块统一应对人脸检测的三类难题，
以单阶段架构达到 WiderFace SOTA。
