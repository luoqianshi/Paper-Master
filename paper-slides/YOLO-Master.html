YOLO-Master

MOE-Accelerated with Specialized Transformers for Enhanced Real-time Detection

把混合专家（MoE）条件计算引入 YOLO 流水线，按场景复杂度动态分配计算资源， 在 MS COCO 上以 1.62 ms 延迟取得 42.4% AP。

Xu Lin · Jinlong Peng · Zhenye Gan · Jiawen Zhu · Jun Liu arXiv:2512.23273

Motivation

研究动机：静态密集计算的代价

实时目标检测广泛服务于自动驾驶、视频监控与机器人系统，YOLO 系列凭借单阶段框架长期占据主导地位。 但是，现有 YOLO 架构全部采用静态密集计算——无论输入简单还是复杂，所有特征都流经完全相同的网络通路、消耗统一的计算资源。
起因

静态密集计算

计算预算与网络容量在设计阶段即被固定，与输入内容无关

→
后果

资源错配

简单场景计算冗余，复杂场景表征容量不足

→
表现

性能与效率同损

为复杂城市场景设计的模型在简单高速路上过参数化，反之容量不足

Insight

来自大语言模型的启示

LLM 研究揭示：不同输入选择性地激活不同的参数子集（稀疏激活），可以同时改善效率与适应性。

  • 历代 YOLO 改进集中在骨干结构、多尺度融合与训练策略的静态设计，缺乏按输入特性分配资源的机制
  • 这一条件计算范式尚未在轻量级 CNN 实时检测器上得到系统验证
  • 暂未有工作把混合专家框架引入实时目标检测，依据场景复杂度自适应地分配计算资源

本文切入点：把 MoE 条件计算植入 YOLO 流水线，让简单输入走短路径、复杂输入获得大容量。

Contributions

核心贡献

01

首个面向 RTOD 的 MoE 框架

把 MoE 条件计算引入实时目标检测，通过动态专家激活使模型容量适配输入复杂度，突破静态精度-效率权衡。

02

ES-MoE 模块

多尺度专家 + 动态路由网络：训练用软 Top-K 保持梯度流动，推理用硬 Top-K 实现真实稀疏，训练稳定且部署高效。

03

负载均衡监督

面向检测任务定制的均衡损失抑制专家坍缩，训练期间保持均匀的专家利用，且不牺牲推理稀疏性。

04

五基准 SOTA

COCO 42.4% AP @ 1.62 ms，超 YOLOv13-N 0.8% mAP 且推理快 17.8%；VisDrone、KITTI 增益最大。

Method

YOLO-Master 整体框架

左上：骨干与颈部插入 ES-MoE 的 Backbone-Neck-Head 主干通路；左下：ES-MoE 内部信息流；右侧：动态路由网络在标准 Softmax、软 Top-K（训练）与硬 Top-K（推理）三种决策逻辑间切换。

Method

ES-MoE 信息流

给定输入特征图 X ∈ ℝC×H×W，路由网络产生路由特征，Softmax 门控计算各专家的权重分布，门控权重计算为：
wi = exp(gi(X))∑j=1E exp(gj(X)) ,  i = 1, 2, …, E
选出权重最高的 top-K 个专家（K ≪ E 保证稀疏），输出经加权聚合：
Y = Norm( ∑i∈TK wi · Experti(X) )
X ∈ ℝC×H×W输入特征图，C、H、W 为通道数、高与宽
E / gi(·)专家总数 / 第 i 个专家的门控函数
TK / Norm(·)top-K 专家索引集合 / 稳定聚合特征的归一化操作

直观上，每个输入只为自己「点名」少数最匹配的专家：简单输入路径短，复杂输入容量大。

Method

专家网络：多尺度感受野

每个专家以深度可分离卷积为基本构件，代替标准卷积，把空间滤波与通道整合解耦，大幅压缩参数量与 FLOPs：
Experti(X) = DWConvki, Cin→Cout(X)
  • 核大小 ki 取互不相同的奇数（3, 5, 7, …），让专家组覆盖从小到大一系列感受野
  • 即使 E 较大，专家网络整体的参数量与计算成本仍然可控，保持 Nano 级模型的轻量本 性
全部专家输出按路由权重 Ω = [ω1, …, ωE] 聚合成 ES-MoE 的最终输出：
YMoE = ∑i=1E ωi · Yi

这等价于用路由权重对一组多尺度滤波器做凸组合，比单一固定核卷积块更能自适应地聚合不同空间范围的上下文。

Method

门控网络：轻量路由决策

设计前提是路由决策本身不能成为计算瓶颈。先用全局平均池化把输入压缩成全局描述子，为整张特征图提供统一指引：
P = GAP(X) ,  P ∈ ℝC×1×1
再经两层 1×1 卷积（Cin → Cred → E）与 SiLU 激活生成 E 个专家的 logits：
Λ = Conv1×1out=E( SiLU( Conv1×1out=Cred(P) ) )
  • 通道缩减率 γ = 8，中间通道 Cred = max(C/γ, 8)，约束门控开销
  • 整条通路只作用于通道维，logits 计算量只依赖 C 与 E、与空间尺寸 H×W 无关

门控因此在骨干与颈部的高分辨率特征图上都能高效运行，随后交给分阶段路由策略完成专家选择。

Method

分阶段路由：软训练，硬推理

Training · 软 Top-K

梯度可流动的稀疏

  • logits 经 Softmax 得到选择概率 Ω′
  • 构造 top-K 二值掩码 MK，屏蔽非 top-K 项
  • 对非零权重重归一化得 Ωtrain（防除零项 ε）
  • 被选权重仍由 Ω′ 连续计算，梯度可流回门控网络
Inference · 硬 Top-K

真实的计算稀疏

  • 直接选 top-K logits，只对它们做 Softmax
  • 其余 E−K 个专家权重严格置 0
  • 前向传播只调用 K 个专家模块
  • 在实际硬件上获得确定性加速
算例 · E=4, K=2

Λ = [2.1, 0.9, 0.3, −0.5] → Softmax 得 Ω′ ≈ [0.65, 0.20, 0.11, 0.05] → 掩码 top-2 并重归一化 → Ωtrain ≈ [0.77, 0.23, 0, 0]：只有两个专家参与聚合，路由依然可微、可学习。

Method

损失函数与负载均衡

LTotal = LYOLO + λLB · LLB λLB > 0 控制均衡项权重
检测损失沿用 YOLOv8 三分量形式；负载均衡损失针对专家坍缩——路由网络倾向把多数输入分给少数「更强」的专家：
LYOLO = Lcls + Lloc + LDFL 分类 / CIoU·DIoU 定位 / 边界框分布
LLB = 1E ∑i=1E ( μi − 1E )2 μi：专家 i 的平均利用率
  • μi 是专家 i 的训练期软权重在 batch 与全部空间位置上的平均占比
  • 最小化 LLB 等价于约束各专家被均匀使用，充分利用全部 E 个专家的容量
  • 只通过训练期软权重 Ωtrain 反传，不牺牲推理期的硬稀疏

Experiments

精度-延迟权衡

YOLO-Master-N 位于 Pareto 前沿左上角（42.4% AP @ 1.62 ms）：比 YOLOv13-N 快 17.8%，仅比最快的 YOLOv11-N 慢 8%——精度提升没有以牺牲实时性为代价。

Ablation

消融 I：放置位置与专家数量

仅骨干 62.1%（+1.3%）；仅颈部 58.2%；双处插入 54.9%

4 专家 62.3%（2.76M）；2 专家 61.0%；8 专家 62.0% 且参数 +33%

  • 级联路由在反向传播中产生相互冲突的路由梯度：更多 ES-MoE 并不保证更好性能，本文采用仅骨干的默认配置
  • 2 专家容量不足，8 专家收益递减——适度的专家多样性已足以覆盖多尺度变化
Ablation

消融 II：Top-K 与损失配置

K=2 在 50% 稀疏度下最优（61.8%）；K=1 表征不足低 0.5%

Config 5（无 DFL、仅权重 1.5 的 MoE 损失）62.2% 最优

  • 两个互补专家即可兼顾特征多样性与计算效率，K 继续增大收益消失
  • DFL 与强 MoE 并存的 Config 4 最差（61.4%）——两者存在梯度竞争
Ablation

损失配置的训练动态

Config 4（DFL + 强 MoE）的损失曲线大幅振荡，Config 5（MoE-only）平滑收敛：DFL 强制的均匀分布精炼与 MoE 损失鼓励的实例自适应专家特化存在梯度竞争，移除 DFL 后 MoE 损失同时承担回归引导与专家特化，训练更稳定。

Experiments

下游任务泛化

检测（COCO S）：49.1% mAP，超 YOLOv13-S 的 48.0%

分类（ImageNet）：Top-1 76.6%，比 YOLOv12-cls-N 高 4.9%

分割（COCO）：mAP mask 35.6%，比 YOLOv12-seg-N 高 2.8%

检测、分类、分割三个任务的一致增益表明 ES-MoE 学到的骨干表征具备跨任务通用性。

Qualitative

可视化分析：四个挑战场景

① 草地小动物：v12 置信度仅 0.47，YOLO-Master-N 达 0.65-0.82；② 海岸伪装：v10-v12 漏检遮挡目标，本文精准定位；③ 剪毛场景：平均置信度 0.85（v13 为 0.77）；④ 密集餐桌：以 0.87-0.97 的高置信度补全大量被漏检的小物件——尺度自适应路由的优势能稳定迁移到真实画面。

Summary

总结与优点

1

范式创新——把混合专家条件计算引入实时目标检测，将静态的精度-效率权衡改造成按输入复杂度动态分配表征容量的可微机制，小目标与密集场景受益最明显（VisDrone +2.1%、KITTI +1.5%）。

2

设计干净利落——软/硬 Top-K 分阶段路由：训练期掩码重归一化保住梯度流动，推理期严格稀疏换来真实加速；门控开销与分辨率无关，条件计算在 Nano 级模型上真正可部署。

3

消融有指导意义——仅骨干放置 ES-MoE 最佳、双处插入因路由梯度冲突反而退化；MoE-only 损失替代 DFL 有训练曲线佐证；五基准加三类下游任务的覆盖说服力强。
