Coordinate Attention
Coordinate Attention for Efficient
Mobile Network Design

把 2D 全局池化分解为两个互补的 1D 特征编码过程，在保留轻量性质的同时把位置信息嵌入通道注意力，MobileNetV2 Top-1 提升 2.0 个百分点。

Qibin Hou · Daquan Zhou · Jiashi Feng
National University of Singapore
注意力模块 移动网络 坐标注意力 即插即用
Contributions

核心贡献：带位置信息的轻量通道注意力

01

2D 池化分解为 1D 编码

用 (H,1) 与 (1,W) 两种池化核分别沿水平与垂直方向聚合，一个方向捕捉长程依赖、另一方向保留精确位置。

02

方向感知注意力图

拼接 → 共享 1×1 卷积 → split → 独立 1×1 卷积生成两张方向感知的权重图，乘积近似 2D 位置选择图。

03

移动网络零开销嵌入

可直接嵌入 MobileNetV2 反转残差块与 MobileNeXt sandglass 块，Pixel 4 延迟仅增 1-2 ms。

在分类、检测、分割三类任务上系统验证，密集预测任务上增益尤为突出——语义分割增益明显大于分类与检测。

Motivation

SE 注意力的位置信息丢失问题

(a) SE 用 2D 全局平均池化压成 C×1×1，位置信息丢失；(b) CBAM 用 7×7 卷积只能捕捉局部关系； (c) 坐标注意力用 X Avg Pool 与 Y Avg Pool 两个 1D 池化保留方向与位置信息。
Method 01

坐标信息嵌入：方向感知的 1D 特征编码

水平方向编码 · 式 (4)

zhc(h) = 1W Σ0≤i<W xc(h, i)

沿水平方向聚合、保留垂直方向的精确位置信息。

垂直方向编码 · 式 (5)

zwc(w) = 1H Σ0≤j<H xc(j, w)

沿垂直方向聚合、保留水平方向的精确位置信息——两个方向的信息互补。

Method 02

坐标注意力生成与方向感知重加权

  • 拼接 + 共享卷积：f = δ(F1([zh, zw]))，压缩进低维中间表示
  • Split + 独立卷积：拆成 fh 与 fw，分别经 Fh、Fw 生成 gh = σ(Fh(fh)) 与 gw = σ(Fw(fw))
  • 逐元素重加权：yc(i,j) = xc(i,j) × gch(i) × gcw(j)
最终输出

yc(i, j) = xc(i, j) × gch(i) × gcw(j)

行注意力与列注意力同时乘到输入上，两张 1D 权重图的乘积近似出一张 2D 位置选择图。

Method 03

嵌入移动网络块的方式

(a) MobileNetV2 反转残差块：注意力接在 Dwise 3×3 之后、Conv 1×1 之前； (b) MobileNeXt sandglass 块：接在第一个 Dwise 3×3 之后。 只增加注意力块自身的少量参数与乘加，不改变原块配置。
Experiments 01

ImageNet 分类：MobileNetV2 +2.0% Top-1

宽度 1.0 时坐标注意力把 Top-1 从 72.3% 提到 74.3%（+2.0），超过 SE 的 +1.2 与 CBAM 的 +1.3。 宽度 0.75 与 0.5 下增益进一步扩大到 +2.2 与 +1.6。
Experiments 02

Grad-CAM：坐标注意力精准锁定对象

加入坐标注意力后高响应区域更贴合对象轮廓：甲虫背部、火烈鸟躯干、啤酒杯口都被紧凑覆盖。 SE 与 CBAM 的响应更弥散、容易扩散到背景区域。
Experiments 03

下游任务：密集预测增益大于分类

  • COCO 检测：MobileNetV2+CA 取得 24.5 AP，超基线 22.3、+SE 的 23.7
  • VOC 2012 分割：mIoU 从 70.84 提到 73.32（stride 16）
  • Cityscapes 分割：mIoU 从 71.4 提到 74.0
  • 分割增益明显大于分类与检测，作者归因于带精确位置信息的长程依赖对密集预测更有益
Experiments 04

消融：两方向互补、缩减比例稳健

  • 只加 X 或只加 Y 方向都只到 73.5%，与 SE 持平
  • 两方向同时加入才达到 74.3%，Pixel 4 延迟仅增 1-2 ms
  • r 减半到 16 后达到 74.7%（+2.4），仍高于 r=12 的 SE 与 CBAM
Summary

优点和创新点

1

2D 池化分解为 1D 编码

在保留轻量性质的同时把位置信息嵌入通道注意力，使移动网络能以近乎零开销关注大区域，思路新颖。

2

插入灵活

可直接嵌入 MobileNetV2 反转残差与 MobileNeXt sandglass 等经典块，在 EfficientNet-b0 上仅替换 SE 即获增益。

3

三类任务系统验证

分类、检测、分割三类任务上系统验证，密集预测任务上增益尤为突出，实验丰富、说服力强。

Coordinate Attention：方向感知、位置精确、轻量高效

把 2D 全局池化分解为两个互补的 1D 特征编码，
在移动网络中以近乎零开销嵌入位置感知的通道注意力。
