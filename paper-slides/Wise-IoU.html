核心贡献：动态非单调聚焦机制

01

WIoU v1 双层注意力

距离注意力放大普通质量锚框的损失，高质量锚框的 LIoU 自动降低关注。

02

离群度动态评价

用 β = L*IoU / L̄IoU 代替 IoU 评价锚框质量，质量划分标准随训练动态更新。

03

WIoU v3 非单调聚焦

同时压制 高质量与低质量锚框，聚焦普通质量样本。

WIoU v3 将 YOLOv7 在 MS-COCO 上的 AP75 从 53.03% 提升到 54.50%。

Motivation

低质量样例：真实训练数据的客观存在

  • 现有 BBR 损失研究大多 默认训练数据是高质量的，把精力放在增强拟合能力上
  • 标注不准、错误、不完整的低质量样例客观存在，盲目加强 BBR 损失反而危害定位
  • Focal-EIoU v1 的聚焦机制是静态的，预先指定质量划分标准，非单调聚焦潜力未充分发掘

核心问题：如何 随训练状态动态评价锚框质量并合理分配梯度增益？

Method 01

WIoU v1：双层注意力机制

WIoU v1 定义

LWIoU v1 = RWIoU · LIoU

RWIoU = exp((d²) / (Wg² + Hg²)*)

RWIoU ∈ [1, e) 放大普通质量锚框的 LIoU；LIoU ∈ [0,1] 在吻合良好时降低高质量锚框的关注。Wg、Hg 从计算图分离（*），不引入阻碍收敛的梯度。

Method 02

WIoU v3：动态非单调聚焦机制

离群度与梯度增益

β = LIoU* / LIoU ∈ [0, +∞)

LWIoU v3 = r · LWIoU v1,   r = β / (δ · αβ−δ)

β 小 = 高质量锚框，β 大 = 低质量锚框。当 β=δ 时 r=1 达最高梯度增益。高质量与低质量锚框同时获得小梯度增益，聚焦普通质量样本。

L̄IoU 是动态的，锚框质量划分标准随之动态变化，WIoU v3 能在每一时刻做出最符合当前情况的梯度增益分配。
Experiments 01

仿真实验：WIoU v1 收敛路径最短

  • 6,860,000 个回归案例的仿真中，SIoU 在现有一系列 BBR 损失中收敛最快
  • 在主要案例中各损失收敛速度 极为接近，差异主要来自不重叠边界框
  • WIoU v1 的注意力机制 对不重叠情形改善最大
Experiments 02

定性验证：WIoU v3 屏蔽低质量样例

带单调聚焦的 WIoU v2 受低质量样例影响产生 较差预测，而 WIoU v3 有效屏蔽这些影响、得到理想预测。
Experiments 03

定量对比：WIoU v3 全表最优

WIoU v3（α=1.9, δ=3）取得 54.50/64.20/45.68 AP75/AP50/AP，为全表最优，相比 CIoU 基线 53.03 AP75 提升 1.47。单调聚焦机制对距离惩罚较强的 SIoU 与 EIoU 产生负面影响，对较弱的 CIoU 与 WIoU v1 则有效。
