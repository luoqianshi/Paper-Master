PAPER READING arXiv 2022
Conv2Former
A Simple Transformer-Style ConvNet
for Visual Recognition

用卷积调制（Convolutional Modulation）替换自注意力，以 Hadamard 积与大核深度卷积构建线性复杂度的 Transformer 风格纯卷积网络。

Qibin Hou · Cheng-Ze Lu · Ming-Ming Cheng · Jiashi Feng
南开大学 TMCC 实验室 · 字节跳动新加坡
骨干网络 卷积调制 大核卷积 arXiv:2211.11943
Contributions

核心贡献：把自注意力归约为一次卷积调制

01

卷积调制操作

用 k×k 深度卷积的输出作为权重，经 Hadamard 积调制 value 分支；HW×HW 的相似度矩阵被换成与特征图同尺寸的权重，空间编码由二次降为线性。

02

五个金字塔变体

以四阶段金字塔堆叠卷积调制块，得到 N/T/S/B/L 五个变体（15M–199M），并给出核尺寸、加权策略、归一化与激活的微设计建议。

03

三任务一致领先

ImageNet 分类、COCO 检测、ADE20K 分割上全面超过 Swin Transformer 与 ConvNeXt；Conv2Former-L 在 ImageNet-22k 预训练后取得 87.7% top-1。

论文的目标不是刷 SOTA，而是回答一个问题：如何更高效地用卷积编码空间特征 —— 答案是一个操作、一套骨干、一组可复用的微设计结论。

Motivation

空间编码的两条路线，缺口在哪里

ConvNet 路线

大感受野，但缺显式全局建模

早期 ConvNet 依靠堆叠卷积块与金字塔结构聚合大感受野响应，却忽视了对全局上下文信息的显式建模；SENet 一系把注意力引入 CNN 以捕获长程依赖。ConvNeXt 用 Transformer 式配方现代化 ResNet，RepLKNet 展示大核潜力，但 ConvNeXt 同时指出：不使用重参数化时核超过 7×7 几乎无增益、只增加计算负担。

ViT 路线

全局成对依赖，代价是二次复杂度

自注意力建模全局成对依赖，在 ImageNet 分类与下游任务上超过当时的先进 ConvNet；但相似度矩阵为 N×N（N = H×W），处理高分辨率图像时的计算代价相当可观，检测与分割等密集预测任务尤为吃紧。

问题至此收窄为：暂未有工作把自注意力归约为一种纯卷积的调制操作，从而更高效地利用大核空间卷积来构造强 ConvNet。

Method 01

从自注意力到卷积调制：只替换权重生成

对长度 N = H×W 的 token 序列 X，自注意力先由线性层生成 key、query、value，输出是 value 按相似度得分 A 的加权平均：

Self-Attention

Attention(X) = AV， A = Softmax(QK⊤)

A 的形状为 N×N，复杂度随序列长度二次增长 —— 这正是卷积调制要替换掉的部分。

  • 卷积调制把 A 换成 k×k 深度卷积的输出：A = DConvk×k(W1X)，权重张量从 HW×HW 缩到 HW×C
  • 差别在于卷积核是静态的、自注意力矩阵随输入自适应；实验表明静态卷积权重同样能取得优异结果
  • H = W = 4、k = 3 的例子：自注意力要为单个位置算 16×16 = 256 个相似度元素，卷积调制只关联窗口内 9 个像素
左（蓝框）自注意力由 Q、K 矩阵乘生成 HW×HW 注意力矩阵；右（橙框）卷积调制用 k×k 卷积直接产出 HW×C 权重，再与 value 做 Hadamard 积。 既然卷积特征也能当权重，空间编码就可以从二次复杂度的矩阵乘法换成线性复杂度的卷积。
Method 02

卷积调制块：用卷积特征当权重

Convolutional Modulation

Z = A ⊙ V，  A = DConvk×k(W1X)，  V = W2X

⊙ 为 Hadamard 积；每个位置 (h, w) 的输出是以它为中心的 k×k 区域内像素的加权和，通道交互交给其后的线性层与 FFN。

从左到右依次是残差块、ConvNeXt 块、Transformer 块与卷积调制块。(c) 需显式构造 HW×HW 的相似度矩阵，而 (d) 的中间张量始终保持 H×W×C。 直接把注意力层换成卷积调制块，就得到完整骨干，对高分辨率输入更省内存。

相比自注意力更省内存，相比经典残差块又能随输入内容自适应 —— 一个操作同时拿到两种好处。

Method 03

四阶段金字塔：与 ConvNeXt、Swin 同构

以 Conv2Former-T 为例，四个阶段分辨率 56×56 → 28×28 → 14×14 → 7×7，块数 {L1, L2, L3, L4} = {3, 3, 12, 3}；阶段之间用 stride 2 的 2×2 卷积做 patch embedding，末端接分类头。
  • 布局与 ConvNeXt、Swin Transformer 一致，便于与同类骨干做受控对比
  • 全网络只含卷积，计算量随图像分辨率线性增长而非二次增长，对检测与高分辨率分割等下游任务更友好
  • 五个变体参数量依次为 15M / 27M / 50M / 90M / 199M
Method 04

模型变体：宽度与深度的分配

  • N / T：通道 {64,128,256,512} / {72,144,288,576}，块数 {2,2,8,2} / {3,3,12,3}，参数 15M / 27M
  • S / B / L：块数 {4,4,32,4} / {4,4,34,4} / {4,4,48,4}，参数 50M / 90M / 199M，通道逐级加倍
  • 阶段比例：ResNet-50 为 (3,4,6,3)，ConvNeXt-T 与 Swin-T 为 (3,3,9,3) 并对大模型用 1:1:9:1 的计算比，本文进一步加深第三阶段
  • 经验结论：小尺寸模型（<30M）取更深的配置表现更好，受控对比见后页 table2
原文 §3.1 架构与阶段配置正文（PDF 页裁剪）：patch embedding 为 2×2、stride 2 卷积，五个变体的通道与块数汇总于 Tab. 1。 本文在 ConvNeXt 的阶段比例上把第三阶段再加深，换来同参数下更高的精度。
Method 05

微设计：核尺寸、加权与归一化

01

核尺寸默认 11×11

ConvNeXt 发现核从 3 增到 7 有效，但继续增大（无重参数化）几乎无增益。本文把卷积特征当权重后，增大 k 等价于扩大每个输出位置的加权感受野，5×5 到 21×21 持续增益，出于效率默认 11×11。

02

Hadamard 积前不加变换

深度卷积输出直接作为权重调制线性投影后的特征，Hadamard 积之前既不加激活也不加归一化（Sigmoid、Lp 归一化都不加），与 SENet 一系在重标定前用 Sigmoid 的做法相反。

03

LN + GELU

沿用 ViT 与 ConvNeXt 的选择，用 LayerNorm 替代 BatchNorm、GELU 作激活，原文报告该组合带来 0.1%–0.2% 的精度提升。块内数据流：深卷积 + 线性层 → Hadamard 积 → FFN。

三条微设计的证据都在实验节：核尺寸见 fig4 的消融曲线，加权策略见 tab. 6 的定量对比。

Experiments 01

实验设置：ImageNet 训练配方

  • 数据：ImageNet-1k 约 120 万训练图、1000 类、5 万验证图；ImageNet-22k 约 1400 万图、21841 类
  • 优化：AdamW，lr = LRbase × batch/1024、LRbase = 0.001，weight decay 5e-2，cosine 衰减，共 300 epochs
  • 增强与正则：MixUp、CutMix、Stochastic Depth、Random Erasing、Label Smoothing、RandAug，Layer Scale 初值 1e-6
  • 22k 流程：预训练 90 epochs 后在 ImageNet-1k 微调 30 epochs；相比 ConvNeXt 不用 layer-wise lr decay 与 EMA
原文附录 A.1 的随机深度率表：ImageNet-1k 上 N/T/S/B 依次 0.1/0.15/0.3/0.7，ImageNet-22k 上 S/B/L 为 0.1/0.2/0.1。 模型越大、正则越强，最大取到 0.7。
Experiments 02

Experiments 05

ImageNet-1k：同规模全面领先

  • Conv2Former-T 27M / 4.4G 达 83.2%，比 ConvNeXt-T（82.1%）高 1.1%、比 SwinT-T（81.5%）高 1.7%
  • Conv2Former-N 仅 15M / 2.2G，精度与 28M / 4.5G 的 SwinT-T 持平（81.5%）
  • S 尺寸 84.1% vs ConvNeXt-S 83.1%、SwinT-S 83.0%；B 尺寸 84.4% vs 83.8% / 83.5%
  • Conv2Former-B 以 84.4% 超过计算量两倍于它的 EfficientNet-B7（84.3%，37G、600²）

Experiments 06

ImageNet-22k 预训练：数据扩展后优势不减

  • Conv2Former-S 84.9%（ConvNeXt-S 84.6%）；B 在 224 / 384 下 86.2% / 87.0%（ConvNeXt-B 85.8% / 86.8%）
  • Conv2Former-L 199M 取得 87.0% / 87.7%，超过 EfficientNetV2-XL（87.3%，208M）与 CoAtNet-3（87.6%）
  • 相对 ConvNeXt 的增益在 22k 预训练后保持一致，说明扩大数据没有抹平架构差异

COCO：检测与实例分割同时领先

  • Cascade 3×：T 51.4 / 44.5、S 52.8 / 45.7、B 52.8 / 45.6，三个尺寸全部领先同规模对手

Ablation 01

消融：核尺寸 5×5 → 21×21 持续增益

左图横轴为核尺寸、右图横轴为模型变体，纵轴均为 ImageNet top-1。T 从 82.8% 升到 83.4%、B 从 84.1% 升到 84.5%，到 21×21 才趋于饱和；把 Hadamard 积换成逐元素相加后四个变体全部掉点。
  • 六档核 {5,7,9,11,15,21}×{5,7,9,11,15,21} 上精度单调上升，与 ConvNeXt「大于 7×7 无增益」的结论相反
  • 小模型从 Hadamard 积中受益更多 —— 调制式加权而非简单相加才是收益的关键来源
  • 曲线在 11×11 之后基本走平，出于模型效率默认取 11×11，兼顾精度与计算量
Ablation 02

消融：加权策略 —— Hadamard 积最优

  • 逐元素相加 82.7%；A 后加 Sigmoid 82.3%；A 后加 L1 归一化 82.8%；把 A 线性归一化到 (0, 1] 82.2%
  • 不做任何变换的 Hadamard 积以 83.2% 最优，全部结果基于 Conv2Former-T
  • 把 A 调成正值反而掉点更多，与 SE、CA 等传统注意力在重标定前用 Sigmoid 的做法相反 —— 加权前的归一化习惯在这里不适用
原文 §4.3 的加权策略讨论（PDF 页裁剪）：原文明确指出 Hadamard 积优于所有其它融合方式，并把「正值化后掉点」留作后续研究。 调制式加权是收益来源，而不是任意融合都能奏效。
Ablation 03

消融：阶段配置 —— 小模型更深更好

  • ResNet-50 (3,4,6,3) 26M / 4.0G 得 78.5%；Swin-T (2,2,6,2) 28M 得 81.5%；ConvNeXt-T (3,3,9,3) 29M 得 82.1%
  • Conv2Former-N (2,2,8,2) 仅 15M / 2.2G 得 81.5%，与 28M 的 Swin-T 持平
  • Conv2Former-T 改为 (3,3,12,3)、27M / 4.4G 得 83.2%，高于 ConvNeXt-T 1.1 个点
  • 结论：参数量固定时，小尺寸模型把预算放在深度（加深第三阶段）比放在宽度更划算
原文 §3.1 stage configuration 正文（PDF 页裁剪）：ResNet-50 的 (3,4,6,3)、ConvNeXt 的 (3,3,9,3) 与 1:1:9:1 计算比，四个 tiny 模型的对比见 Tab. 2。 轻微调整块数即可换来稳定增益。
Ablation 04

与不同核尺寸的大核 ConvNet 对比

  • RepLKNet-31B（31×31，79M）83.5%；ConvNeXt-B（7×7，89M）83.8%；SLaK-B（51×51，95M）84.0%
  • Conv2Former-B 在 7×7 核下即达 84.2%（89M / 15.6G），11×11 核下进一步到 84.4%（90M / 15.9G）
  • 不使用重参数化、不使用稀疏权重，说明卷积调制对大核的利用效率高于传统用法
原文 §4.3 method analysis 正文（PDF 页裁剪）：六档核尺寸 5×5 至 21×21 的消融结论，以及 Hadamard 积优于逐元素相加的分析。 核越大越好的前提，是把卷积特征当作权重来用。
Ablation 05

等向架构：收益不依赖金字塔

  • Conv2Former-IS 23M 取得 81.2%，比 DeiT-S（79.8%）与 ConvNeXt-IS（79.7%）高约 1.5%；改用 3 层卷积做 patch embedding 到 82.0%
  • Conv2Former-IB 86M 取得 82.7%，比 ConvNeXt-IB（82.0%）高 0.7%、比 DeiT-B（81.8%）高 0.9%；3 卷积版到 83.0%
  • 设置与 ConvNeXt 一致：18 个块、plain 结构，16×16 stride 16 卷积或 3 层卷积做 patch embedding
原文 §4.4 等向架构设置（PDF 页裁剪）：18 块 plain 结构，与 DeiT、ConvNeXt 在同等参数与计算下对比，结果见 Tab. 7。 卷积调制的收益不依赖金字塔结构。
Summary

优点和创新点

1

简洁的卷积调制

把自注意力归约为深度卷积加 Hadamard 积，从空间编码视角统一了注意力加权与卷积加权，保留内容自适应调制能力的同时把复杂度从二次降为线性，易于移植。

2

大核卷积的新经验

系统考察大核的使用方式，用 5×5 到 21×21 持续增益的证据修正「大于 7×7 无增益」的既有结论，为 ConvNet 的核尺寸选择提供可复用经验。

3

多维度实验验证

覆盖 ImageNet 分类、COCO 检测、ADE20K 分割三类任务，以及 22k 预训练、等向架构、核尺寸与加权策略消融，证据链完整、说服力强。

Conv2Former：简洁、高效、强大

用卷积调制替换自注意力，
让 ConvNet 回归「以线性复杂度编码空间信息」的本质。
