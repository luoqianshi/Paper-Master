PAPER READING arXiv 2022
Conv2Former
A Simple Transformer-Style ConvNet
for Visual Recognition

用卷积调制（Convolutional Modulation）替换自注意力，以 Hadamard 积与大核深度卷积构建线性复杂度的 Transformer 风格纯卷积网络。

Qibin Hou · Cheng-Ze Lu · Ming-Ming Cheng · Jiashi Feng
南开大学 TMCC 实验室 · 字节跳动新加坡
骨干网络 卷积调制 大核卷积 arXiv:2211.11943
Contributions

核心贡献：把自注意力归约为卷积调制操作

01

卷积调制操作

用 k×k 深度卷积的输出作为权重，经 Hadamard 积调制 value 表征，把空间编码复杂度从 O(N²) 降为线性。

02

释放大核卷积潜力

核从 5×5 增大到 21×21 时精度持续上升，推翻 ConvNeXt「大于 7×7 无增益」的结论。

03

全面超越主流模型

Conv2Former-L 在 ImageNet-22k 预训练后取得 87.7% top-1，在分类、检测、分割三任务上一致领先。

实验覆盖 ImageNet 分类、COCO 检测与 ADE20k 分割，Conv2Former 在全部任务上全面超过 Swin Transformer 与 ConvNeXt。

Motivation

空间信息编码：卷积与自注意力的两条路线

A

ConvNet 路线

堆叠卷积块与金字塔结构聚合大感受野，但缺乏对全局上下文的显式建模。ConvNeXt 表明深度卷积核超过 7×7 几乎不带来性能增益，大核卷积的潜力没有被真正释放。

B

ViT 路线

自注意力建模全局成对依赖，在多个任务上超过 ConvNet，但计算复杂度随分辨率二次增长，处理高分辨率图像时代价可观。

暂未有工作把自注意力归约为一种纯卷积的调制操作，从而更高效地利用大核空间卷积来构造强 ConvNet。

Method 01

从自注意力到卷积调制

左侧自注意力通过 query 与 key 的矩阵乘法生成 HW × HW 的注意力矩阵，右侧卷积调制则直接用 k×k 深度卷积产出与特征图同尺寸的权重——把空间编码的复杂度从二次降为线性。
Method 02

卷积调制块的计算

卷积调制公式

Z = A ⊙ V，  A = DConvk×k(W1X)，  V = W2X

其中 ⊙ 为 Hadamard 积（逐元素乘法），W1 与 W2 是两个线性层的权重矩阵，DConvk×k 表示核尺寸 k×k 的深度卷积。每个空间位置与 k×k 区域内所有像素相关联。

  • 自注意力需要为每个位置计算 HW × HW 个相似度元素
  • 卷积调制只需一次 k×k 深度卷积，计算量只与窗口大小有关
  • Hadamard 积之前不加激活也不加归一化层，是取得好性能的关键
Method 03

四种空间编码块的结构对比

残差块、ConvNeXt 块、Transformer 块与卷积调制块的空间编码对比：卷积调制块用深度卷积 + Hadamard 积替换自注意力，空间编码之后接 FFN 做通道混合，结构简洁。
Method 04

四阶段金字塔整体架构

Conv2Former 采用与 ConvNeXt、Swin Transformer 相同的四阶段金字塔结构，五个变体（N/T/S/B/L）参数量从 15M 到 199M，计算量随图像分辨率线性增长，对检测与分割等下游任务更友好。
Method 05

释放大核潜力：5×5 到 21×21 持续增益

核尺寸从 5×5 增大到 21×21 时精度持续上升，Conv2Former-T 从 82.8% 升到 83.4%，推翻 ConvNeXt「大于 7×7 无增益」的结论；Hadamard 积全面优于逐元素相加。
Experiments 01

ImageNet-1k：全面超越 ConvNeXt 与 Swin

Conv2Former-T 以 27M 参数取得 83.2% top-1，比 ConvNeXt-T 高 1.1%；15M 参数的 Conv2Former-N 与 28M 的 SwinT-T 持平；Conv2Former-L 取得 87.7%。
Experiments 02

COCO 检测与 ADE20k 分割：密集预测同样领先

  • COCO Mask R-CNN 3× schedule：Conv2Former-T 的 box AP 达 48.0，超过 SwinT-T 与 ConvNeXt-T 约 2 个点
  • ADE20k：Conv2Former-T 以 56M 参数取得 48.0 mIoU，比 ConvNeXt-T 高 1.3%
  • Conv2Former-L 达 54.3 mIoU，三个任务上一致领先

卷积调制提取的特征对密集预测同样有效，线性复杂度在高分辨率输入下的红利在检测与分割任务上兑现。

Experiments 03

消融：加权策略与融合方式

  • 加权策略对比（Conv2Former-T）：逐元素相加 82.7%、加 Sigmoid 82.3%、加 L1 归一化 82.8%，而 Hadamard 积 83.2% 最优
  • 在 A 后加 Sigmoid 使性能下降超过 0.5%，与 SE、CA 等传统注意力的做法相反
  • 等向架构下 Conv2Former-IS 以 23M 取得 81.2%，比 DeiT-S 与 ConvNeXt-IS 高约 1.5%

调制式加权（Hadamard 积）而非简单相加，是卷积调制块收益的关键来源。

Summary

优点和创新点

1

简洁的卷积调制

把自注意力归约为深度卷积加 Hadamard 积，保留内容自适应调制能力，空间编码复杂度从二次降为线性。

2

大核卷积新发现

5×5 到 21×21 持续增益的反结论证据，推翻「核大于 7×7 无增益」的既有经验。

3

多维度实验验证

覆盖分类、检测、分割三任务与 ImageNet-22k 预训练、等向架构、核尺寸等多个维度。

Conv2Former：简洁、高效、强大

用卷积调制替换自注意力，
让 ConvNet 回归「以线性复杂度编码空间信息」的本质。
