EMA
Efficient Multi-Scale Attention Module
with Cross-Spatial Learning

通道分组 + batch 维 reshape 避开通道降维，用矩阵点积的跨空间学习融合两条并行分支输出，在 ResNet50 上取得 +3.43% Top-1 增益。

Daliang Ouyang · Su He · Guozhong Zhang · Mingzhu Luo · Huaiyong Guo · Jian Zhan · Zhijie Huang
中国航天科工集团深圳有限公司

Contributions

核心贡献：不降维的多尺度跨空间注意力

01

通道分组 + batch 维 reshape

把部分通道维 reshape 到 batch 维，从机制上避开通道维度缩减，保留每通道信息的同时控制参数量。

02

跨空间学习

用矩阵点积融合两条并行分支输出，捕获像素级成对关系并突出全局上下文，超越简单平均聚合。

03

极致轻量

参数增量仅 0.01M 至 0.22M，在分类与检测上稳定超过 CBAM、SA、ECA、CA。

CIFAR100 上 ResNet50 Top-1 从 77.26% 提升到 80.69%（+3.43%），参数量与 FLOPs 低于 CA。

Motivation

通道降维副作用与并行分支融合不充分

A

通道维度缩减的副作用

SENet 式的通道注意力对每个通道独立做全局平均池化，再用两个 FC 层与 Sigmoid 生成通道权重，但降维会给通道注意力预测带来副作用。

B

并行分支融合不充分

Shuffle Attention、Triplet Attention 等并行子网络的输出大多只用简单平均聚合，像素级的成对关系与全局上下文没有被充分利用。

问题：暂未有工作在不做通道维度缩减的前提下建模跨通道交互，并同时把并行分支的输出特征图做充分融合。

Method 01

EMA 模块整体结构

Groups 之后三路并行：X Avg Pool 与 Y Avg Pool 两条 1D 池化路径属于 1×1 分支，Conv(3×3) 一路属于 3×3 分支。 两路输出在跨空间学习中交叉相乘，把多尺度信息注入同一处理阶段。
Method 02

通道分组与 batch 维 reshape

  • 沿通道维把 X 划分为 G 个子特征：X = [X0, X1, ..., XG-1]
  • 利用卷积核与 batch 维无关的性质，把 G 个组 reshape 并 permute 到 batch 维
  • 分组把「通道间建模」转化为「组间 batch 并行 + 组内跨空间建模」
  • 从机制上避开通道维度缩减，为后续不做降维的卷积打下基础
关键洞察

普通 2D 卷积核的输入维度为 (oup, inp, k, k)，卷积核数量与前向输入的 batch 系数无关，因此可以把 G 个组 reshape 到 batch 维，将输入张量重新定义为 (C//G) × H × W。

Method 03

跨空间学习：矩阵点积融合

  • 1×1 分支：水平与垂直方向 1D 全局平均池化 → 拼接 → 共享 1×1 卷积 → Split → Sigmoid → 乘法聚合
  • 3×3 分支：单 3×3 卷积扩大特征空间，提供多尺度感受野
  • 跨空间融合：1×1 分支输出 reshape 为 (C//G) × (H·W)，3×3 分支输出 2D 池化 + Softmax 后与之矩阵点积
  • 得到两张 1 × H × W 的空间注意力图：一张汇聚多尺度空间信息，一张保留精确位置信息

每个像素的最终权重同时携带了跨尺度信息与全局位置信息，这正是 cross-spatial 一词的含义。

Experiments 01

CIFAR100 分类：EMA 在 ResNet50/101 上领先

ResNet50 嵌入 EMA 后 Top-1 从 77.26% 到 80.69%（+3.43%），Top-5 从 93.63% 到 95.59%。 在几乎相同计算复杂度下，EMA 的 Top-1 比 CA 高 0.52%，参数量与 FLOPs 更低。
Experiments 02

COCO 与 VisDrone 检测：一致性领先

COCO 上 EMA 以 7.24M 参数取得 57.8% mAP(0.5) 与 38.4% mAP(0.5:0.95)，超过 CA 的 57.5% 与 38.1%。 VisDrone 上 EMA 以多 0.22M 参数的代价取得 0.41% 与 0.4% 的提升。
Experiments 03

消融：跨空间学习是增益主源

关闭跨空间学习的 EMAno 取得 78.24% Top-1，开启后 EMA32 达到 80.69%（+2.45%），可见跨空间学习是增益的主要来源。 分组大小为 32 比 16 更优且参数量更低。
Summary

优点和创新点

1

避开通道降维

利用卷积核与 batch 维无关的性质，把部分通道维 reshape 到 batch 维，在保留每通道信息的同时控制参数量，视角新颖。

2

跨空间学习

用矩阵点积融合并行分支输出，捕获像素级成对关系并突出全局上下文，超越了简单平均聚合方式。

3

轻量即插即用

参数增量仅 0.01M 至 0.22M，在分类与无人机航拍检测上稳定超过 CBAM、SA、ECA、CA。
