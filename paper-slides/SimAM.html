SimAM
A Simple, Parameter-Free Attention Module
for Convolutional Neural Networks

借鉴哺乳动物大脑的空间抑制理论，把神经元重要性形式化为一个能量函数并推导出闭式解 —— 以零附加参数直接推断全 3-D 注意力权重，实现不足十行代码，在分类、检测与分割上取得精度-效率双赢。

注意力模块 零参数 3-D 权重 能量函数闭式解 PMLR 139
Contributions

核心贡献：一个由神经科学原理推导出的模块

01

全 3-D 权重 + 能量函数

受人脑注意力机制启发，提出带完整 3-D 权重的注意力模块，并设计一个能量函数来计算这些权重 —— 不再沿通道或空间单一维度精炼。

02

闭式解，不足十行代码

为能量函数推导闭式解，加速权重计算并使整个模块保持轻量形态；实现不到十行代码，且不向原网络添加任何参数。

03

算子由解选出，而非手工堆叠

模块中大多数算子都是依据能量函数的解选出的，避免了大量结构调参；集成进多个知名网络后在多类任务上评测，在精度、模型大小与速度三方面均表现优异。

定位声明：本文聚焦的是一个小的即插即用模块，而不是超越现有 ConvNet 的新架构 —— 目标是让已有网络在不做大改动的前提下进一步提升表示能力。

Motivation · 1/2

即插即用注意力模块：低成本路线的两个问题

  • 为什么值得做：设计残差块、密集连接这类结构需要丰富的专家知识与大量时间；而 SE、CBAM 等模块被插入残差块内部精炼卷积输出，与网络架构无关，因此被广泛部署于 VGG、ResNet、ResNeXt，甚至被纳入 AutoML 的搜索空间。
  • 效果确实存在：SE 让网络能捕获与任务相关的特征（图 1 的「mountain tent」），并抑制大量背景激活（图 1 的「steel arch bridge」）。
问题一

只能沿单一维度精炼

SE 生成 1-D 通道权重、CBAM 生成 2-D 空间权重，把同一通道内或同一空间位置上的所有神经元同等对待 —— 限制了学习「同时在通道与空间上变化」的注意力权重的灵活性。

问题二

结构靠手工因素堆叠

模块结构由池化类型、全连接层、卷积等一系列手工因素堆叠而成，多数权重计算算法基于无理论依据的启发式，设计缺乏统一原则指导，需要大量工程精力做结构调参。

Motivation · 2/2

已有的 3-D 权重方案为什么不够用

既有尝试

两条路都走不通

  • 编码器-解码器子网络（Wang et al., 2017）：确实用手工设计的 encoder-decoder 学习 3-D 权重，但要从 ResNet 的低层到高层逐层引入不同的子网络，难以模块化地推广到其它网络。
  • CBAM 的两步组合：分别估计 1-D 与 2-D 权重再组合，并不直接生成真 3-D 权重，两步式的做法还耗费过多计算时间。
  • Aubry et al., 2014 研究过用于语义部件匹配的类似函数，但需要计算大型协方差矩阵，不适合深度神经网络。
本文的主张

用统一原则替代手工堆叠

  • 3-D 权重的计算应当直接了当，同时让模块保持轻量。
  • 在人类视觉中，基于特征的注意力（对应通道注意力）与基于空间的注意力（对应空间注意力）是共存并共同作用于信息选择的 —— 模块应当同样地给每个神经元分配一个唯一权重。
  • 于是把权重生成formulate 成一个能量函数：算子由解选出，而非凭启发式挑选。
Method · 定位

现有注意力模块概览：1-D、2-D 与真 3-D

三种注意力步骤的对比：(a) 通道注意力从特征 X 生成 1-D 权重再沿空间扩展，(b) 空间注意力生成 2-D 权重再沿通道扩展，(c) SimAM 为特征图上每个点估计一个独立标量，即真 3-D 权重
  • 现有模块通常被集成进每个块中，用于精炼前几层的输出；这个精炼步骤要么沿通道维、要么沿空间维进行，因此生成的是 1-D 或 2-D 权重，把每个通道或每个空间位置内的神经元同等对待，限制了学习更具判别性线索的能力。
  • 图 1 就是一个例证：SE 丢掉了「grey whale」的部分主体组件。据此本文主张完整的 3-D 权重优于传统的 1-D 与 2-D 注意力，并用全 3-D 权重来精炼特征。
Method · 对照

各模块的算子、参数量与设计方式

  • 表中算子缩写：空间/通道平均池化 GAP、CAP，空间/通道最大池化 GMP、CMP，沿空间维计算的标准差 GSP，标准卷积 C2D 与基于通道的卷积 C1D，标准全连接 FC 与逐通道全连接 CFC，层归一化 LN、批归一化 BN、Softmax、ReLU；k 为卷积滤波器数、r 为缩减比、C 为当前特征通道数。
  • SE、CBAM、GC、ECA、SRM 的参数量分别为 2C²/r、2C²/r + 2k²、2C²/r + C、k、6C，且设计方式均为 handcrafted（手工设计）。
  • SimAM 只用到 GAP、除、逐元素乘、加四类算子，参数量为 0，设计方式直接来自后文的最小能量公式 —— 这张对照表把本文的改造方向固定为「用统一原则替代手工堆叠」。
不同注意力模块在结构设计与参数量上的对比：既有模块依赖 FC、Conv2D、BN 乃至高度定制的 CFC 等大量算子，SimAM 参数量为 0
Method · 能量函数

空间抑制与线性可分性：能量函数

神经科学依据：在视觉神经科学中，信息量最大的神经元通常是放电模式与周围神经元显著不同的那些；且活跃神经元会抑制周围神经元的活动，即空间抑制（spatial suppression）。显示清晰空间抑制效应的神经元应在视觉处理中被赋予更高优先级 —— 其最简单的实现，就是度量一个目标神经元与其它神经元之间的线性可分性。

Eqn (1) → 二值标签 + 正则项 → Eqn (2)
et = (yt − t̂)² + (1/(M−1)) Σi=1…M−1 (yo − x̂i)²
et = (1/(M−1)) Σi=1…M−1 (−1 − (wtxi + bt))² + (1 − (wtt + bt))² + λwt²
为简化，对 yt 与 yo 采用二值标签（1 与 −1）并加入正则项；λ 是正则项系数。
t, xi输入特征 X ∈ ℝC×H×W 单个通道内的目标神经元与其它神经元；i 是空间维上的索引，式中所有量都是标量
t̂, x̂i对 t 与 xi 的线性变换：t̂ = wtt + bt，x̂i = wtxi + bt；wt、bt 是变换的权重与偏置
M = H × W该通道上的神经元数量；yt、yo 是两个不同的目标取值
Eqn (1) 的最小值在 t̂ 等于 yt、其余 x̂i 都等于 yo 时取得 —— 最小化该能量等价于寻找目标神经元 t 与同通道所有其它神经元之间的线性可分性，能量越低说明该神经元越「与众不同」。
Method · 闭式解

闭式解与最小能量

Eqn (3)(4) 闭式解 → Eqn (5) 最小能量
wt = − 2(t − μt) / [ (t − μt)² + 2σt² + 2λ ]，   bt = −½ (t + μt) wt
et* = 4(σ̂² + λ) / [ (t − μ̂)² + 2σ̂² + 2λ ]
μt 与 σt² 是该通道内除 t 以外所有神经元的均值与方差（分母 M−1）；μ̂ 与 σ̂² 则是通道内全部 M 个神经元的均值与方差。
  • 为什么需要闭式解：理论上每个通道有 M 个能量函数，用 SGD 一类迭代求解器逐一求解计算负担过重；而 Eqn (2) 关于 wt 与 bt 存在快速闭式解。
  • 为什么能复用均值方差：解是在单通道上得到的，因此假设同一通道内所有像素服从同一分布是合理的；均值与方差可在全部神经元上计算一次并对该通道所有神经元复用，避免逐位置迭代计算 μ 与 σ，显著降低计算成本。
  • 怎么读这个式子：et* 越低，神经元 t 与周围神经元的差异越大、对视觉处理越重要 —— 因此每个神经元的重要性可由 1/et* 获得。
  • 为什么零参数：整个推导只涉及均值、方差与逐元素运算，没有任何需要学习的量 —— 这正是模块无需可学习参数的原因。
Method · 精炼

以缩放方式精炼特征

Eqn (6) 精炼阶段
X̃ = sigmoid( 1/E ) ⊙ X
E 把全部 et* 沿通道维与空间维归组；⊙ 为逐元素相乘。
为什么用缩放

神经增益效应

依据 Hillyard 等人的结论，哺乳动物大脑中的注意力调制通常表现为对神经元响应的增益（缩放）效应 —— 因此选用缩放算子而非加法来做特征精炼。

为什么加 sigmoid

约束过大取值

sigmoid 用于限制 E 中过大的取值；因为它是单调函数，所以不会改变各神经元的相对重要性。

等价理解

逐点门控的重要性图

等价于用一张与特征图同形状的重要性图对特征做逐点门控，从而完成真 3-D 注意力。除通道均值与方差的计算外，模块内其余运算全部是逐元素操作。

Method · 实现

模块实现与插入位置

PyTorch 风格实现（Eqn 6）
# X: input feature [N, C, H, W]
# lambda: coefficient λ in Eqn (5)
def forward(X, lambda):
  n = X.shape[2]*X.shape[3] - 1
  d = (X - X.mean(dim=[2,3])).pow(2)
  v = d.sum(dim=[2,3]) / n
  E_inv = d / (4*(v + lambda)) + 0.5
  return X * sigmoid(E_inv)
  • 借助 PyTorch 一类机器学习库，Eqn (6) 的实现不足十行：先算每个神经元与通道均值之差的平方 d，以 d.sum()/n 得到通道方差 v；再按最小能量公式组装重要性 E_inv；最后返回 X * sigmoid(E_inv)。
  • 插入位置：实现被加在每个块内第二个卷积层之后。

Experiments · CIFAR

CIFAR-10/100 分类：稳定提升且不限于特定网络

  • 把 SimAM 接入 ResNet、Pre-activation ResNet、WideResNet 与 MobileNetV2 等成熟架构，与 SE、CBAM、ECA、GC 四种模块对比，结果为 5 次重复的均值 ± 标准差。
  • SimAM 在全部基线网络上都稳定提升 Top-1 精度：ResNet-20 上 C10 从 92.33 升到 92.73、C100 从 68.88 升到 69.57；在 ResNet-20 与 PreResNet-20 这类小网络上取得所有模块中的最好结果，PreResNet-56 在 C10 上同样最好。
  • MobileNetV2（近 2.4M 参数，比约 1.17M 参数的 ResNet-110 还大）上 SimAM 达到 92.36 ± 0.20（C10）与 72.02 ± 0.28（C100），超过 SE 与 CBAM；同表上 ECA 的 C10 为 92.34、CBAM 的 C100 为 71.79。
  • 约 36M 参数的 WideResNet-20x10 上 C100 也从 81.31 升到 81.51 —— 说明无参数模块的有效性不限于特定网络。
不同网络搭配 5 种注意力模块在 CIFAR-10（C10）与 CIFAR-100（C100）上的 Top-1 精度（%，均值±标准差，5 次试验）：SimAM 在不向基线引入任何参数的情况下取得极具竞争力的结果
Experiments · 超参

λ 分析：宽范围内都稳健

  • 搜索设置：以 ResNet-20 在 CIFAR-100 训练集划分上搜索；由于无法验证 λ 的所有实数值，把候选池设为 10−1 到 10−6；每个 λ 值重复 5 次并报告均值与标准差。
  • 结论一：模块在 10−1 到 10−6 的宽范围内都能显著提升性能。
  • 结论二：λ = 10−4 在 Top-1 精度与标准差之间取得较好平衡。
  • 据此，CIFAR 上所有网络统一取 λ = 1e-4 —— 表明模块对 λ 的取值稳健，不需要逐网络调参。
  • ImageNet 上另搜得 λ = 0.1（以精度与稳健性的折中为准），搜索流程见第 11 页。
ResNet-20 上 λ 搜索的结果（每个取值重复 5 次的均值与标准差，横轴为 10−1 到 10−6 的候选池）：λ = 1e-4 兼顾精度与稳定性

Summary

优点和创新点

1

有统一原则的可解释设计

从神经科学的空间抑制理论出发，把神经元重要性形式化为能量函数的线性可分性，使注意力模块的设计有可解释的统一原则、避免手工结构堆叠，思路新颖、耳目一新。
