ASF-YOLO
A Novel YOLO Model with Attentional Scale Sequence Fusion
for Cell Instance Segmentation

Contributions

核心贡献：为细胞实例分割重新设计 YOLO 颈部

01

SSFF 尺度序列特征融合

将 P3、P4、P5 归一化上采样并堆叠为尺度序列，送入 3D 卷积融合跨尺度的全局语义信息。

02

TFE 三特征编码

把大、中、小三种尺寸特征在通道维拼接，保留小目标的局部细节，经 PANet 融入各分支。

03

CPAM 通道与位置注意力

无降维 1D 卷积捕获跨通道交互 + 方向分解位置注意力，仅 12.23K 参数即取得最高 mAP。

配合 EIoU 损失与 Soft-NMS，ASF-YOLO 在 DSB2018 上以 47.3 FPS 取得 0.91 box mAP50 与 0.887 mask mAP50。

Motivation

YOLO 在细胞实例分割上的瓶颈

A

FPN 融合不充分

YOLOv5 颈部采用 FPN，只以简单的相加与拼接融合金字塔特征，主要利用小尺寸特征图，无法充分挖掘各层特征图之间的相关性。

B

细胞小目标未优化

细胞尺寸小、分布密集、相互重叠且边界模糊，不同细胞图像在颜色、形态、纹理上差异巨大；暂未有工作将 YOLO 用于细胞实例分割。

研究缺口：暂未有工作将基于 YOLO 的模型用于细胞实例分割，并系统处理其中的多尺度融合与小目标注意力问题。

Method 01

ASF-YOLO 整体架构

CSPDarknet53 提取 P1-P5 五层特征；颈部 SSFF + TFE + CPAM + PANet 融合；头部在三个尺度上输出检测框与原型掩码。
Method 02

SSFF：尺度序列特征融合模块

  • P3、P4、P5 特征图先与标准差递增的高斯核做卷积，得到从细到粗的尺度空间表示
  • 用最近邻插值对齐到 P3 分辨率，1×1 卷积调整通道数
  • 用 unsqueeze 扩为 4D 张量并沿 depth 维拼接
  • 用 3D 卷积 + 3D 批归一化 + SiLU完成尺度序列特征提取
核心思想

3D 卷积挖掘金字塔各层之间的尺度相关性，而非仅靠逐元素加法或拼接，使跨尺度的语义信息被系统融合。

Method 03

TFE：三特征编码模块

大尺寸特征经混合池化下采样，小尺寸特征经最近邻插值上采样，三路尺寸一致后通道维拼接。 TFE 不改变空间分辨率，只把三个尺度的细节信息打包进同一张特征图。
Method 04

CPAM：通道与位置注意力模块

通道注意力：无降维方案，用大小为 k 的 1D 卷积捕获局部跨通道交互，k 由 C = 2(γ×k-b) 自动确定。 位置注意力：水平与垂直方向分别池化编码，生成方向感知的注意力坐标。
Method 05

锚框优化：EIoU 损失与 Soft-NMS

  • EIoU 损失：直接最小化目标框与锚框的宽高差异，比 CIoU 更适合小目标定位
  • EIoU = IoU 损失 + 距离损失 + 宽高损失三部分
  • Soft-NMS：用高斯函数衰减重叠框分数而非直接置零，缓解密集细胞的错误抑制
EIoU 损失

LEIoU = LIoU + Ldis + Lasp = 1 − IoU + ρ²(b, bgt)/(wc² + hc²) + ρ²(w, wgt)/wc² + ρ²(h, hgt)/hc²

把宽高比惩罚拆成宽与高两个独立回归项，更直接地捕捉小目标的位置。

Experiments 01

DSB2018 与 BCC 定量结果

  • DSB2018：0.910 box mAP50、0.676 box mAP50:95、0.887 mask mAP50，47.3 FPS
  • BCC：0.911 box mAP50、0.737 box mAP50:95、0.898 mask mAP50
  • YOLOv5l-seg 与 YOLOv8l-seg 分别为 0.876 与 0.865
  • Mask R-CNN 系列只有 20 FPS 上下
Experiments 02

消融实验：逐级增益与注意力对比

  • YOLOv5l-seg 基线 + Soft-NMS → 0.881；+ EIoU → mAP50:95 提升 1.8%
  • 依次叠加 TFE、SSFF、CPAM 后达到 0.910 box 与 0.887 mask
  • CPAM 参数仅增加 12.23K、FLOPs 仅增加 2.96M
Experiments 03

注意力机制可视化对比

SENet 响应接近均匀背景，CBAM 与 CA 已能给出细胞位置响应但仍有残留干扰，CPAM 对细胞区域的响应最清晰，表明从原始图像中挖掘了更丰富的通道与位置特征信息。
Summary

优点和创新点

1

SSFF 与 TFE 互补设计

SSFF 把金字塔特征组织为尺度序列送 3D 卷积，TFE 保留大尺寸特征图细节，二者互补，消融增益逐级可查。

2

CPAM 高性价比

无降维 1D 卷积 + 方向分解位置注意力，以约 12K 参数代价在四种注意力中取得最高 mAP。

3

首次 YOLO 用于细胞分割

在一阶段框架上精度与速度均超过 Mask R-CNN、YOLOv5l-seg 等方法，实验覆盖消融与可视化。

ASF-YOLO：尺度序列融合、细节保留、通道位置注意力

首次将 YOLO 用于细胞实例分割，
在两个数据集上精度与速度均超过 Mask R-CNN 系列方法。
